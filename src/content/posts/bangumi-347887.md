> 最后一个初中的夏天，西片终于要鼓起勇气——这一次，被捉弄的人能不能扳回一局？

说实话，等《擅长捉弄的高木同学》第三季的那两年多里，我一直在想：这部"什么都没发生"的作品，还能怎么拍下去？答案是——**让"什么都没发生"慢慢变成"什么都在发生"**。

![擅长捉弄的高木同学 第三季封面](https://lain.bgm.tv/pic/cover/l/2d/ad/347887_j0DFj.jpg)
*擅长捉弄的高木同学 第三季*

第三季里，高木依旧在捉弄，西片依旧在输，可两个人之间那层窗户纸，已经薄到一戳就破了。西片开始会为高木着想、会主动约她、甚至会为她专门设计一款游戏。这一季，是整个动画系列里"甜度"最高的一季。

# 一、第三季的基本信息

## 1.1 播出与制作

| 项目 | 内容 |
|------|------|
| **原名** | からかい上手の高木さん③ |
| **播出时间** | 2022年1月7日起，MBS / TBS 系列"Super Animeism"档 |
| **话数** | 全12话 |
| **动画制作** | 新锐动画 |
| **监督** | 赤城博昭 |
| **原作** | 山本崇一朗 |
| **人物设定** | 高野绫 |
| **音乐** | 堤博明 |

2021年9月，官方同时宣布了**TV 动画第三季与剧场版**的制作决定。第三季于2022年1月开播，剧场版紧随其后在同年6月上映——可以说，第三季就是为剧场版铺路的"最后一程"。

## 1.2 熟悉的原班人马

监督赤城博昭、人物设定高野绫从第一季一路做到第三季，配音阵容也没有变化：**高桥李依**的高木、**梶裕贵**的西片，以及美奈（小原好美）、友加里（M·A·O）、早苗（小仓唯）三人组。还有中井和真野这对"别人家的情侣"，依旧在西片面前秀着恩爱。

# 二、主题曲：秋冬的声音

## 2.1 片头曲《まっすぐ》

第三季的片头曲依旧由**大原由衣子**作词作曲演唱，歌名叫《**まっすぐ**》（笔直地、坦率地）。从第一季的《言わないけどね。》（虽然我不会说出口），到第二季的《ゼロセンチメートル》（零厘米），再到第三季的《まっすぐ》——**三首片头曲的标题连起来，几乎就是两个人关系的变化**：从说不出口，到距离为零，再到坦率地面对。

## 2.2 八首翻唱片尾曲

第三季延续了"高木翻唱 J-POP"的传统，而且这一季的选曲特别有季节感：

| 话数 | 曲名 | 原唱 |
|------|------|------|
| 第1话 | 《夢で逢えたら》 | 大泷咏一 |
| 第2–3话 | 《Over Drive》 | JUDY AND MARY |
| 第4–5话 | 《ひまわりの約束》 | 秦基博 |
| 第6话 | 《学園天国》 | Finger5（高木与2年2班合唱） |
| 第7–8话 | 《じょいふる》 | 生物股长 |
| 第9话 | 《サンタが町にやってくる》 | 艾迪·坎特 |
| 第10–11话 | 《スノーマジックファンタジー》 | SEKAI NO OWARI |
| 第12话 | 《花》 | GENERATIONS from EXILE TRIBE |

第6话的《学园天国》是全班合唱，西片、木村、高尾和三人组都来了，热闹得像一场班级联欢；到了第9话的圣诞歌和第10–11话的《雪之魔法幻想》，片尾画面也换成了冬天。听着这些歌，就像跟着高木和西片一起，从秋天走到了冬天。

# 三、第三季看点梳理

> ⚠️ 以下内容包含第三季动画的情节描述。

## 3.1 季节的推进

第三季最明显的变化是**季节**。前两季多是春夏的明亮色调，而第三季带着观众走进了秋天和冬天：枫叶、文化祭、寒风里一起回家、圣诞节、下雪的小镇……季节变了，两人之间的氛围也跟着变了——少了几分夏天的打闹，多了几分冬天的温柔。

## 3.2 西片的"主动"

如果说前两季的西片还停留在"想赢高木"的阶段，那第三季的西片已经在不知不觉中，**开始为高木着想**了。他会担心高木冷不冷、会在意高木开不开心、会主动做一些让高木惊喜的事。他嘴上还在说着"这次一定要赢"，可行动已经暴露了一切。

高木当然都看在眼里。她的捉弄依旧，可看着西片时的眼神，越来越温柔。

## 3.3 "西片斗恶龙"

第三季最后一集里，西片为高木设计了一个充满谜题的游戏——"**西片斗恶龙**"（西片クエストオンライン），让高木来挑战。一个总是被捉弄的少年，花心思为喜欢的女孩做了一整套游戏，这份笨拙的用心，大概是西片能想到的最浪漫的事了。

更有意思的是，节目播完后，动画官网真的做出了网页游戏版的"西片斗恶龙"供大家免费游玩——**观众也可以亲自体验一下西片的心意**。

## 3.4 配角们的故事

中井和真野依旧是西片眼中"别人家的恋爱"，滨口和北条的故事、三人组的日常也穿插其中。这些配角的存在，让这个小小的海边小镇显得更加热闹、更加真实。

---

# 四、两人关系的变化

## 4.1 高木：等待快要结束了

从第一季开始，高木就一直在等——等西片看懂她的心意、等西片主动回应。到了第三季，她能感觉到那一天快来了。她的捉弄里，多了一些"试探"的味道：**她想知道，西片是不是也和自己一样**。

## 4.2 西片：心意快要藏不住了

西片自己大概还没完全意识到，但他的心早就交出去了。他在意高木的一举一动，会因为高木的一句话开心一整天，也会因为担心高木而手足无措。第三季的西片，**已经站在告白的门口了**，只差最后一步。

而这最后一步，留给了剧场版。

---

# 六、总结：笔直地走向你

第三季的片头曲叫《まっすぐ》——笔直地。我觉得这个词，正好说明了这一季的西片：他终于不再绕着弯子去"赢"高木，而是开始笔直地走向她。

如果说第一季是"心动的开始"，第二季是"距离为零"，那么第三季就是"**终于快要说出口了**"。秋天的枫叶、冬天的雪、圣诞夜的灯光，都在为一句话做准备。

**那句话，留给了那个最后的夏天。**
