> 只会做雏人偶脸的少年，遇见了想穿上心爱角色服装的辣妹——两个人的“喜欢”，在缝纫机前悄悄相遇。

说实话，《更衣人偶坠入爱河》是那种你以为它是“擦边番”，看完却被它的真诚打动的作品。宣传图上是穿着各种服装的辣妹，第1话的台词尺度大到让人想关窗——可越往下看越会发现，这部作品真正在讲的，是**“喜欢一样东西，有什么错”**。

![更衣人偶坠入爱河封面](https://lain.bgm.tv/pic/cover/l/9c/4d/333158_PA0F4.jpg)
*更衣人偶坠入爱河*

一个从小因为喜欢女儿节娃娃而被嘲笑、从此不敢说出自己爱好的少年；一个讨厌别人贬低自己爱好、喜欢什么就大声说出来的少女。当她对他说“好厉害”的那一刻，他心里那道多年的伤口，第一次开始愈合。

# 一、作者与原作

## 1.1 原作基本信息

| 项目 | 内容 |
|------|------|
| **原名** | その着せ替え人形（ビスクドール）は恋をする |
| **简称** | 着せ恋（Kisekoi） |
| **作者** | 福田晋一 |
| **连载** | 《YOUNG GANGAN》2018年No.3（2018年1月19日）至2025年No.7（2025年3月21日） |
| **出版** | 史克威尔艾尼克斯 |
| **繁体中文版** | 东立出版社 |
| **简体中文版** | 哔哩哔哩漫画（杭州翻翻动漫代理） |

单行本的封面人物全部是海梦，从第2卷起都是她 Cosplay 之后的模样——让读者欣赏作者精心设计的服装。

## 1.2 创作背景

在漫画开始连载的一年前，福田晋一多次到女儿节娃娃专门店“**铃木人形**”取材，第三代老板铃木庆章就是男主角五条新菜的原型。

几个有意思的创作细节：

- 海梦是为希望“想跟 Cosplayer 交往”“学生时期想跟这样的女生交往”的男性读者设计的。
- 新菜最初的设定其实更放松：对海梦不用敬语，也不是没有朋友。但为了衍生出“两人一同解决问题”的情节，最终设定为**没有朋友、父母双亡**，以消除他能寻求帮助的对象。
- 为了让读者在第1话就留下深刻印象，作者写了“圣♡湿漉漉女子学园”这种尺度很大的台词，也因此在连载前**完全不指望能动画化**，设计服装时也没有为动画考虑简化。

## 1.3 销量与奖项

| 时间 | 累计发行 |
|------|------|
| 2020年11月 | 超过200万本 |
| 2021年10月 | 超过300万本 |
| 动画首播时（2022年1月8日） | 超过350万本 |
| 播映一个月后（2022年2月2日） | 超过450万本 |
| 2022年3月25日 | 超过550万本 |
| 2024年11月 | 系列累计超过1200万本 |

动画播出一个月，销量就暴涨了100万本——这大概是“动画带动原作”最直观的例子之一。

奖项方面，本作获得2019年下一部漫画大赏纸本部门第6名、2020年电子漫画大赏男性部门奖、2020年全国书店店员推荐漫画第3位，并在2023年 BookLive 读者票选恋爱漫画中排名第2。

# 二、剧情简介

**五条新菜**是一名高中一年级学生，受祖父影响，喜爱制作女儿节娃娃，立志成为娃娃工匠。但青梅竹马一句不认同他兴趣的话，给他留下了心理创伤，也让他从此不善于表达自己的情感。

第一学期的某天，班上的中心人物**喜多川海梦**看到新菜在学校的服装室里缝制娃娃的衣服。她观察了新菜的缝纫技巧后，拜托他为自己制作喜欢的游戏角色的 Cosplay 服装。新菜从来没给真人做过衣服，但在海梦的强烈请求下还是答应了。

新菜误以为时间很紧，在面临考试和祖父身体不适的情况下，咬牙熬夜完成了服装——这让海梦非常感动。两人一起参加了 Cosplay 活动，而海梦，也在这时对新菜萌生了爱意。

# 三、动画制作信息

## 3.1 播出与制作阵容

2021年4月16日宣布动画化，TV 动画第1期于**2022年1月8日**开播，全12话，动画制作为 **CloverWorks**。

| 职位 | 人员 |
|------|------|
| **导演** | 筿原启辅 |
| **系列构成、全话剧本** | 富田赖子 |
| **人物设定、总作画监督** | 石田一将 |
| **服装设定** | 西原惠利香 |
| **音乐** | 中冢武 |
| **旁白** | 富冈美沙子 |
| **动画制作** | CloverWorks |

导演筿原启辅接下这份工作时，原作才出到第4卷，篇幅上做不到结局，所以系列构成一开始也没决定最终回要做到哪里。

## 3.2 《奇蛋物语》的班底

这部动画的制作阵容里，有大量《奇蛋物语》的熟面孔：动画制作人梅原翔太是《奇蛋物语》的制作人，人物设定石田一将、总作画监督川妻智美都参与过《奇蛋物语》；第17话的分镜由《奇蛋物语》导演若林信担当。第8话的海边美术板由《奇蛋物语》美术监督船隐雄贵负责，片头曲 CD 的封面也是他画的。

除此之外，动画工房的山崎淳亲自担任第11话作画监督，负责了其中180个镜头。**一部恋爱喜剧，用的是做原创大作的阵容**——这也是它画面如此精致的原因。

## 3.3 故事编排的巧思

制作组讨论后认为，第1话停在那段对话——“《圣♡湿漉漉女子学园 大小姐是耻辱俱乐部 淫乱的梦幻生活2》的黑江雫！”“你说什么？”——是最好的。导演希望海梦的性格在后半才慢慢展露，以免观众太早猜到发展；篇幅不足的部分，则增加了新菜家里的描写。

第2话则**只包括量尺寸的剧情**，用加强作画来对应，不推进到之后的校园剧情，以免观众不明白这一集想表达什么。看过的人都知道，这个决定有多正确。

## 3.4 声优阵容

| 角色 | 声优 |
|------|------|
| 喜多川海梦 | 直田姬奈 |
| 五条新菜 | 石毛翔弥（幼时：高柳知叶） |
| 干纱寿叶 | 种崎敦美 |
| 干心寿 | 羊宫妃那 |
| 五条薰 | 斧笃志 |
| 姬野天音（天野千岁） | 村濑步 |
| 五条美织 | 富冈美沙子 |

四位主要角色的声优都是第一次共演，全部通过试音获得角色，其中只有种崎敦美是资深声优；**这也是新人羊宫妃那第一次通过试音拿到动画角色**。种崎敦美试音时除了纱寿叶，还应征了心寿。

直田姬奈收到的演技指示很有意思：以“有男子气概”“像个小学生男孩子”为基础，比起可爱，更追求爽快感。而石毛翔弥和直田姬奈还会根据原作漫画做一些剧本上没有的即兴演出，比如第1话海梦在新菜答应时高兴得跳起来的样子。

由于声优人数少，本作没有受到疫情期间收录人数限制的影响，大家都是一起录音的。石毛翔弥提到，虽然和种崎敦美是初次见面，但第6话浴室一幕两人一起惨叫时依然非常合拍。

# 四、第1期剧情解析

> ⚠️ 以下内容包含第1期动画的剧情，未看者请注意。

## 4.1 黑江雫：第一件衣服

海梦想 Cos 的第一个角色，是美少女游戏里的**黑江雫**。新菜第一次为真人量尺寸、第一次做真人的衣服、第一次熬夜赶工——当海梦穿上那套衣服站在他面前时，新菜看到的不只是一个 Cosplayer，而是自己的手艺第一次被一个人如此珍视。

## 4.2 朱朱与心寿：姐妹的愿望

第6话，高人气 Cosplayer“**朱朱**”——干纱寿叶登场。她在 Cos 展上察觉到海梦扮演的黑江雫，被精细的服装吸引，跟踪新菜找上门来。她从不与人合作、不参加活动，是 Cos 界的“孤狼”，而她唯一的摄影师就是妹妹心寿。

纱寿叶身材娇小，心寿却有178公分的高个子。心寿一直只为姐姐拍照修图，心里却希望能和姐姐一起 Cos，因为觉得自己不适合而作罢——后来，在新菜的帮助下，她终于达成了愿望。

## 4.3 夏天：烟火、海边与心动

除了做衣服，海梦和新菜也一起逛街、看烟火、看电影，关系越来越近。第8话的海边、各种夏日约会，是第1期最甜的部分。

动画还在宣传期做了一件很可爱的事：2022年3月起与 motto cafe 合作，菜单里有海梦在**第7话做坏了的蛋炒饭**。

## 4.4 海梦的“自觉”

海梦在第一次合作 Cos 之后就逐渐喜欢上了新菜，而新菜一开始完全没有察觉，只把她当作“做衣服的朋友”。第1期的大部分甜度，都来自海梦一个人的手忙脚乱：她会因为新菜一句无心的“喜多川同学，非常的美丽”而当场宕机，会在心里大喊，又在新菜面前装作若无其事。

# 五、角色深度解析

## 5.1 五条新菜：被一句话困住的少年

新菜擅长裁缝与化妆，无论对象是娃娃还是真人，也有丰富的服装知识。他因为童年那句否定，不敢再说出自己的爱好，不喜欢女性多的场合，对人群有些微恐慌，因此**憧憬着和自己完全相反的海梦**。

随着为海梦等人制作服装的次数增加，他的手艺越来越好，也和同学们建立起了羁绊。他的成长不是“变得自信”这么简单，而是**终于相信：自己喜欢的东西，也可以被别人喜欢**。

## 5.2 喜多川海梦：喜欢就要说出来

海梦性格外向、行动力高，食量有点大，不擅长手工和料理。她是典型的御宅族，喜欢的东西从儿童向魔法少女动画到成人游戏都有，也最讨厌别人贬低自己的爱好、讨厌自己的立场被无视。

她对新菜说的“好厉害”，不是客套，而是发自内心的赞美——**这正是新菜这么多年来最需要听到的话**。海梦的魅力，在于她的坦率不需要任何理由：喜欢就是喜欢，好就是好。

## 5.3 干纱寿叶：认真的孤狼

纱寿叶比新菜大一岁，小时候以成为魔法少女为目标，现在用 Cos 魔法少女角色代替了儿时的梦想。她说自己做 Cosplay 只是为了自己，也只会留下好看的照片。种崎敦美用一种又凶又认真的语气演她，让这个角色比外表看上去成熟得多。

## 5.4 干心寿：高个子的温柔

心寿和姐姐的关系很好，是姐姐的专属摄影师。她因为身高觉得自己“不适合”Cos，却一直默默羡慕着。羊宫妃那的第一个试音角色，就是这样一个内向又温柔的女孩。

## 5.5 五条薰：新菜的爷爷

斧笃志配音的五条薰，是一位老练的女儿节娃娃工匠，也是新菜唯一的家人。新菜对娃娃的爱、对手艺的执着，都是从爷爷那里来的。

# 六、Cosplay 的真实感

## 6.1 不只是“穿上衣服”

本作以 Cosplay 为主轴，除了服装制作，还有大量关于**化妆和摄影**的描写，以反映 Cosplayer 的真实状况。新菜要为海梦量尺寸、选布料、做道具、调整假发、化妆，甚至要考虑拍照时的光线和角度——每一套衣服背后，都是一整套工程。

手工艺用品店“Yusawaya”的店员宇佐见创，经常给新菜提供制作 Cos 服的建议；动画还原创了一个角色“葵”，专门负责讲解 Cosplay 相关的知识。对于完全不了解这个圈子的观众来说，看完这部动画，大概会对“Coser 到底有多辛苦”有一个全新的认识。

## 6.2 剧中作：为了 Cos 而虚构的作品

为了让海梦她们有角色可 Cos，作品里虚构了一大批“剧中作”，动画也为它们专门做了角色设计：

| 剧中作 | 类型 | 相关角色 |
|------|------|------|
| 《圣♡湿漉漉女子学园……2》 | 美少女游戏 | 黑江雫：海梦 Cos 的第一个角色 |
| 《花公主烈！！》 | 魔法少女动画 | 黑翠蝶花（二阶堂音苑）由海梦 Cos；黑百合（二阶堂紫苑的暗堕形态）由纱寿叶 Cos；天花寺飒马由心寿 Cos |
| 《超畅销高中生轻小说作家的我每晚受到淫魔夜袭很困扰》 | 四格漫画 | 淫魔莉兹：海梦 Cos 的角色 |
| 《太空偶像宇宙恋人》 | 偶像养成游戏 | 初濑川昴：姬野天音初遇新菜和海梦时 Cos 的角色 |

《花公主烈！！》甚至有一整套专门的角色设计、道具设计和作画监督（山本ゆうすけ），还为这些“不存在的角色”请了宍户留美、桑岛法子、大谷育江等声优。**为了一部虚构的作品认真到这种程度**，本身就是对 Cosplay 文化的一种尊重。

## 6.3 一个小插曲

第2话新菜玩《湿漉女2》时的屏幕画面，播出时用过曝处理成了一片白；不过制作组其实画好了实际的游戏画面，放在了 BD 里。这大概是对原作“尺度”最温柔的一次妥协。

# 九、观看顺序与入坑建议

## 9.1 观看顺序

1. TV 动画第1期（2022年1月，全12话）
2. TV 动画第2期（2025年7月起）

原作漫画已于2025年3月完结，想知道两人的结局，可以去看原作。

## 9.2 适合谁看

- 喜欢恋爱喜剧，尤其是“女追男”“女主角主动”的观众；
- 对 Cosplay、手工、服装制作感兴趣的观众——本作对化妆和摄影的描写也相当写实；
- 曾经因为自己的爱好而被嘲笑过的人。

需要提醒的是，本作有不少强调性感的情节，介意的话请斟酌。但如果你能接受，就会发现它的内核其实非常温柔。

---

# 总结

《更衣人偶坠入爱河》讲的是两个人如何互相拯救：海梦需要一个能把她喜欢的角色“做出来”的人，新菜需要一个能告诉他“你喜欢的东西很好”的人。一针一线缝出来的，是衣服，也是两颗慢慢靠近的心。

**喜欢一样东西从来都不是错——能遇到一个和你一起喜欢的人，才是最大的幸运。**
