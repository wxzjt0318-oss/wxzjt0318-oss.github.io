> “我要成为莉莉艾露！”——对三次元毫无兴趣的漫研社长，遇见了想变成他心中偶像的少女。

说实话，《2.5次元的诱惑》刚播的时候，我是带着一点偏见点开的：Cosplay 题材、露出度不低的服装、一个对三次元没兴趣的男主角——怎么看都像是一部“擦边福利番”。

![2.5次元的诱惑封面](https://lain.bgm.tv/pic/cover/l/53/13/410346_MmQCm.jpg)
*2.5次元的诱惑*

可看了几集以后，我发现自己完全想错了。这部作品真正在讲的，是**一群人怎么认真地去喜欢一样东西**：喜欢一个角色喜欢到想变成她，喜欢摄影喜欢到半夜研究布光，喜欢 Cosplay 喜欢到为了它跟父母、跟过去、跟网络上的恶意对抗。服装可能很大胆，但这份“喜欢”的姿态，干净得让人羡慕。

# 一、原作：少年 JUMP+ 上的 Cosplay 青春

## 1.1 作品基本信息

| 项目 | 内容 |
|------|------|
| **原名** | 2.5次元の誘惑（リリサ） |
| **作者** | 桥本悠 |
| **连载** | 少年 JUMP+，2019年6月15日—2025年12月20日 |
| **出版** | 集英社；繁体中文版由青文出版社代理 |
| **主题** | Cosplay |
| **获奖** | “下一部人气漫画大赏2020”网络漫画部门第4名 |
| **累计发行** | 截至2022年12月超过170万册（含电子版） |

《2.5次元的诱惑》是**桥本悠**在少年 JUMP+ 上连载的漫画，从2019年6月一直连载到2025年12月，最终话为第200话。日文标题里“诱惑”一词的注音是“リリサ”（莉莉纱）——**这部作品的“诱惑”，从一开始指的就是女主角本人**。

连载节奏上，本作起初每周六更新，2021年起改为连载三周休一周，同年4月底又改为隔周连载。对于一部服装、道具、摄影细节都需要大量考据的作品来说，这样的节奏调整并不意外。

## 1.2 衍生游戏

本作还推出了衍生手游《2.5次元的诱惑 天使们的舞台》（简称“リリステ”），由 Aiming 开发，2024年9月3日开服，登陆 iOS、Android 与 PC 平台，中文版由大宇资讯代理。官方后来宣布英文版与简体中文版于2026年1月14日终止运营。游戏原创剧情“2.5次元的爱情（真由梨）”篇讲述了羽生真由梨的过往，共15章，于2026年9月完结。

# 二、故事简介

高二学生**奥村正宗**是校内漫画研究社唯一的社员兼社长。他对三次元女性毫无兴趣，只喜爱二次元的角色，尤其是漫画角色**莉莉艾露**。

某天，学妹**天乃莉莉纱**来到了社团。同样热爱莉莉艾露的她与奥村志趣相投，她想 Cos 成莉莉艾露，请奥村协助她拍摄写真 ROM。

尽管奥村一直宣称自己对三次元没有兴趣，但他实在太想要一个同好了，于是让莉莉纱入了社，答应了她的请求。

问题是——Cos 成莉莉艾露的莉莉纱，在奥村眼里既不是二次元，也不是三次元。她是**“2.5次元”**。而这件事，让奥村的信念开始剧烈地动摇。

# 四、分阶段剧情解析

> ⚠️ 以下内容包含原作与动画的剧情剧透。

## 4.1 漫研社与第一张 ROM

故事的起点很简单：一个只想守护二次元的社长，一个想变成二次元的学妹。

奥村和莉莉纱熬夜制作写真 ROM，参加了第一次展售会，莉莉纱也借此交到了许多 Coser 朋友。在回程的路上，莉莉纱向奥村道谢，并说出了她的心意。

为了提升自己的摄影能力，奥村向在展售会上认识的摄影师**荻野**讨教，并立下了一个目标：**让莉莉纱登上 Cos 界的顶点**。从这一刻开始，奥村不再只是“帮忙拍照的社长”，而成了莉莉纱真正的搭档。

## 4.2 青梅竹马的反击

奥村和青梅竹马**橘美花莉**重逢了。美花莉是人气模特儿，上过电视，却暗恋了奥村十多年。她把莉莉纱视为潜在的威胁，于是 Cos 成莉莉艾露的搭档**米莉艾拉**，试图挽回奥村。

美花莉的加入，让这部作品多了一条清晰的恋爱线，也让“Cosplay 小队”初具雏形。有趣的是，她原本对 Cosplay 并没有兴趣——她 Cos 的动机，一开始纯粹是“为了奥村”。

## 4.3 老师是前四天王

奥村发现学校的家政科老师**羽生真由梨**竟然是前 Coser，而且是 Cos 界“四天王”之一的“真由罗”。真由梨为了偿还学生贷款放弃了 Cosplay，转而当了老师，生怕自己曾贩售写真 ROM 的过去曝光而影响执教。

但她同样欣赏莉莉纱的 Cosplay。最终，她勉为其难地答应担任漫研社的指导老师，让社团免于废社的危机。

## 4.4 与753的较量

在 Cosplay 活动中，莉莉纱与四天王之一的**753♡**正面较劲。753是专门承接企业委托的 Coser，却在网络上遭到“为了赚钱而 Cos，对角色没有爱”的诽谤，于是对那些纯粹出于喜爱而 Cos 的人产生了敌意。

在753的质问下，莉莉纱重新思考了“我为什么要 Cosplay”这个问题。而同为四天王的真由梨重披战袍为她暖场，莉莉纱的气势最终压过了753，被视为**四天王候补**。之后，753也与莉莉纱和解，开始不时给她建议。

这一段是全作最精彩的部分之一：它没有简单地把“商业 Coser”塑造成反派，而是让两种“喜欢”正面碰撞——**为了生计而 Cos，难道就不是爱吗？** 753的愤怒是真实的，莉莉纱的困惑也是真实的。

## 4.5 越来越大的小队

随着故事推进，来自其他学校的**惠比寿乃爱**（NONOA）和**喜咲亚理亚**也加入了莉莉纱的圈子。乃爱是社交障碍极重、却因“无表情酷脸”风格而广受好评的新人 Coser；亚理亚则是个对 Cosplay、漫画、动画都不太了解的新手，她 Cos 的理由，是想借此找到下落不明的漫画家父亲。

就这样，漫研社的社团教室里，渐渐坐满了一群各怀心事、却同样热爱 Cosplay 的人。

# 五、角色深度解析

## 5.1 奥村正宗：嘴上说着“不要三次元”的人

奥村是漫研社社长，母亲不知去向，与姐姐也很疏远。他宣称“对三次元女性没有兴趣”，其实是源于**过去的创伤**。

他对莉莉纱有着类似恋爱的感情，却坚持“不会用有色的眼光看待她”，保证要把她当做同好朋友来对待——尽管在周围人眼里，他们的相处模式早就像恋人了。

我很喜欢奥村的一点是：**他的“喜欢”是有原则的**。他尊重莉莉纱作为 Coser 的选择，尊重她想要表达的东西，从不把她当成被凝视的对象。这个设定，恰恰是这部作品能够在大胆服装下依然显得干净的关键。

（顺带一提，他平时看起来不怎么运动，其实一直在暗中锻炼——外表单薄的社长，实际上有六块腹肌。）

## 5.2 天乃莉莉纱：想要变成喜欢的角色

莉莉纱比奥村低一个年级，平时戴眼镜，Cos 时换隐形眼镜。她没有 Cos 专用的艺名，也没有社交媒体账号，所以在 Cos 圈里，大家就直接叫她“莉莉艾露”。她的目标是制作一款**终极的莉莉艾露写真 ROM**。

她起初对奥村只有朋友和同好的友谊与敬意，后来才意识到自己真的爱上了他，并在与淡雪英里华拍摄外景时向奥村表白。原作中，她还有一个更远的梦想：**成为 Cosplay 服装设计师**。而这个梦想被重视学历的母亲发现时，一度被误认为是在从事情色行业——这段与家人的冲突，是莉莉纱最需要勇气的一场“Cos”。

## 5.3 橘美花莉：十年的单恋

美花莉是莉莉纱的同班同学，人气模特儿“美花琳”，长相天生丽质。她小时候因为头发毛燥而饱受欺凌，是奥村帮了她。从那以后，她对奥村怀着十多年的好感。

她是 Cos 小队里最有常识的人，可一旦牵涉到奥村，就会变得行为失常——只要奥村说一声好，连原本不想 Cos 的角色她都会毫不犹豫地接受。这份“狂热”背后，是一个被救赎过的女孩，十年如一日地想要站到救她的人身边。原作最终话（第200话），她向奥村表白，确认了关系。

## 5.4 惠比寿乃爱：无表情的天才

乃爱有着极重的社交障碍，初次见面无法正常交谈，甚至会不经意地流露出怒视的表情。正因如此，她 Cos 时总是保持无表情的酷脸——结果这种风格反而让她扮演的“库莉亚”大受好评，成了下一代新人四天王的候选之一。

她制作服装和道具的能力在主要角色中最为出众，和莉莉纱一起主导做衣服；她对恋爱极度迟钝，完全没发现身边几个女孩对奥村的好感；漫画里她还经常被画成二头身，成了吉祥物一般的存在。**乃爱是这部作品“不需要恋爱也能闪闪发光”的证明。**

## 5.5 喜咲亚理亚：为了寻找父亲而 Cos

亚理亚来自单亲家庭，母亲工作忙碌，所以她很会做饭。她的父亲是漫画家**日枯阳一**，下落不明。为了传达对父亲作品的喜爱、借由 Cosplay 成名进而找到父亲，她第一次参加 Cos 活动时，扮演的就是父亲漫画里的角色。

奥村一直支持着她寻父的愿望，她也渐渐对奥村产生了好感。亚理亚的故事给 Cosplay 赋予了另一层意义：**扮演一个角色，也可以是向创造这个角色的人喊话。**

## 5.6 四天王：Cos 圈的不同答案

“Cosplay 四天王”是这部作品最有深度的群像之一，每一位都代表着一种对 Cosplay 的态度：

| 四天王 | 态度 |
|------|------|
| **真由罗**（羽生真由梨） | 为了现实放弃，又为了后辈复出 |
| **753♡** | 把 Cosplay 当成职业，养活自己一辈子 |
| **淡雪英里华** | 把 Cosplay 视为艺术，一年只为一场夏日同人展 |
| **星月夜姬** | 渴望被认可与关注，主 Cos 当红作品 |

尤其是“淡雪英里华”这个双人组合：前 Coser 英里华负责服装和摄影，现役 Coser 小雪负责展示。英里华因为难以维持理想体型，想出了“让别人来 Cos，就能永远 Cos 下去”的办法——这份执念，既浪漫又有点心酸。

# 六、主题曲

| 类型 | 曲名 | 演唱 | 使用话数 |
|------|------|------|------|
| 片头曲1 | 《シャッターチャンス》（快门时机） | めいちゃん | 第1—12话 |
| 片头曲2 | 《ツギハギの翼》（拼接的翅膀） | SORARU | 第13—23话 |
| 片尾曲1 | 《Watch Me》 | 天乃莉莉纱（前田佳织里）、橘美花莉（鬼头明里） | 第1—12话 |
| 片尾曲2 | 《Release Sigh》 | 莉莉纱、美花莉、乃爱（铃代纱弓）、亚理亚（渡部纱弓） | 第13—20、22—24话 |

一个特别可爱的彩蛋是：**这四首歌全部“逆输入”回了原作漫画**——在第193话的卡拉 OK 回里，由主角们亲口演唱。动画和原作就这样互相致敬了一次。

《シャッターチャンス》这个歌名也很贴切：对摄影师奥村来说，每一个“快门时机”，都是他和莉莉纱一起追逐的瞬间。而片尾曲从两人合唱的《Watch Me》变成四人合唱的《Release Sigh》，也恰好对应着 Cos 小队从两个人变成一群人的过程。

# 七、观看建议

- **适合谁看**：喜欢“御宅/同好”题材的观众；喜欢看一群人为同一件事拼尽全力的青春群像的观众；对 Cosplay 文化感兴趣的观众——本作对服装制作、摄影、展会文化的描写相当细致。
- **需要注意**：本作的服装尺度不小，福利镜头也有，介意的观众请做好心理准备。但请相信，它的内核远比外表认真。
- **想继续看**：24话动画之后，第2期已宣布制作；原作漫画已于2025年12月完结，共200话，想提前知道结局的可以直接补漫画。

# 总结：介于二与三之间的那份喜欢

《2.5次元的诱惑》的标题里，“诱惑”被注音为“莉莉纱”。可看完之后你会发现，这部作品里真正诱人的，不是哪件服装，也不是哪个镜头，而是**每个人谈起自己喜欢的东西时，眼睛里的那道光**。

奥村说他对三次元没有兴趣，可他最终爱上的，是一个为了接近二次元而拼尽全力的三次元女孩。这大概就是“2.5次元”的意思——**当一个人认真地去喜欢，她就会站在梦想与现实的正中间，闪闪发光。**
