> 被父母抛弃的打工少年，成了学院第一大小姐的贴身侍从——而这位大小姐，完全没有生活自理能力。

说实话，这部作品的标题长到我第一次念的时候差点断气：《才女的侍从 在满是高岭之花的贵族学校暗中照顾（毫无生活自理能力的）学院第一大小姐》。但标题里那个括号——"毫无生活自理能力的"——一下子就把整部作品的笑点和萌点都交代清楚了。

学院第一的才女、人人仰望的高岭之花，回到家就变成一滩只会喊"伊月"的软泥。而负责照顾她的，是一个靠打工养活自己的普通高中生。这种反差，就是这部作品最甜的地方。

# 一、作者与原作

## 1.1 原作基本信息

| 项目 | 内容 |
|------|------|
| **中文名** | 才女的侍从 在满是高岭之花的贵族学校暗中照顾（毫无生活自理能力的）学院第一大小姐 |
| **原名** | 才女のお世話 高嶺の花だらけな名門校で、学院一のお嬢様（生活能力皆無）を陰ながらお世話することになりました |
| **作者** | 坂石游作 |
| **插画** | みわべさくら |
| **网络连载** | 2020年4月2日起于成为小说家吧连载 |
| **文库** | HJ文库，2021年5月1日起发行 |
| **漫画** | 水岛空彦作画，2021年7月2日起于"Comic Fire"连载 |

本作最初是坂石游作在"成为小说家吧"上连载的网络小说，网络版原题就是《在满是高岭之花的贵族学校暗中照顾（毫无生活自理能力的）学院第一大小姐》。书籍化时，原题被改为副标题，前面加上了主标题"才女的侍从"。

## 1.2 剧情简介

高中生**友成伊月**每天辛勤打工，某天却被父母抛弃。之后，他卷入了一场针对日本财阀千金**此花雏子**的绑架事件，意外引起了雏子的注意。此花家的女仆**静音**将他安排在此花家工作和生活，他也和雏子一起进入贵皇学园，成为了雏子的贴身侍从。

雏子表面上才貌双全，其实是个毫无生活能力的懒散之人。然而因为家庭的缘故，她不得不在学院里扮演"完美的大小姐"。想要保护这样的她，伊月尽心尽力地照顾着她；而雏子，终于也可以向伊月全力撒娇了——

"现在……伊月不在身边的话，不要。"

一段与反差萌大小姐一同开始、超越主从关系的恋爱故事，就此展开。

# 三、剧情解析

> ⚠️ 以下内容涉及原作剧情，介意者请先观看动画。

## 3.1 绑架事件：主从关系的起点

伊月的父母沉迷赌博，他只能靠打零工维持生计。某天晚上，父母离家出走，几乎没给他留下一分钱。高二开学前一天，他在路上发现一张遗落的学生证，结果意外和雏子一起被劫匪绑架，又一同被此花家的女仆静音救出。

被绑架期间，雏子还优哉游哉地提出要上厕所、喝茶、吃点心。获救后，因为伊月的细致照顾，她指名让伊月来当自己的侍从。于是伊月从龙宫高中转学到了富家子弟云集的私立学校贵皇学园，寄宿在此花家，开始了"贴身侍从"的生活。

## 3.2 学院日常：膝枕、薯片与"三秒规则"

两人第一天一起上学就开始互相喂食，雏子还经常让伊月给她膝枕。放学时她不想回家，伊月只用一包薯片就把她"钓"了回去。

为了和伊月待在一起，雏子参加了大正克也和旭可怜举办的茶会。伊月又把天王寺美丽和都岛成香也叫了过来，茶会之后，大家都成了朋友。茶会上，伊月教给大家一个没有科学根据的平民说法——"三秒规则"。从没接触过这些的大小姐们，觉得很有趣。

## 3.3 宴会风波：完美演技的代价

雏子在宴会上和父亲一同招待客人，努力扮演举止得体的大小姐。可一时松懈，她忘了场合，用"三秒规则"捡起桌上的碎屑吃了下去——结果客人撤回了亲事的介绍，伊月也被父亲解雇，雏子则被要求一刻也不准停止"完美"的演技。最后，在静音的帮助下，伊月才得以被重新雇回。

这一段是整部作品情感最重的地方之一。伊月带给雏子的"轻松"，恰恰是此花家最不允许她拥有的东西。

## 3.4 天王寺美丽的婚约

美丽因为伊月礼仪上的不自然，开始怀疑他的伪装身份。后来她从养母口中听到了伊月身份设定的漏洞，又派人去此花家侦察，发现伊月和雏子住在一起，感到自己被欺骗。她把伊月叫到道场，用竹刀狂砍，逼他说出了真实身世——但之后，她又亲自请求此花家不要让伊月退学。

美丽向伊月透露，自己如果接受婚约，很可能会马上退学。意识到她并不想离开的伊月，邀请她在休息日一起去游戏中心。最终，在得知父母其实很重视自己是否幸福之后，美丽决心正视自己内心的感情，拒绝了婚约。

# 四、角色深度解析

## 4.1 友成伊月：普通人的温柔

伊月出身贫寒，被父母抛弃，却没有因此变得冷漠。他对雏子的照顾，不只是"侍从的工作"，而是真心想要保护一个被迫扮演完美的人。他在贵皇学园里是个格格不入的"伪装者"，却也正因为这份普通，成了大小姐们身边最自在的存在。

## 4.2 此花雏子：最喜欢薯片的高岭之花

雏子出身于日本最富有的家族之一此花家。在学校里，她是学习运动万能、被同学称作"高岭之花"的完美千金；可在侍从面前，她懒散到了极点——前几任侍从都干不到一个月，前一任甚至胃穿孔了。她最喜欢薯片，在家基本都在睡觉。

她的母亲已经去世。她之所以要伪装完美，是因为要作为此花家长子的替代，寻找入赘女婿作为家族继承人——这给她带来了很大的精神负担。

她喜欢和伊月在一起时那种轻松自在的感觉，于是对他产生了感情。只要伊月和别的女生互动，她就会不高兴：看到伊月摸成香的头，她当场发表了"主权宣言"；伊月留宿天王寺家之后，她更是醋意全开。伊月陪美丽去过游戏中心后，作为补偿也带雏子去了一次——她竞速游戏、太鼓游戏全都惨败，还嘴硬说"真正的太鼓我才不会输"——不过气垫球最后赢过了伊月。

## 4.3 天王寺美丽：骄傲又温柔的对手

美丽是与此花家匹敌的名门天王寺家的千金，也是集团继承人——其实是天王寺家的养女。她极度自豪，自认是雏子的竞争对手，一头金色竖卷发漂亮到有人怀疑是染的。

她严于律己、宽于待人。第一次见面时，她恼怒于伊月知道此花集团却不知道天王寺集团，却还是帮他把雏子掉在女厕所的钱包拿了出来。因为觉得伊月太过自卑，她主动提出指导他礼仪，渐渐对他产生了感情。

她以为伊月和自己一样是养子，因此感到亲切；发现被骗后用竹刀狂砍，却又亲自为他求情。去游戏中心时，赛车、气垫球、保龄球、太鼓全都惨败，卡拉OK却靠儿歌拿了高分——因为她不会唱流行歌。**骄傲、认真、又有点笨拙**，是美丽最可爱的地方。

## 4.4 都岛成香：重逢的青梅竹马

成香是都岛家的独生女，家里经营体育用品制造企业。她个性内向，不善与人沟通。她和伊月从小就认识，并对他怀有感情，在贵皇学园重逢时欣喜若狂。她是伊月已故外婆老家的亲戚，自幼师从父亲接受训练，武术和运动都很强，但除了历史以外的科目都比较弱。

她的父亲都岛武藏也有一段趣事：伊月小时候曾未经同意带成香出去玩，武藏本想向他道谢，结果因为表情太吓人，伊月以为自己在挨骂，吓得逃走了。

## 4.5 鹤见静音与此花华岩

- **鹤见静音**：此花家的女仆，总是冷静沉着，能力出众，对雏子却很温柔，总把雏子的意愿放在雇主华岩的命令之上。她一边照顾雏子，一边训练伊月成为雏子得力的侍从。
- **此花华岩**：雏子的父亲，总资产三百兆日元的此花家族长。他收留伊月做女儿的贴身侍从，却警告他"敢对我女儿出手的人，我都会杀了他"。为了此花家，他希望雏子成为出身良好的新娘。

## 4.6 贵皇学园的同学们

- **旭可怜**：伊月和雏子的同班同学，个性友善，家里经营零售业，"杰斯电器"业绩名列全国第五，在学院里态度很脚踏实地。
- **大正克也**：同班同学，自称个性朴实，其实家里是大型货运公司"大正搬家"。和旭关系很好。

# 五、入坑建议

- 喜欢**反差萌大小姐**和"照顾系"恋爱喜剧的观众；
- 喜欢主从关系、贵族学园题材的观众；

全12话，甜度很高，节奏轻快。如果看完意犹未尽，原作小说和漫画都可以继续追。

# 总结

《才女的侍从》讲的是一个被要求"完美"的女孩，终于找到了一个可以不完美的地方。伊月照顾的不只是她的生活，更是她那份被压在"高岭之花"之下的真实。

**在所有人面前完美，只在一个人面前任性——这大概就是被喜欢的样子。**
