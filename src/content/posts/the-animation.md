> 修学旅行的夜里，他只想和女朋友完成一次初吻——偏偏所有人都回来了，两个人只好躲进了壁橱。

说实话，“捉迷藏”这个标题第一眼看上去，很难让人联想到恋爱故事。可等你知道它讲的是什么——修学旅行的夜里，一对恋人为了躲开突然回来的同学，慌慌张张地挤进同一个壁橱——就会明白这个名字起得有多贴切：**这是一场两个人的“捉迷藏”，心跳声比谁都大**。

之前这篇写得很短，因为资料太少。这次补齐了原作、制作和声优的信息，重新整理一遍。

*爱我「捉迷藏」THE ANIMATION*

先说清楚：这是一部**成人向（18禁）OVA**。如果你未满十八岁，或者对这类内容没有兴趣，可以直接关掉这一页了。下文只聊作品背景、制作、角色和系列关系，不涉及露骨内容。

# 一、作品基本信息

## 1.1 基本资料

| 项目 | 内容 |
|------|------|
| **中文名** | 爱我「捉迷藏」THE ANIMATION |
| **原名** | らぶみー『かくれんぼ』THE ANIMATION |
| **别名** | Hide & Seek |
| **形式** | 成人向 OVA |
| **推出时间** | 2025年9月26日 |
| **话数** | 全1话（约30分钟） |
| **原作** | きょくちょ《捉迷藏》《还要捉迷藏》（短篇漫画） |
| **动画制作** | Studio 1st |
| **发行** | Pink Pineapple |

“らぶみー”是英语“Love me”的日文写法，也就是系列名“爱我”；书名号里的“かくれんぼ”意思是“捉迷藏”。

## 1.2 原作：两部短篇

这部 OVA 改编自原作者きょくちょ的两篇读切（单篇）漫画：

| 年份 | 篇名 | 说明 |
|------|------|------|
| 2018 | 《捉迷藏》（かくれんぼ） | 修学旅行之夜的故事 |
| 2020 | 《还要捉迷藏》（もっとかくれんぼ） | 两人交往之后的续篇 |

一篇讲“开始”，一篇讲“之后”。动画把两篇放进同一话里，正好构成一个完整的小故事：从第一次心动，到成为一对稳定的恋人。

## 1.3 原作者：きょくちょ

きょくちょ（英文常写作 Kyockcho）以细腻的表情刻画闻名，被宣传为“融化表情大师”，代表作是同样已经动画化的《枫与铃》。和《枫与铃》的姐妹双女主不同，《捉迷藏》把镜头收窄到一对普通的校园情侣身上——这也让作者擅长的“表情”变得更加集中。

# 二、故事舞台

> ⚠️ 以下只介绍两段故事的设定与舞台，不描述具体内容。

## 2.1 《捉迷藏》：修学旅行之夜

修学旅行的夜里，**Ryou** 一个人偷偷溜进了女生房间——他想和女朋友 **Hina** 完成两人的初吻。可就在这时，同房间的女生们陆续回来了，计划彻底乱了套。情急之下，两个人决定躲进壁橱里……

修学旅行、深夜、偷偷溜进的房间、随时可能被发现的紧张感——这是校园恋爱故事里最经典的一类场景。所谓“捉迷藏”，指的就是这场躲在壁橱里、屏住呼吸不敢出声的“躲猫猫”。

## 2.2 《还要捉迷藏》：交往之后

自修学旅行那一夜之后，Hina 和 Ryou 作为恋人一直相处得很好。只是 Ryou 冒出了一个让 Hina 头疼的念头。某天社团活动时，Hina 突然被 Ryou 叫到体育仓库，听他提出了一个“请求”……

续篇的舞台从旅馆换成了学校，“躲起来”的主题却一脉相承：两个人的小秘密，总是藏在不会被人发现的角落里。

## 3.1 制作阵容

这套班底和三年前的《枫与铃》完全一致：监督太多秀太、人物设计兼作画监督マツジュン、Studio 1st 制作、Pink Pineapple 发行。同一位作者的作品交给同一套人马，画面风格自然一脉相承。

**枫**的客串是这部作品给系列老观众的一个小彩蛋：她来自《枫与铃》，声优也沿用了阳向葵ゅか。

# 四、角色介绍

## 4.1 Hina——健康开朗的女主角

Hina 是 Ryou 的女朋友，一个健康开朗的少女。她是故事真正的主角：从修学旅行那一夜的手足无措，到交往之后被男友的“请求”弄得哭笑不得，观众看到的，是她面对恋人时一次次心跳加速、又一次次“拿他没办法”的样子。

## 4.2 Ryou——想要“更进一步”的男朋友

Ryou 是 Hina 的男朋友。两段故事都由他的“计划”开始：先是想在修学旅行完成初吻，后来又有了新的念头。他的冲动和笨拙，正是故事里所有“意外”的来源。

## 4.3 远藤爱奈与枫

远藤爱奈是登场的配角之一；而枫则是从《枫与铃》客串而来的角色，让两部动画有了交集。

## 4.4 一对一的纯爱

和《枫与铃》的三人关系不同，《捉迷藏》是彻底的一对一：没有第三个人的拉扯，只有两个人之间的距离一点点缩短。题材标签也从“姐妹”变成了“纯爱”。如果说《枫与铃》的看点是“反差”，那《捉迷藏》的看点就是“心跳”。

# 五、系列关系

## 5.1 与《枫与铃》的联系

[《爱我「枫与铃」THE ANIMATION》](/posts/the-animation-338672/)（2022年，3话）是“爱我”系列的第一部动画。三年半之后推出的《捉迷藏》，原作者、制作公司、监督、人物设计全部相同，并让枫以客串身份登场——两部作品因此被串成了同一个系列。

## 5.2 两部作品对照

| 项目 | 爱我「枫与铃」 | 爱我「捉迷藏」 |
|------|------|------|
| **推出时间** | 2022年3月 | 2025年9月 |
| **话数** | 3话（每话约27分钟） | 1话（约30分钟） |
| **原作** | 《枫与铃》系列 | 短篇《捉迷藏》《还要捉迷藏》 |
| **主角** | 双胞胎姐妹与学生会书记 | 一对校园恋人 |
| **核心看点** | 姐妹的冷热反差 | 情侣之间的心跳 |

## 5.3 观看顺序

两部作品故事独立，从哪一部开始都可以。不过按推出顺序先看《枫与铃》，再看《捉迷藏》，就能认出枫的客串。

# 总结

《爱我「捉迷藏」THE ANIMATION》只有一话，却把两篇短篇串成了一个完整的小故事：从修学旅行之夜的手忙脚乱，到交往之后的新烦恼。同一位作者、同一套班底，换了一对主角，也换了一种甜法——《枫与铃》靠姐妹的反差，《捉迷藏》靠恋人之间的心跳。

**躲进壁橱的那一刻，捉迷藏就开始了；只是这一次，谁都不想被找到。**
