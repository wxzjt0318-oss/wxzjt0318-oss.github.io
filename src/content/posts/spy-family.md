> 间谍爸爸、杀手妈妈、会读心的女儿——三个各怀秘密的人，凑成了全东国最“普通”的一家。

说实话，第一次听到《间谍过家家》的设定时，我的第一反应是：这也太“满”了吧？间谍、杀手、超能力者，随便拎出一个都能撑起一部动作片，结果作者偏偏把他们塞进了同一套公寓、同一张餐桌，让他们去应付孩子的入学面试、邻居的闲话和周末该去哪儿玩。

![间谍过家家封面](https://lain.bgm.tv/pic/cover/l/de/4a/329906_hmtVD.jpg)
*间谍过家家*

可看完第一部分的十二话，我才明白这种“满”恰恰是它的妙处。**每个人都在撒谎，可每个人撒谎的理由，都是为了别人。** 劳埃德装成好父亲，是为了一个“不会让孩子哭泣的世界”；约尔装成普通的妻子，是为了让弟弟安心；阿尼亚装作什么都不知道，是因为她太害怕再被送回孤儿院。这三个谎言叠在一起，竟然成了最真诚的一个家。

# 一、原作：一部“明亮而欢乐”的漫画

## 1.1 作者与连载

| 项目 | 内容 |
|------|------|
| **原名** | SPY×FAMILY |
| **作者** | 远藤达哉 |
| **连载平台** | 集英社《少年Jump+》 |
| **连载开始** | 2019年3月25日，隔周一更新 |
| **主要荣誉** | 2020年版《这本漫画真厉害！》男生篇第一名 |
| **累计发行** | 截至2024年12月突破3800万册 |

《间谍过家家》是**远藤达哉**在《少年Jump+》上连载的漫画。它是《少年Jump+》史上第一部连载首话留言就突破2000则的作品，第五话时阅览数就超过了300万；第七卷发售时，又成为这个平台第一部销量破千万的漫画。2019年还拿下了第五届“下一部人气漫画大赏”网络漫画类第一名。

## 1.2 从《I SPY》到《间谍过家家》

远藤达哉的前一部长篇是2010年至2012年连载的《月华美刃》。完结之后，他陆续画了三部单篇：《炼狱的阿西娅》《予石薄红 予铁以星》和《I SPY》，而《间谍过家家》正是这三篇的要素集结而成。

其中最直接的前身是《I SPY》：主角是一名擅长变装的男间谍，却误把一个对他释出好意的奇怪女高中生当成了敌人。读者对这篇单篇的好评，让远藤决定开始一部间谍题材的连载。有意思的是，约尔那离谱的体能和“黑暗料理”设定，就是从《I SPY》的女主角身上沿用过来的；而阿尼亚的设计灵感，则来自《炼狱的阿西娅》的女主角。

远藤此前的作品偏黑暗，这一次他和长年合作的责任编辑林士平商量好：**不画沉重的东西，要让它成为一部明亮且欢乐的漫画**，线条也尽量简化，力求容易理解。标题最初只是编辑随手起的暂定名“Spy Family”，后来两人想了一百多个候选，最终还是用了英文“SPY FAMILY”，再在中间加上一个“×”。

一个小彩蛋：单行本每一卷的封面上都有一把知名设计椅，第1卷的劳埃德坐的是勒·柯布西耶设计的 LC2 扶手椅，第2卷的阿尼亚坐的是棉花糖沙发，第3卷的约尔则斜倚在伊姆斯夫妇的云朵椅上。

## 1.3 世界观：影射冷战的东西两国

故事背景被远藤笼统地设定在1960至1970年代。**东国**影射冷战时期的东德，首都巴林特影射柏林；**西国**则影射西德，是主角“黄昏”的祖国。两国之间打过两场“东西战争”，十年前才停战，如今维持着脆弱的冷战状态。

西国的情报机构“WISE”原型是英国秘密情报局，东国的国家保安局则参照了东德的史塔西——被黄昏称为“WISE的天敌”。姓氏“Forger”本身就是“伪造者”的意思，**一家人从名字开始，就是假的**。

选角里有个很有名的小故事：**种崎敦美最初接到的其实是约尔的试音**，可她觉得“这个角色非早见沙织莫属”，主动请求改试阿尼亚——结果这一换，换出了一个几乎无可替代的阿尼亚。她那种带着奶音、说话颠三倒四却又鬼精鬼灵的语气，让“阿尼亚知道”“阿尼亚喜欢花生”这些台词都成了当年的流行语。

另一个让观众会心一笑的点是：江口拓也和早见沙织曾在《我的青春恋爱物语果然有问题。》里分别为比企谷八幡和雪之下雪乃配音，于是这部作品也被网友戏称为“大老师和雪乃的婚后生活”。

# 三、剧情简介

这是一个世界各国都在暗地里展开激烈情报战的时代。为了缓和东西两国的紧张局势，西国顶尖间谍“黄昏”奉命调查东国国家统一党总裁**多诺万·德斯蒙**的战争计划——行动代号〈枭（Strix）〉。

麻烦在于，德斯蒙深居简出，唯一会公开露面的场合，是他儿子就读的名校**伊甸学园**半年一度的联谊会，而且只有成绩优异、获得〈皇帝的学徒〉头衔的学生和家长才能参加。于是任务变成了：**一周内组建一个家庭，让孩子考进伊甸学园，再一路拿到八颗星星。**

黄昏化名精神科医生“劳埃德·福杰”，先从孤儿院领养了女儿阿尼亚，又和市政府公务员约尔假结婚。可他不知道，阿尼亚是能读懂人心的超能力者，约尔则是暗杀组织〈花园〉的杀手。三个人各怀秘密，就这样过起了虚假的家庭生活——而整个世界的和平，就托付在这个状况百出的临时家庭身上。

# 四、第1部分剧情解析

> ⚠️ **以下内容包含第一季第1部分的剧情剧透，未看过的朋友请谨慎阅读。**

## 4.1 第一阶段：一周内凑出一个家

黄昏在孤儿院遇见了阿尼亚。阿尼亚读心发现眼前这个人是间谍，兴奋得眼睛发亮，于是靠读心“作弊”完成了报纸上的填字游戏，让黄昏以为她是个聪明孩子而收养了她。她不知道的是，在这之前的一年里，她已经被领养过四次、又被退回了四次。

为了让阿尼亚更像“名门子女”，劳埃德带她去裁缝店订做衣服，偶然遇见了约尔。阿尼亚读心发现她是杀手，激动得不行，立刻开始撮合：“阿尼亚没有妈妈好寂寞。”而约尔这边，正因为大龄单身容易被怀疑是间谍而发愁，本想找个人假扮男朋友——结果误打误撞，两人直接演成了假夫妻。

### 关键情节节点

- **手榴弹拉环的求婚**：劳埃德原本准备了戒指，却在混战中弄丢了。在前有约尔表白、后有追兵的情况下，他扔出手榴弹，用拉环当戒指向约尔求婚——这大概是动画史上最“硬核”的求婚之一。
- **户籍上的谎言**：两人在户籍上伪装成一年前就已结婚，对外则说劳埃德的前妻已经去世，他是在帮失去母亲的阿尼亚找妈妈。
- **唯一的知情者**：一家三口里，只有阿尼亚知道全部真相。她称劳埃德为“父亲”、约尔为“母亲”，每天在心里一边吃瓜一边替这个家捏把汗。

## 4.2 第二阶段：伊甸学园的入学考试

伊甸学园是东国历史悠久的贵族学校，入学除了笔试，还有父母必须同时出面的**三方面试**，对家庭背景尤其看重。劳埃德行事谨慎到了极点，为了应对突发情况，特地给自己和家人各准备了两套备用衣服。

### 关键情节节点

- **约尔的“防身术”**：面试当天，约尔察觉到有许多视线在暗中观察他们；也是在这段剧情里，她用类似点穴的招式只身放倒了一头牛，再次刷新了观众对“普通公务员”的认知。
- **入学成功**：阿尼亚最终考进了伊甸学园，并在劳埃德的安排下，和德斯蒙的次子**达米安**分到了同一个班。

## 4.3 第三阶段：一拳打出来的“雷电”

伊甸学园的校规很严：表现好的学生奖励一颗〈星星〉，表现差的就罚一道〈雷电〉，集满八道雷电直接退学。任何暴力行为，一次就罚三道。

第一次见面，达米安就对阿尼亚冷嘲热讽。阿尼亚想起妈妈说的“遇到刁难要一笑了之”，结果露出的是那个后来风靡全网的**轻蔑微笑**——“呵”。达米安被彻底激怒，阿尼亚也忍无可忍，用妈妈教的防身术一拳把他打飞了。

### 关键情节节点

- **从三道雷电到一道**：按校规阿尼亚该领三道雷电，但她用“达米安踩了贝姬的脚”替自己开脱，竟然得到了舍监亨德森老师的欣赏，最终只记一道——不过她依然成了全年级第一个拿到雷电的学生。
- **结识贝姬**：大型军事企业的大小姐**贝姬**成了阿尼亚的第一个好朋友。
- **达米安的心动**：在劳埃德的要求下，阿尼亚向达米安道歉，结果达米安莫名其妙脸红逃跑——他自己死也不肯承认，但这一拳确实打出了点别的东西。
- **“计划B”**：劳埃德在主线之外准备了备用方案“好朋友大作战”，让阿尼亚和达米安成为朋友，借机去德斯蒙家直接接触目标。可惜这位“好朋友”的开局，实在有点惨。

## 4.4 第四阶段：躲避球与第一颗星星

第1部分的后半段，节奏更像一连串轻快的家庭短篇：约尔的弟弟**尤里**登门，这位从小被姐姐照顾大的“究极姐控”，真实身份是东国的秘密警察，而他完全不知道姐姐“结婚”了；劳埃德为了不被邻居怀疑，周末带全家去水族馆，偏偏额外任务的地点也在水族馆，一波三折之后，阿尼亚收获了一只玩具企鹅“企鹅曼”。

### 关键情节节点

- **躲避球作战（第10话）**：为了帮阿尼亚赢下躲避球比赛，约尔在小树林里亲自示范投球。第一球随手一扔，球反弹几次折断了一棵树；第二球的“必杀技”拖着金色的尾巴穿过整片树林，在水库上溅起数米高的浪花——教学效果为零，喜剧效果拉满。
- **第一颗星星**：在一次社会实践中，阿尼亚“救”起了一个溺水的小男孩（其实她不会游泳，真正下水的是暗中跟着的劳埃德），成为年级第一个拿到星星的学生。
- **达米安的维护**：有人嫉妒阿尼亚、说她坏话来讨好达米安，达米安虽然一肚子不甘心，却没有否定阿尼亚的努力，反而替她说话——这让被集体冷落的阿尼亚得到了安慰。

到这里，枭作战的进度不过是“一颗星星、一道雷电”，离八颗星星还遥遥无期。可福杰一家已经在邻居眼中成了“幸福而普通的一家”。筋疲力尽的劳埃德本想申请长假，看到阿尼亚的笑脸后，却更坚定了要守护“不会让孩子哭泣的世界”的决心。

# 五、角色深度解析

## 5.1 劳埃德·福杰：舍弃本名的〈黄昏〉

| 项目 | 内容 |
|------|------|
| **代号** | 黄昏 |
| **伪装身份** | 巴林特综合医院精神科医生 |
| **声优** | 江口拓也 |
| **特长** | 易容、格斗、枪械、情报处理、料理 |
| **睡眠** | 每天只睡2小时 |

劳埃德是那种“六边形战士”式的主角：战斗力、记忆力、情报处理能力都极其优秀，还是易容高手，每次任务都换一副面孔和名字——不过太过离谱的体型差异他也伪装不了，比如扮成相扑力士或小孩子。他做饭的手艺是一流厨师水准，家里的早晚饭和后来的狗粮都由他负责；为了阿尼亚，他还戒了烟。

他最有意思的矛盾在于：嘴上反复强调“扮演家人只是为了任务”，行动上却一次次把家人的心情放在任务前面。**他太在乎阿尼亚和约尔的感受，在乎到常常想太多**——这份笨拙，才是这个完美间谍身上最像“人”的地方。

## 5.2 约尔·福杰：会脸红的〈荆棘公主〉

| 项目 | 内容 |
|------|------|
| **旧姓** | 布莱尔 |
| **年龄** | 27岁 |
| **表面身份** | 巴林特市政府公务员 |
| **真实身份** | 〈花园〉杀手〈荆棘公主〉 |
| **武器** | 针状苦无 |
| **声优** | 早见沙织 |

约尔幼年父母双亡，为了养活弟弟尤里才成了杀手。她是本作已知角色中最强的战力——官方设定里，如果约尔的身体能力是100，劳埃德大概只有60到70。可她同时又是个性格天然、对自己的美貌毫无自觉的“残念系”美人：做饭能把人和狗吃到昏死，酒量半瓶威士忌就倒，害羞到极点时还会控制不住力气，一脚把劳埃德踢到看见走马灯。

旧姓“Briar”意为野玫瑰，代号“荆棘公主”取自格林童话里的《荆棘玫瑰》——美丽，却浑身带刺。早见沙织把她温柔时的轻声细语和杀气外露时的冷冽演得判若两人，这种反差正是约尔的魅力所在。

## 5.3 阿尼亚·福杰：知道一切的小女孩

| 项目 | 内容 |
|------|------|
| **代号** | 实验体007 |
| **年龄** | 谎称6岁，实际约4到5岁 |
| **能力** | 读心（新月时会失灵） |
| **喜欢** | 花生、间谍动画《间谍大战争》 |
| **声优** | 种崎敦美 |

阿尼亚曾是某组织的超能力实验体，受不了每天无趣的“读书”而逃出研究所。她讨厌学习，字写得连擅长破解暗号的劳埃德都看不懂，可关键时刻又勇敢机智。作者把她定位为**拥有上帝视角、最贴近读者的角色**——全家只有她知道所有人的真实身份，于是观众也跟着她一起“吃瓜”。

她的“呵”之笑在2020年的官方票选中以大优势夺得“最佳表情”第一，还被做进了优衣库联名T恤；2023年，她甚至被《新闻周刊》日本版选为“世界尊敬的百大日本人”之一，是少数登上这份榜单的虚构角色。

片头曲《混合坚果》由藤原聪作词作曲，轻快的旋律配上“混在一起的坚果”这个意象，简直就是为福杰一家量身定做——一群毫不相干的人，被硬凑在一起，却意外地合拍。星野源包办词曲编唱的《喜剧》则温柔得多，像是一家人在漫长的一天后终于坐下来吃晚饭。两首歌一首热闹、一首温暖，恰好对应这部作品的两张面孔。

# 七、观看顺序与入坑建议

TV 动画的播出顺序如下：

1. **第一季第1部分**（2022年4月，12话）——本篇
2. 第一季第2部分（2022年10月，13话，详见[《间谍过家家 第2部分》](/posts/spy-family-2/)）
3. 第二季（2023年10月，12话，详见[《间谍过家家 第二季》](/posts/spy-family-season-2/)）
4. 剧场版《间谍过家家 CODE: White》（2023年12月上映，远藤达哉参与创作的全新故事）
5. 第三季（2025年10月，详见[《间谍过家家 第三季》](/posts/spy-family-season-3/)）

如果你喜欢家庭喜剧、不排斥一点点动作戏，第1部分几乎没有门槛：前两话就把三个人的秘密全部摊开，之后每一话都在“伪装快被拆穿”和“家人越来越像家人”之间来回拉扯。建议一口气看到第12话，再无缝接上第2部分——那里还有一位重要的家庭成员在等着登场。

# 总结：谎言堆起来的真心

《间谍过家家》最聪明的地方，是它从来不让“秘密被拆穿”成为悬念的终点。观众知道所有人的底细，阿尼亚也知道，真正的看点从来不是“他们会不会暴露”，而是**他们会为了守住这个假的家，做出多少真的事**。

劳埃德是为了任务成为父亲的，约尔是为了掩护成为妻子的，阿尼亚是为了不再被抛弃成为女儿的。可当约尔为阿尼亚的躲避球比赛认真示范、当劳埃德为了一颗星星偷偷跳进水里、当阿尼亚为了“父亲的任务”拼命去接近那个讨厌的次子时，你很难再说这一切只是演戏。

**一家人从名字开始就是假的，可他们给彼此的温暖，一点都不假。**
