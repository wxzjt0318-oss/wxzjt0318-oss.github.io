> 无法都市的夜幕下，暗影庭园的少女们各自行动，而希德只想在最帅的时机登场。

说实话，看完第1期的时候我就在想：“误会喜剧”这种东西，能撑多久？观众已经知道希德什么都不懂、七影什么都当真，第二季还能怎么让人笑出来？

![想要成为影之实力者！ 第二季封面](https://lain.bgm.tv/pic/cover/l/86/5a/419846_UWUv4.jpg)
*想要成为影之实力者！ 第二季*

答案是——**把误会玩得更大**。第1期的误会还停留在“希德说了句帅话、七影领悟了深意”；到了第2期，希德的一个“赚零花钱”的念头，直接引发了一场席卷整个城市的金融危机，还让整个暗影庭园以为主人抛弃了她们。这一季，误会从个人层面升级到了组织层面、经济层面，甚至国家层面。

# 一、第2期的基本信息

## 1.1 播出与制作

| 项目 | 内容 |
|------|------|
| **原名** | 陰の実力者になりたくて！ 2nd season |
| **播出时间** | 2023年10月4日起 |
| **话数** | 全12话 |
| **导演** | 中西和也 |
| **系列构成** | 加藤还一 |
| **原作** | 逢泽大介（插画：东西） |

2023年2月22日，第1期刚播完一周，官方就宣布了第2期的制作决定，并在同年10月开播。第2期播完后的2023年12月20日，又宣布了《**剧场版 想要成为影之实力者！ 残响篇**》的制作——可以说，第2期就是通往剧场版的桥梁。

## 1.2 原班声优

主要声优全部续投：希德／暗影的**山下诚一郎**、阿蕾克西雅的**花泽香菜**、萝丝的**白石晴香**、克莱儿的**日高里菜**，以及七影的濑户麻沙美、水濑祈、三森铃子、菲鲁兹·蓝、金元寿子、朝井彩加、近藤玲奈。

这一季新登场或戏份大增的角色中，比较重要的有：

| 角色 | 声优 | 身份 |
|------|------|------|
| 约翰·史密斯 | 福山润 | 希德在无法都市使用的假身份 |
| 拉姆达 | 长谷川育美 | 编号者“11号”，暗影庭园的魔鬼教官 |
| 纽 | 内田真礼 | 编号者“13号”，伽玛直属，负责与希德联络 |
| 凯 | 南真由 | 伊普西龙的直属部下 |
| 欧米加 | 前川凉子 | 伊普西龙的直属部下 |
| 559号／维多莉亚 | 伊藤美来 | 极度崇拜暗影的精灵族成员 |
| 多艾姆·凯兹哈特 | 速水奖 | 萝丝的未婚夫，对国王下药企图控制王国 |

有意思的是，“约翰·史密斯”这个假身份专门请来了**福山润**配音——希德换个面具，连声音都换了，这份“讲究”本身就是一个笑点。

## 1.3 这一季有什么不一样

如果说第1期的舞台主要是米德加尔魔剑士学园和王都，那第2期就是希德的“**出差季**”：无法都市、奥里亚纳王国，一路走一路换身份。约翰·史密斯、钢琴家的弟子、暗影——他几乎每一篇都要换一张面具。

与此同时，暗影庭园本身也变得更立体了。第1期我们认识的主要是七影，第2期则让拉姆达、纽、凯、欧米加、559号这些“七影之下”的成员走到台前。观众这才意识到：原来希德随手救下的那几个女孩，已经发展成了一个层级分明、各司其职的庞大组织——**而组织的“盟主”，依旧以为大家在陪他演戏**。

# 二、篇章解析

> ⚠️ 以下内容包含第2期动画的剧情，未看者请注意。

## 2.1 无法都市篇（第1–3话）

武神祭结束后，希德跟着姐姐克莱儿来到**无法都市**，讨伐吸血鬼始祖“血之女王”——克莱儿想为将来进入骑士团攒些功劳。

希德注意到了血色的月亮，却只把它当成“方便玩中二设定的自然现象”。来到无法都市后，他果不其然和姐姐失散了。这一篇里，第1期“女神的考验篇”登场的欧萝拉，把力量借给了克莱儿——这位“全世界最不了解希德的姐姐”，也开始卷进更大的故事里。

## 2.2 信用战争篇（第4–7话）：一场由零花钱引发的金融危机

这是我心目中第2期最好笑、也最精彩的一篇。

血之女王事件后，无法都市白之塔的主人、妖狐**雪女**找上暗影，提议合作扳倒三越商会和大商会联盟。此时三越商会刚刚发行纸币，大商会联盟也在效法。希德想：三越商会反正已经被盯上了，不如趁机破产重组——于是他化名“**约翰·史密斯**”，提出制作大商会联盟的假钞。

希德的本意，**只是想用假钞赚点零花钱**。雪女却以为他要用假钞同时诱发信用崩盘、搜刮大商会联盟的金币储备，对这份“并不存在的智谋”大为震撼。

接下来，误会像雪崩一样滚下去：

1. 戴尔塔奉阿尔法之命来消灭约翰·史密斯，靠嗅觉认出了他就是暗影。希德知道戴尔塔守不住秘密，于是给她安排了一个“超紧急任务”——去猎杀无法都市黑之塔的头目。结果戴尔塔失联，其他七影都以为她战死了，为她流下眼泪。
2. 希德知道假钞会连累三越商会，就用前世的各种文字写了一封暗号道歉信交给贝塔，顺便告知了金币储藏的位置——但他根本没指望她们能解开。
3. 阿尔法亲自来战约翰·史密斯，通过魔力认出了他。希德拒绝透露目的，说自己放弃了暗影的名字，还说了一句“戴尔塔去了遥远的地方”——**虽然确实没错，但极具误导性**。阿尔法误以为自己和暗影庭园被抛弃了，道心破碎。
4. 最后，是希妲把希德随手写的纸条当作暗号解开，找到了金币，让三越商会撑过了信用破产的危机。七影这才发现——原来一切都是主人的计划。

而希德那边呢？他兴冲冲地来到金币储藏点准备欣赏收获，却发现金币不翼而飞。他以为是大商会联盟的幕后主使月丹拿走了，跑去和对方决斗；月丹弥留之际指向雪女，想把她托付给希德，希德却以为金币埋在那堆雪下面……

**同一场战争，暗影庭园看到的是主人的深谋远虑，雪女看到的是神一般的智谋，而希德看到的只有——我的零花钱没了。**

## 2.3 奥里亚纳王国篇（第9–12话）

希德以为阿尔法她们还在生自己的气，决定趁寒假逃去奥里亚纳王国旅行——顺便忘了要和姐姐一起回老家的约定。

在奥里亚纳，他以暗影的姿态救下了陷入困境的**559号维多莉亚**，得知编号“666”的成员叛逃——可他并不知道666就是萝丝。萝丝因为母妃被多艾姆掌握，被迫要与多艾姆成婚。暗影认为萝丝背叛了“宁可弑父也要成为王”的志向，勃然大怒，决定阻止这场婚事。

接下来是希德最擅长的“变装潜入”：他扮成音乐大师“西蓉”（也就是伊普西龙）的弟子进入王宫。多艾姆想刁难他让他演奏——可西蓉的所有乐曲本来就是希德教的，一曲《**月光奏鸣曲**》让众人神魂颠倒，他还顺手摸走了贵族们的首饰和多艾姆兜里的继承戒指。

后来，萝丝捡到了希德无意中落下的那枚戒指，**误以为那是结婚戒指**——又是一个误会，却也因此坚定了她反抗多艾姆的决心。婚礼上，萝丝公开拒绝多艾姆、戴上戒指，戒指浮现出奥里亚纳国王的遗言，揭穿了多艾姆的恶行。教团十二圆桌之一的莫德雷德随即斩杀多艾姆与王妃，开启“黑蔷薇”想要消灭所有证人。

最终，暗影击败了自黑蔷薇中放出的第四魔界之王与吞食其血肉而变成怪物的莫德雷德。然后——**仅仅因为觉得这样很帅**——他跳进了黑蔷薇之中。贝塔紧随其后，两人被传送回了被魔兽蹂躏成废墟的日本。

这就是剧场版“残响篇”的起点。

# 三、角色看点

## 3.1 阿尔法：第一次“道心破碎”

第2期里最让人心疼的，是阿尔法。她是暗影庭园的实际领导者、文武双全的“全能超人”，平时任何事都能冷静应对——唯独遇到和希德有关的事会动摇。“戴尔塔去了遥远的地方”这一句，让这位最强的七影第一次露出了脆弱的一面。濑户麻沙美的演出，让这段误会在好笑之余，竟然带上了一点悲壮。

## 3.2 萝丝：从公主到666号

萝丝在第1期末为了不让王国落入教团手中而弑父，本想自刎时被暗影所救，之后加入暗影庭园，成为编号“666”的一般成员，和664号、665号同组。第2期，她回到奥里亚纳，面对母亲的背叛和多艾姆的阴谋，最终戴上那枚“误会的戒指”站了出来，后来更成为新的女王，与暗影庭园合作对抗教团。**她是全剧被误会推着走得最远的人**，也是成长最多的人。

## 3.3 编号者们

第2期的片尾曲换成了“编号者”，这群七影之下的成员也有了更多戏份：

- **拉姆达**：古铜色肌肤的精灵，原贝卡达帝国军人，暗影庭园的魔鬼教官，训练时要求回答“Sir! Yes! Sir!”，连阿尔法和伊普西龙都受过她的训练——可被夸衣服可爱时会害羞。
- **纽**：原米德加尔王国的侯爵千金，因恶魔附体被家族除名，是第一位加入暗影庭园的人族恶魔附体者。平时温柔稳重，在敌人面前却极为可怕。
- **凯与欧米加**：伊普西龙的直属部下，一对搭档。

## 3.4 希妲与伊普西龙

信用战争篇里，解开希德“暗号”的是足不出户的天才研究者希妲；奥里亚纳篇里，希德冒充的则是伊普西龙的弟子。两位七影在这一季都有了专属的高光时刻。

# 四、主题曲

## 4.1 片头曲《grayscale dominator》

第2期片头曲依旧由 **OxT** 演唱，hotaru 作词，Tom-H@ck 作曲编曲。第1话用作片尾曲，第8话只使用了开头两句，第12话没有使用。

## 4.2 片尾曲《Polaris in the Night》

延续第1期“每集换人独唱”的传统，第2期片尾曲《**Polaris in the Night**》由暗影庭园的**编号者**演唱：

| 成员 | 独唱话数 |
|------|------|
| 拉姆达（长谷川育美） | 第2、10话 |
| 纽（内田真礼） | 第3、6话 |
| 凯（南真由） | 第4、9话 |
| 欧米加（前川凉子） | 第5、11话 |

从第1期的“Darling in the Night”到第2期的“Polaris in the Night”，“Night”一脉相承，**夜晚始终是暗影庭园的舞台**。

## 4.3 特殊片尾

- 第7话：《Everything is Changing》，前岛麻由演唱；
- 第8话：重新用回第1期的《Darling in the Night》（七影演唱）；
- 第12话：以第1期片头曲《HIGHEST》作结。

最终话用第1期片头曲收尾，像是一次对整个 TV 系列的致敬。

# 总结

第2期的《想要成为影之实力者！》把误会喜剧推上了新的高度：一张假钞、一封没指望被解开的道歉信、一枚随手落下的戒指，就足以掀起金融战争、让最强的部下道心破碎、让一位公主改变命运。而希德自始至终都只想做一件事——在最帅的时机登场。

**他从不知道自己写下了怎样的剧本，但每一场戏，都被他演成了传说。**
