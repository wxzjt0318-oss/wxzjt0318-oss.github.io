> 毕业了也没关系——只要袋子还在，GJ 部随时能把京夜“请”回来。

说实话，《[GJ部](/posts/gj-club/)》第12话结束的时候，我是有点失落的。真央、紫音、绮罗罗三位学姐毕业了，那间吵吵闹闹的社团活动室，好像也就这样画上了句号。所以一年多以后看到特别篇《GJ部@》的消息，心情大概和京夜一样——又被塞进袋子里了，可是一点也不想挣扎。

![GJ部@封面](https://lain.bgm.tv/pic/cover/l/c8/71/90772_N38CA.jpg)
*GJ部@*

《GJ部@》不是第二季，而是一部一小时的特别篇。它讲的是毕业之后：那些已经不在社团里的人，和还留在社团里的人，要怎么继续做“GJ 部”。

# 一、基本信息

## 1.1 播出与发售

| 项目 | 内容 |
|------|------|
| **原名** | GJ部@（读作 Gujjobu Guruguru） |
| **英文名** | GJ Club@ |
| **形式** | TV 特别节目（一小时） |
| **播出** | 2014年5月5日深夜（即5月6日凌晨），BS日本 |
| **影碟发售** | 2014年5月14日，Blu-ray / DVD |
| **本篇时长** | 46分钟 |
| **原作** | 新木伸（小学馆 GAGAGA 文库） |
| **角色原案** | あるや |
| **动画制作** | 动画工房 |

据日文维基百科，TV 动画《GJ部》于2013年1月至3月在日本电视台播出，同年8月，动画官网宣布制作特别篇。中文维基百科补充说，2014年3月21日官方公开了30秒的宣传影片；5月5日深夜在 BS日本以一小时特别节目的形式播出后，5月14日发售的 Blu-ray / DVD 收录了46分钟的本篇和特典影像，还附有新写的特典小说。

这篇特典小说后来也有了归宿：2015年7月发售的《GJ部 Weekly》收录了《读卖中高生新闻》上连载的新作，以及动画影碟特典里的四格漫画和小说《GJ部@》。

除了 GJ 部的六个人，京夜的妹妹霞、绮罗罗的妹妹杰拉丁、真央和惠的妹妹圣罗这几位“妹妹组”也都登场了——她们正是原作续篇《GJ部中等部》的主角。

## 1.4 再认识一下 GJ 部

- **四之宫京夜**：悠闲自在的和平主义者，总因为说话不合时宜被部员们调戏；泡的茶很难喝，却很擅长给女生梳头。
- **天使真央**：个子小小的部长，一不顺心就咬京夜，却连有接吻场面的漫画都不敢看，兴趣是收集蝉壳。
- **皇紫音**：公认的天才，成熟得像个大人，却缺乏常识，还很想要一个妹妹。
- **天使惠**：真央的妹妹，温柔有礼、心胸开阔——但千万别惹火她，尤其别提体重。
- **绮罗罗·伯恩斯坦**：身高180cm，手里永远拿着肉，有时会和猫说话。
- **神无月环**：第5卷后加入的新部员，家里是神社，被“俺超人”状态的京夜错叫成“狸猫”。

# 二、剧情看点

> ⚠️ 以下内容涉及特别篇剧情。

## 2.1 一趟迟来的毕业旅行

真央她们毕业后的春假，樱花开了，新学期眼看就要开始。京夜像以前一样，突然被塞进袋子里“绑架”了。等他从袋子里出来，看到的是一间和 GJ 部活动室一模一样的房间——可窗外的风景，居然是纽约。

据 Anime News Network 的简介，这一次大家把京夜“抓”来，是为了和已经毕业的三位学姐一起，补上一趟迟到的毕业旅行。熟悉的房间，陌生的城市，**GJ 部把自己的活动室原样搬到了地球另一边**——这种不讲道理的大手笔，很有这个社团的风格。

## 2.2 毕业之后的小别扭

回到日本后，京夜发现，毕业以后真央和自己之间好像有哪里不太对劲。于是其他部员们想了一个办法来帮忙，也借此重新确认了 GJ 部的精神和它的未来。

这一段是我最喜欢的地方。TV 版的真央总是一不顺心就去咬京夜，可人一旦不在同一个社团里了，那种每天理所当然的相处就没有了。**毕业带走的不是人，是“理所当然”**——而 GJ 部的做法，就是想办法把它找回来。

## 2.3 “下一代”的 GJ 部

TV 版后半加入的新部员神无月环，这次也加入了合唱：片尾曲《広がれパワー》（扩散吧力量）由真央、紫音、惠、绮罗罗和环五人合唱，比 TV 版第7–12话的四人片尾曲《走りだそう!》（跑起来吧！）多了一个声音。《走りだそう!》则在特别篇里作为插入曲回归。两首歌的词曲编曲都出自山田高弘之手。

从“四个人”到“五个人”，再加上一群“妹妹组”的登场——特别篇标题里的“@”读作 Guruguru（转啊转），大概也是在说：社团里的人会毕业、会换代，可 GJ 部会一圈一圈地转下去。

# 三、观看顺序与建议

1. TV 动画《[GJ部](/posts/gj-club/)》（2013年1月，全12话）
2. **特别篇《GJ部@》**（2014年5月）——本篇

一定要先看完 TV 版再看特别篇：它的笑点和感动，几乎都建立在“毕业”这件事上。没看过第12话就看《GJ部@》，就像没参加毕业典礼就去参加同学会。

喜欢这个世界的话，还可以去读原作：《GJ部》本篇全9卷另有特别篇2卷，续篇《GJ部中等部》讲的就是霞她们这些“妹妹组”的故事。

---

# 总结：毕业了，也还是 GJ 部

《GJ部@》只有一小时，却给 TV 版补上了最温柔的一笔：毕业不是社团的终点，只是换了一种在一起的方式。

去纽约也好，回到那间活动室也好，只要大家还愿意把京夜塞进袋子里，GJ 部就永远不会解散。

**Good Job，GJ 部——毕业以后也请多指教。**
