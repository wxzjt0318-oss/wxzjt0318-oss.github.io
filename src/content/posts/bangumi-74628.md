> 为了避免黑帮火并，他必须和最讨厌的转学生假扮情侣——可他心里，明明一直装着另一个女孩。

说实话，《伪恋》是我心里"后宫恋爱喜剧"最标准的样子：一个普通（其实是黑帮少主）的男主角，一个凶巴巴的假女友，一个温柔的真暗恋对象，再加上一把十年前的锁和好几把钥匙。开局设定一摆出来，你就知道这一定是个"选谁"的故事——而整部作品最大的乐趣，恰恰就在于看你自己"站哪一队"。

![伪恋封面](https://lain.bgm.tv/pic/cover/l/98/71/74628_8HHlL.jpg)
*伪恋*

但如果你以为它只是一部卖女主的作品，那就小看它了。"假装的恋爱"能不能变成真的？"十年前的约定"和"现在的心意"哪个更重要？这两个问题，伪恋用了整整二十多卷来回答。

# 一、作者古味直志：从《Double Arts》到《伪恋》

## 1.1 第一部连载的遗憾

《伪恋》的作者**古味直志**，在《伪恋》之前曾在《周刊少年 Jump》连载过奇幻漫画《**Double Arts**》。这部作品画风细腻、人物可爱，可惜在竞争激烈的 Jump 里没能撑下去，很快就完结了。

但《Double Arts》里已经能看到古味直志的特长：**女孩子画得特别好看，男女主之间的互动特别有化学反应**。这也为后来《伪恋》的成功埋下了伏笔。

## 1.2 《伪恋》的诞生与连载

《伪恋》最初是以读切（短篇）的形式在 Jump 系列杂志上刊载，反响很好，随后在《**周刊少年 Jump**》正式开始连载，最终连载了五年左右、完结时单行本共 **25 卷**。在一本以战斗漫画为主的杂志里，一部纯恋爱喜剧能连载这么久、人气这么高，本身就是一件很了不起的事。

## 1.3 衍生作品

| 类型 | 内容 |
|------|------|
| **电视动画** | 第一季（2014年1月，全20话）、第二季《伪恋：》（2015年） |
| **OAD** | 随单行本特装版附赠 |
| **外传漫画** | 《魔法甜点师小咲!!》，由筒井大志作画 |
| **真人电影** | 2018年上映的真人版电影 |
| **小说、游戏** | 多部轻小说改编与游戏 |

这里有个有意思的细节：外传《魔法甜点师小咲!!》的作画**筒井大志**，后来自己在 Jump 上连载了另一部恋爱喜剧——《**我们真的学不来**》（本站也有介绍，详见[《我们真的学不来》](/posts/we-never-learn/)）。可以说，《伪恋》直接"培养"出了下一代 Jump 恋爱喜剧作者。

# 二、原作基本信息与故事梗概

## 2.1 基本信息

| 项目 | 内容 |
|------|------|
| **原名** | ニセコイ |
| **英文名** | Nisekoi: False Love |
| **作者** | 古味直志 |
| **连载杂志** | 《周刊少年 Jump》（集英社） |
| **单行本** | 全25卷 |
| **类型** | 恋爱喜剧、后宫 |

## 2.2 故事梗概：一把锁与一场假恋爱

**一条乐**是黑帮"集英组"的唯一继承人，可他自己最大的梦想是当一个普通的公务员。他就读凡矢理高中二年C班，偷偷暗恋着同班的**小野寺小咲**。

乐的脖子上一直挂着一把小小的**锁形吊坠**——十年前，他和一个女孩约定："**总有一天，我们要再见面，然后结婚**。"女孩拿着能打开这把锁的钥匙，可乐已经完全不记得她的名字和长相了。

某天，班上转来了一位金发碧眼的美国混血美少女**桐崎千棘**。两人第一次见面，千棘就一个飞膝把乐踢飞，从此结下了梁子。

没想到当晚，乐被父亲告知：集英组和美国黑帮"**蜂巢**"正处于一触即发的火并边缘，为了避免战争，**两个帮派的继承人必须假扮成恋人**——而蜂巢老大的女儿，正是那个踢了他的千棘。

于是，两个互相看不顺眼的人，开始在全校、在两大帮派面前扮演一对"恩爱情侣"。而乐不知道的是，他暗恋的小咲手里，也有一把钥匙……

## 2.3 核心设定："十年前的约定"之谜

伪恋最大的悬念，是"**十年前和乐约定的女孩到底是谁**"：

- 乐手里有一把锁，约定的女孩有钥匙
- 千棘、小咲，后来还有万里花，都拥有一把钥匙，也都隐约记得十年前的某个夏天
- 每把钥匙都像"可能打开那把锁"，却又总差那么一点

这个设定很聪明：它让每个女主角都和乐有着"命中注定"的可能性，也让读者一直在猜。而到最后你会发现，作品真正想说的是——**比起十年前的约定，现在的心意更重要**。

# 三、动画版：SHAFT 风格的恋爱喜剧

## 3.1 制作信息

| 项目 | 内容 |
|------|------|
| **动画制作** | SHAFT |
| **监督** | 龙轮直征 |
| **系列构成** | 东冨耶子、新房昭之 |
| **人物设定** | 杉山延宽 |
| **音乐** | 千叶"naotyu-"直树、石滨翔（第1–6话）→ 菊谷知树（第7–20话） |
| **播出时间** | 2014年1月 |
| **话数** | 全20话 |

《伪恋》由 **SHAFT** 制作，一看就能认出那股"新房昭之味"：大量的歪头杀、色块分割画面、夸张的转场、文字闪现……这种风格放在恋爱喜剧里，意外地很合适——它把千棘和乐吵架时的"火花"、小咲害羞时的"冒泡泡"都放大了好几倍。

## 3.2 主要角色配音演员

### 桐崎千棘 CV：东山奈央

千棘是那种"嘴巴比拳头还快"的女主角：凶、直、容易炸毛，可一旦害羞起来比谁都可爱。东山奈央把千棘的"大小姐脾气"和"笨拙的温柔"拿捏得很到位，尤其是那种吵架吵到一半突然意识到自己脸红了的瞬间，声音里的慌乱特别真实。

### 小野寺小咲 CV：花泽香菜

小咲是"温柔内向的初恋"模板，说话轻声细语，一紧张就结巴。花泽香菜的声音简直就是为小咲量身定做的——那种软软的、带点气声的语调，让人一听就想保护她。很多观众"站小咲"，有一半是被花泽香菜的声音征服的。

### 一条乐 CV：内山昂辉

乐是个吐槽役兼"老好人"：明明是黑帮少主，却比谁都普通；明明一直在被女孩子们折腾，却总是先替别人着想。内山昂辉的声音偏低沉温和，吐槽的时候有种"累了但还在坚持"的无奈感，非常有喜感。

### 其他重要角色

| 角色 | 声优 | 简介 |
|------|------|------|
| **鸫诚士郎** | 小松未可子 | 蜂巢的王牌杀手，千棘的贴身保镖，男装少女 |
| **橘万里花** | 阿澄佳奈 | 警视总监的千金，自称是乐的未婚妻 |

# 四、第一季剧情梳理

> ⚠️ **以下内容包含动画第一季剧透。**

## 4.1 第一阶段：假情侣成立

开学风波、帮派危机、被迫"交往"——第一季前几话以极快的节奏把核心设定全部摆了出来。乐和千棘在全校面前扮演情侣，私下却天天吵架；而乐更在意的，是这场假恋爱会不会让小咲误会。

最有意思的是，**两大帮派的手下们会时不时冒出来"监视"这对情侣**，乐和千棘不得不在各种尴尬场合里秀恩爱，喜剧效果拉满。

## 4.2 第二阶段：钥匙越来越多

乐偶然得知小咲也有一把钥匙，心里燃起希望；可千棘那边，似乎也和十年前的约定有关。就在乐以为谜底即将揭开的时候，钥匙总会因为各种意外"打不开锁"。

与此同时，**鸫诚士郎**登场——这位一直以男装示人的蜂巢杀手，奉命监视乐、保护千棘，后来却在乐面前露出了女孩子的一面。紧接着，自称是乐"未婚妻"的**橘万里花**也转学过来，手里同样握着一把钥匙。乐身边，越来越热闹了。

## 4.3 第三阶段：假的越来越像真的

随着一起经历林间学校、暑假、各种节日活动，乐和千棘之间的"假恋爱"开始变味。千棘会因为乐和小咲走得近而闹别扭，乐也会在千棘难过的时候不由自主地陪在她身边。**两个人都还嘴硬，可观众已经看出来了**。

第一季在这种"谁都没有说破"的状态中结束，把更多的心动与纠结留给了第二季。

# 五、主要人物深度介绍

## 5.1 一条乐：想当公务员的黑帮少主

### 基本档案

| 项目 | 内容 |
|------|------|
| **身份** | 集英组二代目继承人，凡矢理高中二年C班 |
| **生日** | 12月20日 |
| **梦想** | 成为普通的公务员 |
| **CV** | 内山昂辉 |

乐的设定本身就是一个反差：生在黑帮，却只想过普通人的生活。他做饭好、成绩不错、对人温柔，最大的缺点是**太在乎别人的感受，以至于常常不知道自己真正想要什么**。

他一直以为自己喜欢的是小咲，也一直以为"十年前的约定"能给他答案。可整部作品的成长，正是他慢慢学会：**答案不在锁和钥匙里，而在自己心里**。

## 5.2 桐崎千棘：不坦率的大小姐

### 基本档案

| 项目 | 内容 |
|------|------|
| **身份** | 美国黑帮"蜂巢"老大之女，日美混血 |
| **生日** | 6月7日 |
| **特点** | 金发碧眼、运动神经超群、成绩优秀 |
| **CV** | 东山奈央 |

千棘是全作情绪起伏最大的角色。她一开始是真的讨厌乐，可在一次次"假装恋爱"的过程中，她开始真的在意他。她的可爱在于"**明明喜欢却死不承认**"——又凶又别扭，偶尔露出的那一点真心，反而格外动人。

## 5.3 小野寺小咲：最温柔的初恋

### 基本档案

| 项目 | 内容 |
|------|------|
| **身份** | 和果子店"恩寿庵"的女儿，凡矢理高中二年C班 |
| **生日** | 6月15日 |
| **特点** | 温柔内向、厨艺"致命" |
| **CV** | 花泽香菜 |

小咲和乐其实是**双向暗恋**——她从初中开始就喜欢乐，却因为性格内向一直不敢说。她最让人心疼的地方在于：明明喜欢的人就在眼前，却眼睁睁看着他和别人"交往"。

## 5.4 鸫诚士郎：杀手少女

蜂巢的王牌杀手，从小和千棘一起长大，对千棘忠心耿耿。她一直以男装示人，连乐一开始都以为她是男生。随着剧情发展，她对乐产生了连自己都搞不懂的心情，那种"一个杀手第一次心动"的手足无措，非常可爱。

## 5.5 橘万里花：直球未婚妻

警视总监的女儿，自称是乐的未婚妻，手里同样有一把钥匙。她和其他女主角最大的不同是**直球**：喜欢就说、想要就抢，毫不掩饰。可在这份直球背后，是她从小体弱多病、一直把"和乐重逢"当作活下去的动力的过去。

# 六、名场面与看点

## 6.1 "飞膝"初遇

千棘和乐的第一次见面，是千棘翻墙时一个飞膝把乐踢飞。这个"最糟糕的初遇"，几乎定下了两人之后所有互动的基调。

## 6.2 帮派监视下的"恩爱"

两大帮派的手下随时可能冒出来，乐和千棘只好在各种场合硬着头皮秀恩爱——牵手、喂饭、约会，每一次都尬得脚趾抠地，也每一次都让两个人离真心更近一步。

## 6.3 钥匙打不开锁

每当剧情走到"这把钥匙会不会打开锁"的关键时刻，总会有意外发生。这个"梗"被用了很多次，但每次都能让观众又气又好笑。

## 6.4 小咲的每一次欲言又止

小咲好几次差点就要说出口了，却总是被打断。这些"差一点"的瞬间，是很多小咲党心中最痛的回忆。

# 七、原作的后续走向（轻剧透）

动画两季加起来只改编了原作的前中段，而原作漫画后半部分，才是《伪恋》真正"见分晓"的地方：

- **更多的钥匙与更多的女主角**：后续登场的角色让"十年前的约定"变得更加扑朔迷离，几乎每个女主角都和那个夏天有关
- **约定之谜的真相**：古味直志在后期逐步揭开了十年前那个夏天发生的事——那不是一个女孩的约定，而是一群孩子共同的回忆
- **乐的最终选择**：作品最终给出了明确的结局，乐面对自己的心意做出了选择。无论你站哪一队，这个结局都值得你亲自去看

我不打算在这里说出最终选的是谁——这大概是伪恋粉丝之间争论最多、也最有意思的话题。但我可以说的是：**结局并不是由"钥匙"决定的，而是由"心意"决定的**。这一点，和作品开头的设定形成了一个很漂亮的呼应。

# 八、伪恋在 Jump 恋爱喜剧里的位置

## 8.1 承前启后的一部作品

在《伪恋》之前，Jump 的恋爱喜剧代表作有《草莓100%》《To LOVE-Ru》等；在《伪恋》之后，又出现了《我们真的学不来》《超超超超超喜欢你的100个女朋友》等新作品。《伪恋》恰好处在中间：它继承了"多女主竞争"的传统，又用"锁与钥匙"的悬念，给后宫恋爱喜剧加上了一条清晰的主线。

## 8.2 "选谁"的乐趣

和很多"永远不选"的后宫作品不同，《伪恋》从一开始就埋下了"总有一天要做出选择"的伏笔。这种"一定会有结局"的确定感，让读者愿意认真地站队、认真地讨论——也让结局公布时的讨论热度格外高。

# 九、入坑建议

## 9.1 动画还是漫画？

- **只想轻松看看**：动画第一季 + 第二季，SHAFT 的风格非常适合恋爱喜剧，笑点很密
- **想知道结局**：一定要读原作漫画，动画没有讲到最后
- **两者都想要**：先看动画熟悉角色，再从动画结束的位置接着读漫画

## 9.2 看完还可以看什么？

- 《**我们真的学不来**》：《伪恋》外传作画者筒井大志的作品，同样是"多女主 + 明确结局"的 Jump 恋爱喜剧
- 《**辉夜大小姐想让我告白**》：如果你喜欢千棘和乐那种"谁都不肯先承认"的拉扯，辉夜和白银的恋爱头脑战会让你笑到停不下来
- 《**龙与虎**》：同样是"凶巴巴的女主 + 温柔的男主"，但更偏向青春群像和情感深度

# 十、第二季与 OAD

第一季之后，动画在2015年推出了第二季《**伪恋：**》，进一步展开了千棘、小咲、鸫、万里花之间的感情，并加入了新角色。此外，还有随单行本特装版发售的 **OAD**，讲述正篇之外的日常小故事（详见[《伪恋 OAD》](/posts/nisekoi-oad/)）。

动画只覆盖了原作的前中段内容，**"十年前的约定"的最终谜底与乐的最终选择，需要去读原作漫画**。

---

# 十一、总结：假的恋爱，真的心意

《伪恋》第一季，讲的是一场被迫开始的"假恋爱"，和一把十年前的锁。它的节奏轻快、笑点密集、女主角个个可爱，是一部非常适合放松看的恋爱喜剧。

但在那些吵吵闹闹的日常下面，它其实一直在问一个问题：**比起命中注定的约定，你现在喜欢的人是谁？**

如果你还没看过，推荐从动画第一季开始；如果你已经站好了队——那么，原作漫画的结局，你准备好了吗？
