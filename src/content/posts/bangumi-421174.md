> 离开了魔物之国的利姆路，在另一个国家遇见了需要守护的新面孔——这是一段番外里的温柔冒险。

说实话，第二季播完到第三季开播之间那将近三年，是史莱姆粉丝最难熬的一段时间。剧场版《红莲之绊篇》上映过了，外传日记也看完了，正篇却迟迟不来——就在这时候，官方悄悄端上了一盘“小点心”：《柯里乌斯之梦》。

![关于我转生变成史莱姆这档事 柯里乌斯之梦封面](https://lain.bgm.tv/pic/cover/l/fc/78/421174_nlx3z.jpg)
*关于我转生变成史莱姆这档事 柯里乌斯之梦*

它只有3话，不讲世界大战，也不讲魔王之争。但正因为没有那么多沉重的东西，它反而让人想起了史莱姆最初吸引我们的样子：一群可爱的伙伴，一位好脾气的史莱姆，和一段轻松的冒险。

# 一、作品的来历

## 1.1 从蓝光特典到网络动画

《柯里乌斯之梦》（日语：転生したらスライムだった件 コリウスの夢）最初并不是为动画而写的——它是**TV 动画第二季蓝光附赠的短篇小说**，原本只有购买蓝光的观众才能读到。

2023年11月1日，这篇短篇被改编成动画，以**全3话**的网络动画形式配信。对于没有买蓝光的观众来说，这算是第一次正式接触到这个故事。

## 1.2 基本信息

| 项目 | 内容 |
|------|------|
| **原名** | 転生したらスライムだった件 コリウスの夢 |
| **形式** | 网络动画 |
| **配信时间** | 2023年11月1日 |
| **话数** | 全3话 |
| **原作** | 第二季动画 BD 附赠短篇小说 |
| **监督** | 中山敦史 |
| **音乐** | 藤间仁 |
| **人物设定** | 江畑谅真 |

监督中山敦史、人物设定江畑谅真都是第二季的原班人马，音乐则由此前为剧场版《红莲之绊篇》作曲、之后又负责第三季配乐的**藤间仁**担任。所以在时间线上，《柯里乌斯之梦》正好夹在第二季和第三季之间，制作阵容也像是两季之间的一座桥。

---

# 二、主题曲：利姆路亲自开唱

## 2.1 片头曲《ヒカリハナツ》

片头曲《**ヒカリハナツ**》（绽放光芒）由**寺岛拓笃**作词并演唱，作曲、编曲是 Arte Refact 的酒井拓也。寺岛拓笃从第一季的《Nameless Story》《メグルモノ》，到第二季的《Reincarnate》，几乎是史莱姆动画的“御用歌手”，由他来唱番外的片头曲再合适不过。

## 2.2 片尾曲《ココロトラベル》

片尾曲《**ココロトラベル**》（心之旅行）由利姆路的声优**冈咲美保**亲自演唱，作词、作曲、编曲是永冢健登。

这首歌是我觉得这部番外最值得一提的地方。冈咲美保凭借利姆路一角受到关注，并在2020年获得了声优奖新人女优赏。在正篇里，利姆路的声音要么在吐槽、要么在作战；而在这首片尾曲里，我们第一次听到“利姆路”用唱歌的方式，轻轻地说着一段旅行的心情。歌名里的“旅行”，大概也正是这部番外的气质。

# 三、登场角色

> ⚠️ 本作为番外短篇，以下只介绍登场角色，不展开具体情节。

## 3.1 利姆路与大贤者

主角依旧是**利姆路·坦派斯特**（CV：冈咲美保）。陪在他身边的，是只有他能听到声音的独特技能**大贤者**（CV：丰口めぐみ）。在正篇里，大贤者常常是“冷静的解说员”，偶尔还会多嘴解说一些多余的事情；在番外这种轻松的氛围里，这一对“主仆”之间的互动反而更有趣。

## 3.2 红丸

**红丸**（CV：古川慎）是大鬼族的少主、朱菜的哥哥，被利姆路命名后进化为鬼人。他作战时主要使用火焰和日本刀，为人勇敢慷慨，深受部下爱戴，同时也因为帅气的外表很受女性欢迎——顺带一提，他还是个甜食控。

## 3.3 苍影

**苍影**（CV：江口拓也）是红丸多年的挚友兼对手，同样是大鬼族幸存者之一。在魔国联邦，他率领着以间谍活动为主的密探集团“蓝暗众”。一个统领大军、一个潜伏暗处，这对老友在魔国联邦里正好一明一暗。

## 3.4 岚牙

**岚牙**（CV：小林亲弘）是利姆路身边最早的伙伴之一。他原本是牙狼族，被利姆路取名后进化成岚牙狼族，在与猪头帝一战中又进化为能操纵龙卷、黑雷的“黑岚星狼”。在原作后来的设定里，他还会成为“圣魔十二守护王”之一的“星狼王”。

这几位在正篇里都是要扛起军团的大人物，但在番外里，他们更像是陪利姆路出门的一群老朋友。

# 四、在系列中的位置

## 4.1 观看顺序

1. TV 动画第一季（2018年10月）
2. TV 动画第二季第1部分（2021年1月，详见[《关于我转生变成史莱姆这档事 第二季》](/posts/that-time-i-got-reincarnated-as-a-slime-season-2/)）
3. TV 动画第二季第2部分（2021年7月，详见[《关于我转生变成史莱姆这档事 第二季 第2部分》](/posts/that-time-i-got-reincarnated-as-a-slime-season-2-part-2/)）
4. 剧场版《红莲之绊篇》（2022年11月）
5. **网络动画《柯里乌斯之梦》**（2023年11月）——本篇
6. TV 动画第三季（2024年4月，详见[《关于我转生变成史莱姆这档事 第三季》](/posts/that-time-i-got-reincarnated-as-a-slime-season-3/)）

## 4.2 史莱姆的番外传统

史莱姆动画一直很擅长做番外：第一季有收录于漫画特装版的 OAD《外传：M的悲剧？》和《外传：HEY！尻！》，还有原作者伏濑原案的三部 OAD；正篇之间又穿插着《维鲁多拉日记》《迪亚波罗日记》这样的角色日记总集篇。《柯里乌斯之梦》延续的正是这种传统：**在正篇的宏大叙事之外，留一点空间给角色们“过日子”**。

## 4.3 入坑建议

这部番外**不建议作为入坑作**——它默认你已经认识红丸、苍影、岚牙这些角色，也了解魔国联邦的来龙去脉。最好的观看时机，是看完第二季、在等第三季的时候；或者在第三季开播前，当作一次轻松的“热身”。

---

# 总结：一个温柔的梦

《柯里乌斯之梦》不是那种会让你热血沸腾的作品。它短，它轻，它没有改变世界的大事件。

但它让我想起，自己当初为什么会喜欢上这只史莱姆——不是因为他有多强，而是因为跟着他，总能看到一群伙伴开开心心地过日子。

**在漫长的等待里，做一个温柔的梦，也挺好的。**
