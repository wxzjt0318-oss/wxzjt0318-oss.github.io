> 存在感为零的少年，只有她能一眼找到——久保同学的捉弄，是他平凡日常里最亮的光。

说实话，第一次看《久保同学不放过我》的时候，我以为这又是一部“美少女捉弄男主”的恋爱喜剧——毕竟这几年这一类作品实在太多了。可看着看着，我发现它真正打动我的，不是久保同学的捉弄，而是一件更简单的事：**有一个人，能一眼看见你。**

![久保同学不放过我封面](https://lain.bgm.tv/pic/cover/l/12/39/381793_oNshs.jpg)
*久保同学不放过我*

白石纯太是那种走在路上没人会注意、坐在座位上会被人坐到身上的男生。存在感低到连母亲都可能注意不到他。而久保渚咲，全班最耀眼的“女主角级”美少女，却总是能轻易找到他、主动跟他搭话。这部作品讲的，就是一个“看不见的人”被“看见”之后的故事。

# 一、作者与原作

## 1.1 基本信息

| 项目 | 内容 |
|------|------|
| **原名** | 久保さんは僕（モブ）を許さない |
| **作者** | 雪森宁宁（雪森寧々） |
| **连载杂志** | 集英社《周刊Young Jump》 |
| **连载时间** | 2019年47号（2019年10月24日发售）至2023年14号（2023年3月2日发售） |
| **话数** | 全144话 |
| **同步连载** | 2020年8月12日起于《少年Jump+》同步连载 |
| **中文版** | 繁中：东立出版社；简中电子版：哔哩哔哩漫画 |

标题里那个读作“モブ”（路人）的“僕”，就是这部作品的全部设定：**我是一个路人，而久保同学不放过我。**

## 1.2 成绩

| 时间 | 成绩 |
|------|------|
| 2020年 | 下一部人气漫画大赏（纸本漫画部门）第19名 |
| 2021年 | 下一部人气漫画大赏（纸本漫画部门）第7名 |
| 2021年2月 | 单行本累计发行逾40万册 |
| 2021年6月 | 累计发行逾80万册 |
| 2021年9月 | 累计发行逾100万册 |

短短七个月，发行量从40万册涨到了100万册。连载期间，《周刊Young Jump》官方YouTube频道还在2020年2月公开过一段由花泽香菜为久保配音的ASMR影片——那时候动画还没有官宣，但久保同学的声音，已经提前确定了。

连载完结后，集英社还推出了完结纪念公式书《GIFT〜久保さんは僕を許さない 完結記念公式ファンブック〜》。

有个小八卦：漫画连载初期，久保同学的造型因为和乃木坂46的三期生久保史绪里相似，在一部分粉丝间引起了话题。

# 二、剧情简介：唯一能找到他的人

春贺北高中一年级生**白石纯太**，是个存在感薄弱到不可思议的男生。别人要连续确认五次才能发现他；不做出大动作，就完全不会被人看到；开学一年，班上九成的同学都表示没见过他。“看到白石”甚至成了一种幸运的象征。

他每节课结束都会上去问老师问题——其实是为了证明自己没翘课。初中毕业时他拿了全勤奖，所有人都很惊讶：“原来他一直在啊！”

可是，同班的**久保渚咲**却能轻易找到他。她是才貌兼备、成绩全校前三的“女主角级”美少女，也是第一个主动和白石搭话的人。她喜欢捉弄白石，喜欢看白石被捉弄后的反应，还总能看穿白石的心思——似乎总是“不放过”他。

这就是故事的全部：一个路人，和一个总能看见他的女孩，在校园里度过的平凡日常。

## 3.2 一波三折的播出

这部动画的播出过程有点坎坷。2022年5月13日官宣动画化，男女主角的声优同时公布；8月宣布2023年首播，9月定档1月，并公布了明菜和沙贵的声优。

可开播没多久，2023年1月24日，制作委员会就宣布：**受新冠疫情影响，第7话及之后的话数延期播出**。节目按原定日程播到第6话为止，之后从4月4日起，从第1话开始重新播放完整集数。所以这部作品的播出期，从1月一直延续到了6月20日。

## 3.3 主题曲

| 类型 | 曲名 | 演唱 |
|------|------|------|
| 片头曲 | 《ドラマチックじゃなくても》（即使不够戏剧化） | 花泽香菜 |
| 片尾曲 | 《かすかでたしか》（微弱却真切） | DIALOGUE+ |
| 插入曲 | 《ふたりに祝福を》（向两人献上祝福，第5话） | 矢野水音 |

片头曲由久保同学的声优花泽香菜亲自演唱；片尾曲由DIALOGUE+演唱，田渊智也作词作曲。有一个很温柔的小设计：**第12话里，片头曲和片尾曲互换了位置**——片头曲当片尾曲用，片尾曲当片头曲用。

我特别喜欢这两首歌的标题。“即使不够戏剧化”，说的是这部作品的日常——没有惊天动地的事件，只有教室里的小打小闹；“微弱却真切”，说的就是白石本人——存在感微弱，可他确确实实地在那里，而久保同学，确确实实地看见了他。

# 四、名场面与日常

> ⚠️ 以下内容包含原作漫画的部分情节。

这部作品没有贯穿始终的大事件，它的魅力全在一个个小小的日常里。原作中有不少让人印象深刻的片段：

- **课堂上的“社会性死亡”**：在久保同学的怂恿下，白石在课堂上偷偷在椅子上做各种动作，最后被老师发现——可怜的路人第一次被全班“看见”，竟是以这种方式。
- **书店的误会**：白石去买漫画时，看到被客人弄乱的书，想摆整齐时顺便“偷看一眼”，结果被在书店打工的久保姐姐明菜撞见。明菜误以为白石是个“绅士”，还捡到了他掉的学生证，让妹妹送到学校还给他。
- **泥水与洗澡**：一次白石被泥水溅了一身，久保同学让他去自己家洗澡。
- **间接接吻**：白石带弟弟诚太出去玩，诚太喝了久保同学的饮料，又“盛情邀请”哥哥下一个喝——精明能干的好弟弟。
- **黑暗物质与曲奇**：情人节前，久保同学亲手做了巧克力，被姐姐吐槽是“黑暗物质”；后来在姐姐的帮助下，她把做得最好看的曲奇送给了白石。
- **特别篇的礼物**：久保同学送给白石一件印着荧光字“主人公”的T恤，白石回礼了一副手套。

我最喜欢的是那件“主人公”T恤。一个总被当作路人的男生，被一个女孩郑重其事地告诉：**你是主人公。**这大概就是整部作品最想说的话。

# 五、角色深度解析

## 5.1 白石纯太：已经放弃了的路人

白石对自己的存在感低“没什么意见”，已经放弃了改变现状。因为没存在感，班委选举时他只能捡剩下的，担任大家都觉得无聊的环境委员。由于几乎没有和他人交流的机会，一旦被人搭话，他的行为就会变得可疑起来。

可这部作品一点一点地告诉我们：他不是“没有存在感”，他只是**没有被看见**。他很细心，会注意到一些小细节；因为弟弟诚太常摔跤，他随身带着创可贴；他侧脸很帅、笑容灿烂，学动漫人物变身时也很酷。原作里，他在和久保同学玩心理测试时得到了“只会和一人交往”的结果——这个结果，后来也确实应验了。

能一眼找到他的人，只有弟弟诚太和久保家全体成员（不包括婶婶）。白石因此还感叹过“DNA的强大”。

## 5.2 久保渚咲：小恶魔之下的认真

久保同学平时是小恶魔系，喜欢捉弄白石；可她其实也会害羞，害羞的时候会在床上打滚。她喜欢兔子，笔袋、拖鞋上都是兔子；喜欢甜食，尤其是蛋糕和曲奇；害怕鬼，不敢一个人去黑的地方，害怕时会哭，被摸摸头就好了。

她没有恋爱经验，一开始也不确定自己对白石的感情是什么。后来，她向好友平玉绪和工藤叶月坦白了“喜欢白石”。维基百科记下了她说的理由：白石存在感低很有趣；走路时会放慢速度等她；**哪怕没有人注意，也会努力做到最好**，这一点很让她佩服；他平时很温柔、特别可靠，和他在一起总是很开心，他的笑容也让她心动。

我觉得这段话就是整部作品的“题眼”。久保同学喜欢白石，不是因为他特别，而是因为她看见了别人看不见的那些“普通的好”。

她的成绩也很优秀：初登场是年级第三，一年级期末拿了年级第二，后来拿到了年级第一。

## 5.3 久保家的姐妹们

- **久保明菜**：渚咲的姐姐，在书店打工，也有洞察人心的本领，心机小恶魔系，得逞后会大笑。几乎什么都会，是渚咲憧憬的对象；她最早察觉到了妹妹对白石的感情。不能喝酒，赏花时喝醉后对白石过于亲密，回家就被妹妹训了一顿。
- **久保沙贵**：渚咲的堂妹，长得很像初中时的渚咲，叫她“小渚”。她认为渚咲应该和王子一样的人交往，所以很在意白石和渚咲的关系，还会为此吃醋。年纪虽小却很稳重，饭也做得很好。

## 5.4 朋友们

- **工藤叶月**：渚咲的青梅竹马兼同班同学，带点成熟气质，能冷静判断事物，在三人组里担当吐槽役，能隐藏自己的表情。
- **平玉绪（小玉）**：性格开朗、天真烂漫，“大脑和嘴直接相连”，在三人组里担当傻瓜角色，成绩很差，最高分是得到同学辅导后的47分。
- **须藤勇真**：小玉的青梅竹马，一年级时和白石同为环境委员、一起管理花坛，一直想和白石交流，结果花了一年都没找到他。表面上像个老司机，其实完全不会应付女生——可白石不知道，还常问他怎么和久保同学相处。
- **云仙老师**：身高奇矮、地中海秃，不知为何一直努力想拍到白石的照片。

# 六、原作的结局

> ⚠️ 以下内容包含原作漫画结局的重大剧透。

动画只讲到了故事的前半段，而原作漫画早已在2023年3月完结。

升上高二后，久保同学开始着手帮助白石建立正常的人际关系；她还设计让两人一起当上了环境委员，结果传出了“白石是冲着久保同学才选环境委员”的流言。学园祭期间，久保同学拒绝了另一个男生的邀请，“久保渚咲有喜欢的人”的消息传开——白石听到了，却因为太自卑，根本没往自己身上想，反而稍微冷落了她。

白石向须藤请教，得到了一句“等到喜欢得忍不了就去告白吧”。原作第140话，他终于准备好告白，却被须藤、小玉和叶月打断；他告诉须藤“刚刚其实想表白”，偏偏被身后的久保同学听到了……

修学旅行前，两人约定自由行动时一起游览，在京都得到了一对老夫妇的帮助，拍下了合照。告白前夕，明菜和沙贵得知了白石的计划，确认了他的心意之后，给了他祝福。

**修学旅行结束后，白石在教室里向久保同学告白，成功了。**他也终于明白，原来久保同学喜欢的人，就是自己。完结篇里，两人已经同居，而白石正在筹划求婚。

# 七、入坑建议

- **适合的观众**：喜欢“高甜日常”、喜欢慢节奏校园恋爱的观众。它和那些“捉弄系”作品气质相近，但更温柔，也更关注“被看见”这件事本身。
- **观看提示**：动画因疫情中断后又从第1话重播，如果你在找资源时看到两个播出期，不用奇怪，内容是一样的。
- **看完动画之后**：原作漫画已经完结，全144话，简中电子版在哔哩哔哩漫画可以看到。动画停下的地方，离两人真正在一起还有一段距离——想看到最后那个告白，就去读原作吧。

---

# 总结

《久保同学不放过我》讲的不是一个路人如何变得耀眼，而是一个路人如何被一个人认真地看见。白石没有变成主角，他只是遇到了一个愿意一次又一次找到他的人；而久保同学也没有“拯救”他，她只是喜欢上了那些别人从未注意过的、平凡的好。

**这个世界上，总会有人一眼就能找到你——哪怕你自己都快要放弃被看见了。**
