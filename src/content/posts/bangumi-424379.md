> 被恋爱之神告知“你会遇到一百个命中注定的女朋友”——爱城恋太郎决定，一个都不辜负。

说实话，第一次听说《超超超超超喜欢你的100个女朋友》的时候，我以为这是一部靠标题博眼球的后宫番：一百个女朋友？光听设定就觉得要么是擦边，要么是烂尾。

![超超超超超喜欢你的100个女朋友封面](https://lain.bgm.tv/pic/cover/l/37/03/424379_UfMuk.jpg)
*超超超超超喜欢你的100个女朋友*

结果第一集看完我就笑到不行，看到第五集开始真心喜欢上恋太郎。这部作品最了不起的地方在于，它把“后宫”这个通常让人觉得不太舒服的类型，写成了**一个男生对每一个女孩都百分之百真诚**的故事——没有暧昧，没有拖延，没有“选一个”的纠结。恋太郎的答案永远只有一个：**我全都喜欢，所以我全都会负责到底。**

# 一、原作：周刊 Young Jump 上的“恋爱疯狂”

## 1.1 作品基本信息

| 项目 | 内容 |
|------|------|
| **原名** | 君のことが大大大大大好きな100人の彼女 |
| **简称** | 100カノ（ひゃっかの），中文常称“超百女友” |
| **原作** | 中村力斗 |
| **作画** | 野泽由纪子 |
| **连载** | 《周刊 Young Jump》2020年第4・5合并号起；2020年8月20日起于少年 JUMP+ 同步连载 |
| **出版** | 集英社；繁体中文版由东立出版社出版 |
| **获奖** | “下一部人气漫画大赏2020”漫画部门第2名 |

原作由**中村力斗**负责，作画由**野泽由纪子**担当。这对组合的分工有一个很可爱的细节：野泽由纪子深爱自己笔下的每一个角色，**即便原作不特别要求，她也会把所有女友全员画出来**——在一部女友数量不断增加的作品里，这份执着简直令人肃然起敬。她本人后来甚至以角色身份在动画里登场，由野泽雅子配音。

## 1.2 一路攀升的销量

本作的销量增长相当稳定：2022年3月突破100万册，2024年3月突破200万册，2025年6月突破280万册，到了2026年7月，官方宣布漫画销量**突破300万册**。对于一部设定如此“离谱”的作品来说，这份持续的人气，说明它的核心魅力远不只是噱头。

此外，本作还有由はむばね撰写、野泽由纪子插画的外传小说《番外恋物语 ～秘密恋爱故事～》，于2023年7月19日发售。

# 二、故事简介

**爱城恋太郎**在初中毕业前，已经向一百位女孩告白，并全部被拒绝。

毕业前那天，他在神社遇见了神明，才得知自己恋爱运如此惨淡的原因——神明不小心把他人生中“命运之人”的数目多写了两个零，**写成了100人**。

神明还告诉他：一般人只有一个命中注定的对象，遇上就是天大的幸运，相应地也会耗尽一辈子的运气。所以，如果他没能跟对方实现恋情，**对方就会遭遇一连串的不幸，然后死亡**。

升上高中的第一天，恋太郎就遇见了头两位“命运之人”——**花园羽香里**和**院田唐音**。两人都对他一见钟情。而恋太郎做出了一个决定：**同时和两个人交往**。

随着故事推进，越来越多的“命运之人”出现在他面前……

# 四、核心设定：命运之人

在讲角色之前，有必要先说清楚本作最关键的设定——**“命运之人”**。

| 设定 | 内容 |
|------|------|
| **定义** | 一个人出生时就被神明安排好的“最棒的恋爱对象”，一生最多只有一位 |
| **恋太郎的情况** | 因为爱之神的失误，有100位 |
| **相遇方式** | 目光交汇时双方一见钟情，女生会当场坠入爱河，男生则会随时间推移慢慢喜欢上对方 |
| **代价** | 若未能相爱并获得幸福，双方会因耗尽一生好运而遭遇不幸事故，严重时甚至会死 |
| **重要说明** | 命运之人 ≠ 精神控制或洗脑 |

最后一条特别重要。这个设定看似给了恋太郎一个“必须后宫”的借口，但作品始终在强调：女孩们的心意是真实的，恋太郎对她们的爱也是真实的。“命运”只是一个开始，**真正让她们留下来的，是恋太郎一次又一次的真诚**。

# 五、女友们：第1期登场的“恋太郎家族”

> ⚠️ 以下内容包含角色剧情的剧透。

## 5.1 花园羽香里：清纯（自称）的大小姐

羽香里是恋太郎的最初女友之一，粉色短发、总戴着花朵头饰，家境富裕，仪表端庄，温柔可爱。

——以上是她自己的认知。实际上，她是个彻头彻尾的**恋爱脑**，个性好色，总想着和恋太郎进行“男女之间的亲密互动”，常常在恋爱中耍些小心思展现自己的魅力。她和唐音之间的互怼，构成了本作最初、也是最经典的搞笑模式。

但羽香里的可爱之处在于，她的“好色”从来都是**对恋太郎一个人的、全心全意的**喜欢。原作中，她也曾在一次精心策划的“独处”中，理解到恋太郎想以一颗真诚的心对待每一位女友，于是只是吻了他，然后相拥而眠。

## 5.2 院田唐音：傲娇界的天花板

唐音是金发双马尾的**典型傲娇**，力气大到能和暴走族总长一较高下，还打破过游戏厅拳击机的世界纪录。她擅长烤饼干，似乎很喜欢猫，害羞的时候会诉诸暴力来掩饰——也因此常常直接或间接地让恋太郎受伤，但本人并非有意。

最好笑的设定是她的家人：爷爷、奶奶、父母、姐姐、弟弟、外甥、外甥女，甚至连名叫“唐太郎”的仓鼠，**全员傲娇**，连尚是婴儿的小外甥也不例外。唐音的傲娇，原来是家族遗传。

唐音也是作品里最重要的**吐槽役**。在一个所有人都越来越疯狂的家族里，她那一声声“你在说什么啊！”，是观众最需要的锚。

## 5.3 好本静：用书本说话的女孩

静是恋太郎的第3位女友，身材小巧、热爱阅读的无口少女。她不擅长开口说话，只能**指着书中对应的句子**来与他人沟通，因此被同学当成怪人，也遭到母亲的责骂，长期失去自信、陷入孤立。

恋太郎建议她使用手机里的小说朗读程序，让她能够表达自己当下的内心想法。这个解决方案很简单，却非常温柔——**恋太郎没有要求她“改变”，而是帮她找到了一种属于自己的说话方式**。

静的母亲曾试图用极端方法逼她开口，结果适得其反。而在恋太郎的介入和亲眼看到静的改变后，母女关系终于有所改善。这是第1期里最催泪的一段，也是这部搞笑番“认真”起来时的样子。

## 5.4 荣逢凪乃：效率至上的“AI”

凪乃是恋太郎的第4位女友，银色长发、高挑、理性冷静，讲求效率且冰雪聪明，常年保持全年级各科满分榜首——因为名字的谐音，甚至有传闻说她是 AI 机器人（当然被证实是谣言）。她有恐高症，心神不定时会背诵圆周率来让自己冷静。

凪乃最好笑的地方，是她总能用“效率”为理由，**极其理直气壮地和恋太郎秀恩爱**。一个嘴上说着“这样更有效率”、行动上却比谁都黏人的女孩，反差感拉满。

## 5.5 药膳楠莉：8岁外表的学姐

楠莉是恋太郎的第5位女友，化学社社长，擅长制造各种古怪的药。她其实是高三学姐，却因为服用了长生不老药的失败品，平时外表像个8岁小女孩，说话带着“なのだ”的尾音；而她的真身，是一位红色长发的高挑美女。

楠莉的药是本作最强的“剧情装置”——让人变小的药、灵魂分裂药……几乎所有离谱的展开，背后都有一瓶楠莉的药。

## 5.6 花园羽羽里：女朋友的妈妈

是的，恋太郎的第6位女友，是**羽香里的妈妈**。

羽羽里29岁，粉色长发，比女儿更加恋爱脑、更加好色。但她的背景其实相当沉重：13岁时，她不顾全家人的目光未婚生子——因为她的恋人身患重病，她希望留下他的孩子。她深深体会过失去恋人的痛苦。

这层背景让羽羽里的加入不只是“更离谱的后宫成员”，而是一个曾经失去过爱的人，重新获得爱的机会。她是经商天才，也成了恋太郎家族几乎所有大型活动的赞助者。

## 5.7 铭户芽衣：永远闭着眼睛的女仆

芽衣是花园家的女仆，小时候被虐待她的父母抛弃，流落街头，被羽羽里所救，因此对羽羽里绝对忠诚。她秉持着“女仆要在主人面前保持微笑”的观念，几乎总是闭着眼睛——只有在情绪起伏很大时才会睁开，而她的虹膜是彩虹色的。

---

# 六、恋太郎：后宫番里最“正”的男主

## 6.1 一百次失败造就的韧性

恋太郎个性温柔诚实，经历过一百次告白失败的打击，所以格外有耐心和韧性。他观察力强、非常细心，了解每位女友的小习惯，经常帮忙解决她们的烦恼。

但如果有人冒犯了他的女友，他会**大发雷霆**。为了女友，他可以发挥出超越人类的力量，甚至和神力硬碰硬不落下风——哪怕吐血而死，也能原地复活。

## 6.2 他为什么不让人讨厌？

我觉得原因很简单：**恋太郎从来不“享受”后宫**。他的目标是让全体女友成为世界上最幸福的人，是让“恋太郎家族”组成一个真正的大家庭。他会为每一个女孩拼上性命，会认真对待每一个女孩的烦恼，会在每一个女孩需要的时候出现。

在大多数后宫作品里，男主角的“优柔寡断”是推动剧情的燃料；而在这部作品里，男主角的“毫不犹豫”才是最大的笑点和泪点。

另外，他的名字本身就是一个双关：“爱城”谐音“爱情”，加上名字里的“恋”字——**生来就是恋爱漫画的男主角**。生日5月1日，“5”和“1”的日文读音连起来，谐音“恋”。

# 七、名场面与吐槽：打破次元壁的疯狂

本作的另一个魅力，是它对“漫画”这个形式本身的恶搞：

- 季节永远不会变化，角色以“话数”作为时间单位；
- 角色可以拿出漫画本身来看；
- 角色甚至能穿越次元壁，帮作者赶稿。

动画版在这方面更加放飞，加入了大量原作没有的恶搞，比如出现了“把片尾曲剪掉不就好了吗”这样的台词。

# 九、观看建议

- **适合谁看**：喜欢高密度搞笑、吐槽和打破次元壁玩梗的观众；想看一部“真诚到离谱”的恋爱喜剧的观众。
- **需要注意**：本作有不少色气向的玩笑，尺度对部分观众来说可能偏大；另外搞笑节奏非常快，建议不要倍速。
- **续作**：第1期12话只讲到了最初的几位女友，第2期于2025年1月播出，第3期于2026年7月播出。原作中的“恋太郎家族”早已远远超过了20人，而且还在持续增加中。

---

# 总结：一百份真心

《超超超超超喜欢你的100个女朋友》的设定，说到底是一个“神明的失误”。可恋太郎从来没有把它当成失误。

他把每一个命运之人都当成**唯一**来对待——羽香里是唯一的，唐音是唯一的，静、凪乃、楠莉、羽羽里，每一个人都是唯一的。他要的不是一百个女朋友，而是一百个人都能幸福地笑着的那一天。

**喜欢一个人需要勇气，而同时认真地喜欢一百个人，需要的是一颗大到离谱的心。**
