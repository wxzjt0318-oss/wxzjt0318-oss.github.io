> “爆裂吧现实！粉碎吧精神！放逐这个世界！”——想告别中二病的少年，偏偏遇上了自称拥有邪王真眼的少女。

说实话，第一次点开《中二病也要谈恋爱！》的时候，我是抱着“看个乐子”的心态去的。眼罩、绷带、“爆裂吧现实！粉碎吧精神！放逐这个世界！”——光是这些元素，就足够让人一边尴尬得脚趾抠地，一边忍不住笑出声。每个人心里大概都藏着一段不想被翻出来的“黑历史”，而这部作品，偏偏就是要把它翻出来给你看。

![中二病也要谈恋爱！封面](https://lain.bgm.tv/pic/cover/l/3d/fd/29648_LOcOx.jpg)
*中二病也要谈恋爱！*

可看着看着，我发现它没那么简单。六花的中二病不只是“可爱的怪癖”，它背后藏着一个女孩不愿面对的失去；勇太想要“毕业”的那段过去，也不只是羞耻，而是一个人长大时必须做出的选择。**中二病是什么？是一种病，还是一种保护自己的方式？** 这部作品用十二话给出了一个笑中带泪的回答。

# 一、原作：一部获奖的轻小说

## 1.1 作者与出版

| 项目 | 内容 |
|------|------|
| **原名** | 中二病でも恋がしたい！ |
| **英文名** | Love, Chunibyo & Other Delusions |
| **作者** | 虎虎 |
| **插画** | 逢坂望美 |
| **出版** | 京都动画旗下 KA Esuma 文库 |
| **首卷发售** | 2011年6月1日 |
| **卷数** | 全4卷 |

《中二病也要谈恋爱！》原作是**虎虎**创作、**逢坂望美**插画的轻小说，是**第一届京都动画大赏轻小说部门的优秀作品**，获奖评语是“文中的着眼点和想法都令人觉得很有趣”。得奖作品于2011年6月1日由京都动画自家的 KA Esuma 文库出版，之后又推出了续集，全4卷。

作者在后记里提到，书中有不少桥段是在向《凉宫春日的忧郁》致敬——想想也是，一个“自称拥有特殊能力的女孩”拉着男主角卷入非日常的故事，本身就带着一点春日的影子。

## 1.2 原作的故事

富㭴勇太在初中毕业的时候，决定同时给自己办一场“中二病毕业仪式”。他打算在高中顺顺利利地做个普通人，开学那天用最后一句中二台词，把这段黑历史彻底封印。

可惜天不遂人愿。他遇上了现役中二病患者、同班同学**小鸟游六花**，而六花一眼就看出了他身上残留的中二症状，还以此威胁他和自己“立下契约”。从此，勇太本想低调的高中生活，被六花的一举一动搅得一团乱——同学、家人、甚至初中时的老朋友，都开始注意到这对奇怪的组合。

## 1.3 小说与动画：几乎是两部作品

一个很重要的事实是：**动画版除了最基本的角色设定以外，剧情和人物背景都和原作小说不一样**。可以说，京都动画做的是一次“二次创作”。

| 对比 | 原作小说 | TV 动画 |
|------|------|------|
| **凸守早苗** | 不登场 | 动画原创角色，六花的“侍从” |
| **小鸟游十花** | 不登场 | 动画原创角色，六花的姐姐 |
| **六花的过去** | 父母不太关心她，直到遇见勇太才感受到被照顾的温暖 | 父亲病逝，六花接受不了事实，相信能在“不可视境界线”与父亲重逢 |
| **六花的中二病来源** | — | 来自她无意间看到的、中二时期的勇太 |
| **七宫智音** | 与六花是情敌 | 鼓励六花追求勇太 |

正是这些改动，让动画版拥有了一条原作没有的情感主线——**六花为什么要当中二病**。

# 三、第一季剧情解析

> ⚠️ **以下内容包含《中二病也要谈恋爱！》第一季剧情剧透，未看过的朋友请谨慎阅读。**

## 3.1 第一阶段：阳台上的“封印仪式”（第1–3话前后）

勇太升上高中后，翻出了初中时记录自己中二设定的笔记本，羞耻得无以复加，决定和过去彻底割席，把所有中二道具都收了起来。他在新学校当上了男班长，对别人的中二症状毫不留情地吐槽——仿佛只要这样，就能证明自己已经“痊愈”了。

可就在开学那天，他在学校阳台上独自重复了一遍自己的中二行为，想以此彻底告别那段阴影——结果被**六花**看见了。六花认定，这个“漆黑烈火使”和自己一样是来自异世界的存在。两人的羁绊，就从这场“简陋到极点”的封印仪式开始。

### 关键情节节点

- **楼上的邻居**：六花和姐姐**十花**就住在勇太家楼上——想躲都躲不掉。
- **极东魔术午睡结社之夏**：六花在学校创建了这个名字长得离谱的社团，社团教室在一个偏僻的角落。她声称不想引人注意，却又大张旗鼓地在校园里招人——结果招来了一个只擅长午睡的学姐**五月七日茴香**。
- **凸守早苗登场**：比六花低一届的初三学生**凸守早苗**，是“邪王真眼”独一无二的随从，句尾总要加个“death”，双马尾可以当流星锤甩。

## 3.2 第二阶段：森夏的黑历史（第4–6话前后）

班上的女班长、全班男生投票选出的“可爱女生第一名”**丹生谷森夏**，看起来是和中二病最不沾边的人。可她其实和勇太一样，初中时也是中二病患者，自称是“活了上百年、现存于世的正牌魔法师 **Mori Summer**”——而凸守早苗最珍视的《**黑暗圣典（Mabinogion）**》，正是森夏当年写下的。

### 关键情节节点

- **加入社团**：为了销毁《黑暗圣典》的抄本，森夏加入了六花他们的社团。
- **销毁计划失败（第4话）**：森夏到勇太家想销毁黑暗圣典，可凸守早就备份了好几本。从此，“森大人”和“2年级小鬼”之间的战争正式开打。
- **“森大人”**：凸守坚持叫她“森大人”，森夏一听到自己的黑历史就会捶东西——勇太只好吐槽：“你锤的东西是无辜的！”

这一阶段是第一季最欢乐的部分。森夏和凸守的对手戏几乎每次都能让人笑出声，一个拼命想埋葬过去，一个死死抱着那段过去不放，却又意外地合拍。

## 3.3 第三阶段：寻找不可视境界线（第7–9话前后）

一场海边之旅，六花说，她要去那里寻找“不可视境界线”。这段旅程里，大家也见到了六花的祖父母。

### 关键情节节点

- **六花的过去**：三年前，六花的父亲病危，但因为父亲的要求，母亲和十花都没有告诉当时年幼的六花。六花以为父亲很快会康复，可父亲去世了，母亲也离家出走——她一时间接受不了，开始相信自己能在“不可视境界线”与父亲团聚。
- **中二病的源头**：在那之后，六花在一次去十花家的路上，无意间看到了中二状态的勇太。她羡慕这个可以做自己喜欢的事的少年，回家后开始模仿——**六花的中二病，就是从勇太那里来的**。
- **祖父母的态度**：六花的祖父个性认真，无法接受她的中二病行为；祖母则以为戴着眼罩的六花是在玩海盗游戏。
- **察觉心意**：寻找不可视境界线失败后，六花对勇太产生了暧昧的感觉，而当她发现自己喜欢上勇太时，却选择了主动回避他。

到这里，这部作品的底色才真正露了出来：**六花的中二病，是她给自己造的一个避难所**。只要“邪王真眼”还在，她就可以不去面对父亲已经不在了的事实。

## 3.4 第四阶段：恋爱契约（第9–12话前后）

### 关键情节节点

- **屋顶的告白**：在森夏的帮助下，六花鼓起勇气想向勇太表白，却在屋顶失足险些掉下去，被勇太一把接住。
- **反杀告白（第10话）**：最终是六花主动“反杀”，向勇太表白。勇太开启中二模式，两人以“漆黑烈火使”和“邪王真眼”的身份签订了**恋爱契约**，正式开始交往。第10话的两首插入曲《君のとなりに》和《見上げてごらん夜の星を》，就出现在这一话。

至于最后两话的走向——六花能不能、要不要从中二病“毕业”，勇太又会怎么回应——这里就不剧透了。我只能说，“爆裂吧现实！粉碎吧精神！放逐这个世界！”这句台词，在那时候听起来，和第一话完全是两种味道。

# 四、角色深度解析

## 4.1 小鸟游六花：邪王真眼的使用者

### 基本档案

| 项目 | 内容 |
|------|------|
| **生日** | 6月12日 |
| **身高** | 150cm |
| **学校** | 私立银杏学园 1年4组 |
| **外貌** | 紫色呆毛、右眼眼罩、左手绷带、金色隐形眼镜造成的异色瞳 |
| **讨厌** | 番茄 |
| **名言** | 爆裂吧现实！粉碎吧精神！放逐这个世界！ |

“六花”这个名字代表**雪的结晶**，母亲希望她能成长为一个特别的人。她自称右眼是“邪王真眼”，能看见异世界的“不可视境界线”；特技是转手指，在第一季片头里就能看到。

六花最动人的地方，是她的中二病从来都不是“装”的。对她来说，邪王真眼是真实存在的——因为只有这样，那个已经不在的父亲才可能还在某个地方。她用中二病把自己包裹起来，可她又是那么认真地喜欢着勇太、认真地经营着那个只有几个人的社团。

还有一个小细节：班上男生投票的“可爱女生选拔赛”里，六花排在第四名——可实际上只有勇太一个人投了她。因为班上只有13个男生、27个女生，一票就够排进前几名了。

## 4.2 富㭴勇太：已经“毕业”的漆黑烈火使

| 项目 | 内容 |
|------|------|
| **生日** | 7月7日 |
| **身高** | 170cm |
| **身份** | 私立银杏学园 1年4组，男班长 |
| **妄想设定** | 漆黑烈火使，右手封印着黑炎龙 |

勇太是一个很会照顾人的少年，常常被六花“使役”；家里的家务也是他和妹妹樟叶一起承担。他十分厌恶自己的中二病，却又是全剧最理解中二病的人——因为他自己就是从那里走出来的。

勇太的成长，是学会**接纳过去的自己**。他一开始拼命想把“漆黑烈火使”埋起来，可到了最后，他愿意为了六花再次变回那个中二少年。这种“明知羞耻却依然愿意”的温柔，是勇太最帅的地方。

## 4.3 丹生谷森夏：“森大人”

| 项目 | 内容 |
|------|------|
| **生日** | 8月30日 |
| **身高** | 165cm |
| **身份** | 女班长、入学典礼新生代表 |
| **黑历史** | 魔法师“Mori Summer”，必杀技“基因贯雷枪” |

森夏的名字拆开就是“森（Mori）”和“夏（Summer）”，这就是她中二时期的名号。她和勇太一样，为了逃离黑历史，特意选了一所没有初中同学的高中。她最讨厌被叫“森大人”，可偏偏凸守天天这么叫她。

森夏是这部作品里最“现实”的人，也是最常把六花往现实里拉的人。可在关键时刻，帮六花鼓起勇气告白的，也是她。

## 4.4 凸守早苗：雷霆战锤

| 项目 | 内容 |
|------|------|
| **生日** | 8月9日 |
| **身高** | 143cm |
| **口癖** | 句尾加“death” |
| **讨厌** | 喝牛奶 |

凸守是动画原创角色，妄想程度异常严重，可功课却好得惊人——年级第一，已经拿到了高中部的保送。家里非常有钱，住独栋大豪宅，还有保镖。头发放下来的时候，会变成超级美少女。

她和森夏的关系是全剧最大的笑点之一。第一季里，两人还意外地发生了一次“初吻事件”——这对冤家，从此再也分不开了。

## 4.5 五月七日茴香与小鸟游十花

**茴香**是勇太的学姐，悠然自在，最喜欢睡觉，从不忘带自己的枕头，被森夏称为“正牌天然呆”。她的生日其实在10月，名字却叫“五月七日”；她对午睡自有一套学问，是社团里最安静、也最治愈的存在。

**十花**是六花的姐姐，职业是厨师，高中时是体操选手。她随身带着汤勺，用来和中二状态的六花“打架”，一心想矫正六花的中二病——但她同时也是让六花能发泄失去父亲之痛的对象。被六花称为“圣调理人”的她，其实是全剧最心疼六花的人。

# 五、名场面与看点

## 5.1 邪王真眼语录

“遵从血的盟约，我在此召唤汝！”“爆裂吧现实！粉碎吧精神！放逐这个世界！”（爆ぜろリアル！弾けろシナプス！パニッシュメント・ディス・ワールド！）——六花的每一句台词都中二得理直气壮。可紧接着就是“啊，我的眼睛，眼睛……”“不要扯我的呆毛，那是我的萌点所在……”，一秒破功。**这种反差，就是中二病最真实的样子。**

## 5.2 黑暗圣典争夺战

森夏想烧掉《黑暗圣典》，凸守把它备份了好几本；森夏越想否认“Mori Summer”，凸守就越要叫她“森大人”。一个想埋葬过去，一个把那段过去当作信仰——这对冤家每次交锋，都是全剧笑点最密集的时候。

## 5.3 夜空下的歌声

第10话，内田真礼唱起《見上げてごらん夜の星を》。一首老歌，放在一部满是中二台词的动画里，却意外地合适——仰望星空的时候，每个人都可以相信，那里有自己想见的人。

# 六、流行文化的影响

《中二病也要谈恋爱！》播出期间，“**○○也要××**”（○○でも××たい）这个原本很普通的日语句式，开始被大家刻意地拿来套用，而且泛用性极强。其中最常见的就是“××也要谈恋爱”。

能让一个句式流行起来，说明这部作品真的戳中了很多人——毕竟，谁没有过一段想被封印的“黑历史”呢？

# 总结：每个人心里都住着一个邪王真眼

《中二病也要谈恋爱！》讲的不是“中二病有多可笑”，而是**我们为什么需要中二病**。

对勇太来说，那是一段想要埋葬的过去；对森夏来说，那是一本拼命想烧掉的圣典；对凸守来说，那是值得一生追随的信仰；而对六花来说，那是她和父亲之间唯一的连接。

长大，也许就是学会和过去的自己和解。可在那之前，能有一个人愿意陪你一起喊出那句台词，大概就是青春里最幸运的事。

**爆裂吧现实！粉碎吧精神！——然后，好好地去谈一场恋爱吧。**
