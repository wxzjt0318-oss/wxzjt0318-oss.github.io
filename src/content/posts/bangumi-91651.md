> 六段短短的小剧场，把中二病少女们的日常再热闹地演一遍——这是属于老观众的甜点时间。

说实话，Lite 这种短篇动画，是《中二病也要谈恋爱！》系列里很有“京阿尼味”的一个小传统：正片还没开播，先放几集短短的小剧场，让大家提前回到那个熟悉的社团活动室。第一季开播前有一次，第二季开播前，又来了一次。

![中二病也要谈恋爱！恋 Lite封面](https://lain.bgm.tv/pic/cover/l/41/83/91651_vpgN9.jpg)
*中二病也要谈恋爱！恋 Lite*

《中二病也要谈恋爱！恋 Lite》就是第二季的那份“开胃菜”。它不长，也不承担什么主线剧情，但对于等了大半年的粉丝来说，能再看到六花戴着眼罩念中二台词，就已经足够开心了。

# 一、基本信息

## 1.1 播出与制作

| 项目 | 内容 |
|------|------|
| **原名** | 中二病でも恋がしたい！戀 Lite |
| **播出时间** | 2013年12月26日起 |
| **话数** | 全6话 |
| **性质** | TV 动画第二季的先行短篇动画 |
| **动画制作** | 京都动画 |
| **监督** | 石原立也 |
| **原作** | 虎虎 |
| **人物设定** | 池田和美 |

2013年12月26日，短篇动画《中二病也要谈恋爱！恋 Lite》**先于电视动画**播出，全6话。不到两周之后的2014年1月8日，第二季《[中二病也要谈恋爱！恋](/posts/love-chunibyo-and-other-delusions-heart-throb/)》正式开播。

制作班底与 TV 动画一致：监督**石原立也**，人物设定**池田和美**，由**京都动画**制作。

## 1.2 主要登场角色与声优

| 角色 | 声优 | 简介 |
|------|------|------|
| **小鸟游六花** | 内田真礼 | “邪王真眼”的使用者 |
| **富㭴勇太** | 福山润 | 曾经的“漆黑烈火使” |
| **丹生谷森夏** | 赤崎千夏 | 女班长，黑历史是“Mori Summer” |
| **富㭴樟叶** | 福原香织 | 勇太的大妹，擅长料理 |
| **富㭴梦叶** | 设乐麻美 | 勇太的二妹，5岁，非常亲近六花 |

值得一提的是，这一部的登场角色里有勇太的两个妹妹。**樟叶**擅长料理，和哥哥一起负责家里所有的家务；**梦叶**才5岁，充满朝气、性格早熟，非常喜欢勇太买给她的“相扑熊五郎”玩偶，也特别喜欢亲近六花——甚至被认为将来很有可能也会成为中二病。


## 1.3 富㭴家的故事

把樟叶和梦叶放进这部 Lite，和第二季的设定很有关系。第二季里，勇太的父亲在印尼雅加达工作，母亲为了照顾丈夫，带着两个女儿一起搬了过去；后来樟叶为了备考回到日本，和勇太、六花一起开始了同居生活。

在原作小说里，富㭴家养着一只叫 Pepapi 的金毛猎犬；到了动画里，它被改成了由六花祖父母家饲养；取而代之住进富㭴家的，是六花捡来的猫 **Kimera**——因为十花对猫过敏，六花只好把它寄养在勇太家。**一个热闹的富㭴家**，本来就是这个系列里最温暖的背景之一。

# 二、Lite 系列的传统

## 2.1 从第一季说起

Lite 的传统要从第一季说起。2012年9月27日起，在第一季 TV 动画开播之前，京都动画就在 YouTube 官方频道和动画官网上，每周四限时一周配信短篇动画《中二病也要谈恋爱！Lite》，全6话。那一部的片头曲是《**君へ**》，片尾曲是《**漆黒に踊る弧濁覇王節**》，都由 ZAQ 包办。

## 2.2 恋 Lite 的片尾曲

到了第二季的 Lite，片尾曲换成了《**深淵に舞う戦栗謝肉祭**》（在深渊中起舞的战栗狂欢节），依旧由 **ZAQ** 作词、作曲、编曲并亲自演唱。光看这个标题就知道——中二浓度，只增不减。

这首歌也收录在角色曲专辑《暗黑虹彩乐典》，并且同样作为剧场版同时上映的《剧场版 中二病也要谈恋爱！Lite》的主题曲出现过。

# 三、它在系列中的位置

## 3.1 系列观看顺序

1. 短篇《中二病也要谈恋爱！Lite》（2012年9月）
2. TV 动画第一季《[中二病也要谈恋爱！](/posts/love-chunibyo-and-other-delusions/)》（2012年10月）
3. 剧场版《[小鸟游六花·改](/posts/chunibyo-rikka-version-movie/)》（2013年9月）
4. **短篇《中二病也要谈恋爱！恋 Lite》**（2013年12月）——本篇
5. TV 动画第二季《[中二病也要谈恋爱！恋](/posts/love-chunibyo-and-other-delusions-heart-throb/)》（2014年1月）
6. 剧场版《中二病也要谈恋爱！-Take On Me-》（2018年1月）

## 3.2 适合谁看？

- **准备看第二季的人**：在开播前或者看正片之前顺手看掉，就当是热身。
- **喜欢这群角色的人**：Lite 不需要剧情铺垫，打开就能看，看完就能笑。
- **只想看主线的人**：可以跳过，不影响理解第二季。

# 四、为什么值得一看？

## 4.1 短，但有味道

短篇动画最大的好处，就是“没有负担”。不用回顾前情，不用记人物关系，很短的时间，就能重新感受一次这部作品的气氛。

## 4.2 给等待的人

从第一季播完到第二季开播，中间隔了一整年。剧场版《小鸟游六花·改》填补了其中一段，而《恋 Lite》则填补了最后那几天——**它是写给所有等待第二季的人的一封短信**。

---

# 总结：开胃菜也要中二

《中二病也要谈恋爱！恋 Lite》不是一部需要深度解读的作品。它只是在正片开始之前，让六花、勇太、森夏和富㭴家的两个妹妹，先和大家打个招呼。

**正餐还没上桌，开胃菜已经足够中二。**
