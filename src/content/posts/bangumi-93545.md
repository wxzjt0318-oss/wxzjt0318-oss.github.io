> 三个月，二十五万人——救不了这座游乐园，魔法国度的公主就会消失。

说实话，第一次看《甘城光辉游乐园》的开头，我以为这是一部普通的校园恋爱喜剧：神秘的美少女转学生，把枪口抵在男主角面前，逼他答应周末一起去游乐园约会。结果到了游乐园才发现，这根本不是约会，而是一场**面试**。

这座游乐园设施破旧、服务糟糕，是出了名的"最差约会地点"；更要命的是，它三个月内凑不齐25万游客就得关门。而园里那些看起来很敷衍的玩偶吉祥物，**里面根本没有人**——它们是真正来自魔法国度的居民。

![甘城光辉游乐园封面](https://lain.bgm.tv/pic/cover/l/69/e5/93545_zYRKK.jpg)
*甘城光辉游乐园*

一个自恋到极点、却又勤奋到极点的高中生，带着一群满身毛病的吉祥物，和闭园倒计时赛跑。这就是《甘城光辉游乐园》（简称"甘辉"）。

# 一、作者与原作

## 1.1 贺东招二的"不是军事"的新作

| 项目 | 内容 |
|------|------|
| **原名** | 甘城ブリリアントパーク |
| **作者** | 贺东招二 |
| **插画** | 中岛有华 |
| **出版** | 富士见 Fantasia 文库（富士见书房→KADOKAWA），2013年2月起刊行，全8卷 |
| **销量** | 截至2014年11月，系列累计发行40万册 |
| **中文版** | 繁体中文版由青文出版社发行，译名《甘城辉煌乐园救世主》 |

本作是贺东招二在《全金属狂潮》完结大约三年后推出的新系列。原本预定2011年发售，几经延期，直到2013年2月才出了第1卷。

据日文维基百科，作者一开始把它定位成"恋爱喜剧"，后来却自己说"那是骗人的"——书里充满了一点都不像恋爱喜剧的辛辣黑色笑话。

## 1.2 灵感：如果玩偶其实讨厌小孩

作者谈到创作起点时说：在游乐园看到玩偶装，就想到"如果里面其实是个超讨厌小孩的家伙，那应该很有趣"。他还说，像自己这种平时只看"带刺"娱乐作品的大男人，会觉得面向家庭的游乐园很无聊，于是就冒出了一些"坏心眼"的点子。

他想写的是：一群各有毛病的人下定决心去做成一件事、娱乐从业者的苦恼，以及夕阳产业的悲哀。至于为什么把舞台放在游乐园，他的解释是：轻小说的固定舞台是"学校"，可就算离开了学校，人也还有别的容身之处——他想挑战这样的故事。

## 1.3 衍生作品

- **外传小说《甘城光辉游乐园 红枫召唤者》**：八奈川景晶执笔，贺东招二原案、监修，全3卷；
- **漫画版**：吉冈公威作画，《月刊 Dragon Age》2014年3月号～2016年10月号连载，全6卷；
- **四格外传《甘城光辉游乐园？呼姆》**：东皓司作画；
- **《甘城光辉游乐园 The Animation》**：依照动画剧本改编的漫画，全3卷。

在北美，Sentai Filmworks 取得了动画代理，2017年2月发行了日语和英语配音的蓝光。

# 三、剧情：三个月的救园倒计时

> ⚠️ 以下内容涉及动画剧情。

## 3.1 被枪指着去"约会"

自恋的高中生可儿江西也，被神秘的转学生千斗五十铃用毛瑟枪指着，答应了周末去游乐园约会。到了地方他才发现，这里是甘城光辉游乐园：建于泡沫经济全盛期，近年假日游客不到3000人，设施破旧、服务差劲。

西也被带去见了乐园的总园长拉媞珐——一位"真正的"公主。她请西也担任代理园长：**按照合约，三个月内游客不满25万人，乐园就要关门**。

## 3.2 一群需要被拯救的吉祥物

乐园里的吉祥物，其实都是来自魔法国度"红枫乐园"的居民。他们靠人类玩得开心时产生的能量生存，而公主拉媞珐更是被诅咒缠身：乐园一旦关闭，她自己也会面临危机。

西也起初打算拒绝，可看到乐园的惨状后，还是接下了这份工作。从此，他带着这群服务态度极差、各有毛病的吉祥物，一边改造设施、一边招人、一边筹钱。看各话的英文标题就能感受到这份窘迫：游客不够、时间不够、帮手不够、钱不够、人不够……几乎每一集都在"不够"。

## 3.3 动画原创的结局

动画版和原作的走向不一样。据中文维基百科：

- **第11话**：为了冲人数，动画里的西也主动赞助球队，在园内的体育场举办纪念足球赛；原作的这段情节完全不同；
- **第12话**：原作里，达成目标后拉媞珐的记忆会被"重置"，忘掉西也前一年做的一切；动画则让城堡庭园的大树开花，释放出的能量缓解了诅咒，**她保住了这一年的记忆与成长**。

# 四、角色解析

## 4.1 可儿江西也：自恋，但非常勤奋

头脑聪明、运动万能、长相帅气，却自恋到在学校连一个朋友都没有。他曾是红极一时的童星，这段过去是他不太想提的事。他还有恐高症。

日文维基百科特别提到：西也最大的优点不是能力，而是**"勤奋得惊人"**。他在演艺圈练出来的演技、歌唱、舞蹈和导演本事，全被他用在了乐园的表演上。拉媞珐还赐给他一种魔法：读取别人的心思——但这个能力有使用限制。

## 4.2 千斗五十铃：用枪说话的秘书

表情淡漠、身材出众的转学生，真实身份是红枫乐园近卫队的第一卫士。她能变出一把魔法毛瑟枪，动手从不犹豫。

西也之前，她就是乐园的代理园长，可沟通能力差、又不懂娱乐，努力全都用错了方向——这也是乐园陷入绝境的原因之一。西也接手后，她改当西也的秘书。她的祖先里有河童，所以爱吃黄瓜、特别喜欢泡澡。

## 4.3 拉媞珐：被诅咒的公主

乐园的总园长、红枫乐园的第一公主。她身上背着诅咒，体弱多病，几乎不离开城堡；更残酷的是，她的身体成长和记忆每年都会被重置一次。只有在充满欢乐能量的乐园里，她才能活下去。她现在唯一的工作，是做园内限量贩售的可乐饼。

## 4.4 中城椎菜：咬着舌头也要唱下去

按原作设定，她是来乐园应征打工的高中生，个子小得像小学生，非常不擅长和人打交道，说话常常咬到舌头。在松松饼手下接受了服务员特训后，她才慢慢有了起色。她每次受挫都会去唱卡拉OK，歌喉好到每次都被店员夸——后来还成了乐园主题曲 CD 的主唱。她已故的父亲是消防员，生前是松松饼的酒友。

## 4.5 吉祥物群像

- **松松饼**：糖果屋的妖精、乐园的招牌，却讨厌甜食，爱吃可乐饼这类下酒菜。脾气火爆，最讨厌被人说是"山寨品"。他是拉媞珐的舅舅，出身红枫乐园的军人贵族世家。据中文维基百科，他的外形是经插画家四季童子同意，照搬《全金属狂潮》里的"蹦太君"设计的；
- **马卡龙**：音乐剧场的妖精，有艺术家脾气，不想上班就请假。他会演奏各种乐器，还能制作音乐，可对儿童歌谣毫无兴趣；
- **堤拉米**：花园大冒险的妖精，有前科，是通过罪犯更生计划来乐园工作的"问题员工"。松松饼、马卡龙和堤拉米三个，被合称为"甘辉三连星"；
- **元素精灵四人组**：水之精灵缪丝是认真的队长，却苦恼自己存在感太弱；火之精灵莎萝曼走到哪都拿着手机发社交动态，经常引发"炎上"；风之精灵席尔菲有舞蹈天分，却完全不会看气氛；土之精灵珂玻莉内向害羞，最爱男男同人本。

一群人各有各的毛病，却都是让这座乐园转起来的人。

# 六、原作与动画的差异

动画对原作做了不少调整。按日文和中文维基百科的整理：

| 项目 | 原作 | 动画 |
|------|------|------|
| **期限与目标** | 2周内10万人 | 3个月内25万人 |
| **黑色笑话** | 大量辛辣黑色笑话 | 全部删掉 |
| **吉祥物戏份** | 很少描写 | 大幅增加，喜剧演出更多 |
| **游乐设施** | 水族馆（アクワーリオ） | 元素馆（エレメンタリオ） |
| **拉媞珐** | 双目失明 | 没有提到失明 |
| **结局** | 记忆被重置 | 保住了记忆 |

日文维基百科指出，原作"两周十万人"折合下来一天只有约300人，作为改善经营的期限其实很勉强；动画配合一季的播出长度改成"三个月二十五万人"，数字反而更现实。

# 七、作品之外：可乐饼与足球

- **可乐饼联动**：2014年7月19日至8月31日，赤坂 Sacas 的"夏 Sacas 2014"活动上，本作和中野的可乐饼专卖店"西乡亭"联合出展——正好对上了拉媞珐亲手做可乐饼的设定；
- **足球联动**：J2 球队东京绿茵在2015年3月21日对水户蜀葵、4月11日对岐阜 FC 的两场比赛中，都和本作举办了联动企划。动画第11话里，西也正是靠足球赛来冲游客人数的；
- **周年活动**：据アニメハック，2015年4月在角川电影院新宿办过"甘城光辉游乐园开园30周年纪念"活动；2024年6月，为纪念 TV 动画播出10周年，秋叶原 Gamers 本店还开了一场纪念展。

# 八、评价

- 在"Newtype 动画大奖2014-2015"中，松松饼拿下了吉祥物角色奖第2名；
- 在美国网站 Anime Trending 举办的第一届 Anime Trending Awards 中，本作获得年度喜剧动画第2名，西也和五十铃也分别进入年度男性角色、年度女性角色和年度 CP 的榜单；
- 作品的"圣地"是横跨东京都稻城市与神奈川县川崎市的游乐园"读卖乐园"一带。

---

# 九、观看建议

动画全13话一季完结，结局是原创的，看完就是一个完整的故事。蓝光和 DVD 还附有未在电视播出的第14话，以及7集特典短篇《激动人心小剧场 后台涂鸦》。

如果你看完动画还想知道原作里那个"更黑"的甘辉，可以去看小说——不过记得，动画删掉的那些黑色笑话，在原作里一个都不少。

---

# 总结：让游乐园重新转起来

《甘城光辉游乐园》讲的是一座快倒闭的游乐园，也是一群"不被需要"的人：过气的童星、用错力气的近卫、被诅咒的公主，还有一群满身毛病的吉祥物。

西也拯救的不只是乐园的游客数字，还有一群在这里找到容身之处的人。

**梦想的国度，也要有人来认真经营。**
