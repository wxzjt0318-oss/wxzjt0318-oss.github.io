> 幼稚园里最认真的恋爱，大概就是把“长大后要嫁给老师”说得理直气壮。

说实话，第一次点开《花丸幼稚园》的时候，我是抱着"看小朋友卖萌放松一下"的心态去的。结果看完第一话我就愣住了：这群幼稚园小孩，一个在认真规划和老师的婚后生活，一个能把天文知识讲得让大人瞠目结舌，还有一个害羞到被人扶起来一次就坠入了初恋——这哪是什么"萝莉番"，这分明是一部用幼稚园做舞台的恋爱喜剧。

![花丸幼稚园封面](https://lain.bgm.tv/pic/cover/l/42/c8/3848_Z5Lnm.jpg)
*花丸幼稚园*

而更妙的是，孩子们吵吵闹闹的恋爱背后，还藏着一条大人们笨拙又温吞的感情线。新来的土田老师喜欢山本老师，这是全园都知道的秘密——唯独山本老师本人不知道。小孩子的心意直白得过分，大人的心意却迟钝得让人着急，这种反差，就是《花丸幼稚园》最可爱的地方。

# 一、原作：从两次短篇到十一卷连载

## 1.1 基本信息

| 项目 | 内容 |
|------|------|
| **原名** | はなまる幼稚園 |
| **英文名** | Hanamaru Kindergarten |
| **作者** | 勇人 |
| **连载杂志** | 史克威尔艾尼克斯《YOUNG GANGAN》 |
| **连载时间** | 2006年18号起正式连载，至2011年21号完结 |
| **单行本** | 全11卷，共102话 |
| **繁体中文版** | 玉皇朝、尖端出版（尖端官方译名《花圈圈幼稚园》） |

## 1.2 "两次试刊都受好评"的出身

《花丸幼稚园》并不是一开始就被定为长期连载的。根据资料，它先在《YOUNG GANGAN》2005年23号和2006年3号以短篇形式刊登了两次，两次都收获了不错的反响，于是编辑部决定从2006年18号开始正式连载。

这种"先试水、再转正"的出身，某种程度上也说明了这部作品的底色：它没有宏大的设定、没有强烈的戏剧冲突，靠的就是读者看完之后那种"好想再多看一点"的温暖感。尖端出版的宣传文案把它称作"花圈圈一等赏，舒缓系喜剧登场"，"舒缓"两个字，算是把整部作品的气质说透了。

## 1.3 一个有趣的联动

原作还和冰川へきる的《嬉皮笑园》搞过一次合作漫画——《嬉皮笑园》第14卷中收录了"嬉皮笑园和花丸幼稚园"的联动篇。同为《YOUNG GANGAN》系的作品，两部"可爱外表下藏着奇怪内核"的漫画凑在一起，想想就很有画面感。

# 二、剧情简介：一个幼稚园小朋友的"恋爱大作战"

## 2.1 故事梗概

**杏**是花丸幼稚园樱组的小女孩，金色头发、头顶一根呆毛，活泼得像个小太阳。她最喜欢的人，是新来的樱组班主任——**土田直纯老师**。每天，杏都热衷于各种"接近土田老师"的作战，甚至会认真地和同龄男孩子讨论自己和土田老师的"未来设计"。

陪在杏身边的是她最好的两个朋友：知性冷静、热爱变装的**柊**，和纯情害羞的**小梅**。三个人感情好得不得了，杏负责冲锋陷阵，柊负责出谋划策，小梅负责……在一旁脸红。

可杏的恋爱之路上有一个巨大的障碍——桃组的**山本菜菜子老师**。土田老师喜欢的是她，这件事全园皆知；偏偏山本老师在感情方面迟钝得异常，完全没察觉。于是，一边是小朋友直球到不能再直球的追求，一边是大人之间怎么也捅不破的窗户纸，花丸幼稚园的日常就这样热热闹闹地展开了。

## 2.2 这不只是"小孩子的故事"

如果只把《花丸幼稚园》看成一部"萝莉卖萌番"，就太小看它了。作品的视角其实同时照顾了两个世界：

- **孩子的世界**：杏对土田的憧憬、小梅的初恋、雏菊的"聘礼"、健治对柊的不服气……孩子们的感情单纯而认真；
- **大人的世界**：土田对山本的暗恋、草野老师的支持与心意、真弓与漫画家花丸之间的牵挂……大人们反而更笨拙、更说不出口。

这两个世界互相映照，孩子们像一面镜子，照出了大人们的犹豫；而大人们的温柔，又守护着孩子们的天真。

# 四、主题曲：每一话都有一首新的片尾曲

## 4.1 片头曲《青空トライアングル》

片头曲《**青空トライアングル**》（青空三角形）由杏（真堂圭）、柊（高垣彩阳）、小梅（MAKO）三人演唱，作词只野菜摘，作曲编曲 NARASAKI。"三角形"指的自然就是这三个形影不离的好朋友。有个小知识：这首片头曲在第1话和第11话并没有使用。

## 4.2 十二话、十二首片尾曲

《花丸幼稚园》最让我印象深刻的企划，是**每一话都换一首片尾曲**，而且几乎全是由当话的重点角色演唱的角色歌：

| 话数 | 曲名 | 演唱 |
|------|------|------|
| 第1话 | 笑顔ならべて（并排的笑脸） | 杏、柊、小梅 |
| 第2话 | キグルミ惑星（玩偶装行星） | 柊 |
| 第3话 | 草の指輪 花の冠（草的戒指，花的王冠） | 山本老师 |
| 第4话 | 発動!!らぶビーム☆（发动！！爱之光束☆） | 杏 |
| 第5话 | あのねきいてね（那个呀，听我说） | 小梅 |
| 第6话 | ハートの法則（心的法则） | 皋月 |
| 第7话 | 黒ネコのジャズ（黑猫的爵士） | 土田老师、皋月 |
| 第8话 | 撫子ロマンス（抚子浪漫曲） | 雏菊 |
| 第9话 | 黒糖ドロップ（黑糖糖果） | 山本老师、真弓 |
| 第10话 | 僕の忘れもの（我遗忘的东西） | 土田老师 |
| 第11话 | Yes, We Can!! | 草野老师、川代老师 |
| 第12话 | せかいでいちばん（世界第一） | 杏、樱 |

此外，第12话还有一首由山本老师演唱的插入曲《優しい陽だまり》（温柔的向阳处）。

这个企划的妙处在于：**每一首歌都像是那一话主角的"内心独白"**。柊的《玩偶装行星》对应她热爱变装、梦想遨游宇宙的个性；山本老师的《草的戒指，花的王冠》温柔得像她本人；土田老师的《我遗忘的东西》则带着一点大人的怅惘。最后一话让杏和妈妈樱一起唱《世界第一》，母女同声，把整部动画的温度推到了最高点。

音乐方面由 NARASAKI 和 WATCHMAN 组成的 Sadesper Record 负责，作词则集合了只野菜摘、松浦有希、大森祥子、高桥菜菜等人。一部幼稚园番能做到这种程度的音乐企划，诚意是真的满。

# 五、角色深度解析

> ⚠️ 以下内容涉及部分原作漫画后期剧情。

## 5.1 杏：想快点长大的小太阳

杏是美国出生的金发小女孩，是三人组里的带头人和气氛担当。她最可爱的地方，在于那种**"假装大人"与"真的是小孩"之间的来回切换**：前一秒还在一本正经地像大人一样接近土田老师，下一秒就会因为想从妈妈那里吃到点心而离家出走。

杏常常在梦和妄想里看到长大后的自己，又会拿自己和山本老师比较而陷入绝望——她对"成为大人"有着强烈的憧憬。一开始她对山本老师抱有明显的敌意，但随着故事推进，两人逐渐和解，甚至变得非常要好。这段从"情敌"到"朋友"的变化，是杏这个角色最温柔的成长。

## 5.2 柊：没画嘴的天才军师

蓝色马尾、脸上没有画嘴巴——柊的造型本身就很有辨识度。她知识丰富得完全不像幼稚园小孩，能让土田和山本两位老师都瞠目结舌，是三人组的参谋。

但柊绝不只是一个"小大人"。她也会因为理论用错而失败，会因为被老师直接表扬而害羞，比起杏和小梅反而更喜欢"熊喵"这种孩子气的东西。她容易感动，事件解决后总会流下瀑布一样的眼泪；害羞时还会跳一段怪怪的舞。她受天文学者父亲影响，梦想成为宇航员，和各种宇宙人相遇、一起观测星空。

我特别喜欢柊和健治那条小支线：健治自恃博学，被柊一一纠正后不甘心，跟踪她、向她挑战调查公园里的"妖怪"，结果发现妖怪只不过是一堆被弃置的垃圾，第二天就心服口服地拜柊为师。小孩子之间的"学术之争"，看得人忍不住笑。

## 5.3 小梅：害羞的初恋

小梅超可爱又超害羞。某次她跌倒时，被向日葵组的小早川优扶了起来，从此就喜欢上了这个性格温厚的男孩。她还有一个极度溺爱她的大学生哥哥智之——溺爱到大学放假时会特地跑到幼稚园外远远地看妹妹，还把她的一举一动都录下来。小梅自己因为跑得慢，还专门向草野老师请教过。

## 5.4 土田直纯：被小朋友追求的新老师

土田是花丸幼稚园新聘的老师，负责杏所在的樱组。他个性平易近人，平时没什么突出之处，工作以外最大的乐趣是打电动——也因此经常睡过头赶着上班，甚至会反过来向擅长游戏的良太讨教。

土田身上最有意思的设定，是他和杏一家的渊源：他是杏的妈妈樱的高中学弟，学生时代常和"孩子王"樱一起玩。现在学姐的女儿天天追着他说要结婚，这种局面也难怪他招架不住。而他对山本老师的爱慕，更是全园皆知的秘密。

## 5.5 山本菜菜子：天然迟钝的温柔光环

山本老师和蔼可亲、充满母性，对幼稚园的事情极度用心，感情上却迟钝得异常。萌娘百科里有一句很有画面感的描述：她能用温柔的气氛安慰周围的人，"甚至能在无形中攻略暴走族"。

根据原作资料，山本老师直到漫画第10卷末尾才开始意识到土田是异性；在她即将离开花丸幼稚园、转到另一所幼稚园任职时，土田终于向她告白，两人成为恋人。漫画最终卷以他们在异地恋中第一次牵手约会的场景收尾——这个结局对于看了那么久"窗户纸"的读者来说，真的是一份温柔的奖励。

## 5.6 其他让人难忘的配角

- **雏菊**：组长的女儿，因为土田的亲切对待而喜欢上他，甚至为此转学入园、要求结婚。得知土田喜欢山本后向她挑战，明白敌不过之后一度想放弃，最后在杏的鼓励下决定"推迟聘礼"，等自己长大；
- **组长**：雏菊的父亲，脸上有伤、长相凶恶，却为常常吓哭小孩而烦恼，惧内又爱女，平时还为地方活动出力；
- **草野老师**：喜欢肌肉男、立志从幼稚园开始培养男孩子运动的运动型老师。她一直支援土田对山本的恋情，即使后来自己也喜欢上土田并告白，之后依然支持着他们；
- **土田皋月**：土田的妹妹，傲娇兄控，成绩优秀、擅长家务，一边抱怨哥哥在外生活邋遢，一边又对哥哥的事业抱持敬意；
- **真弓与花丸**：山本老师的妹妹真弓在漫画编辑部打工，曾努力鼓励陷入瓶颈期的漫画家花丸，花丸因此喜欢上她，却怎么也说不出口——又是一对迟钝的大人。

# 六、这部作品好在哪里

## 6.1 用孩子的直白，反衬大人的笨拙

《花丸幼稚园》最聪明的结构设计，是让**最直白的感情和最迟钝的感情住在同一个屋檐下**。杏可以毫不犹豫地说"我要嫁给土田老师"，雏菊可以直接谈"聘礼"；而土田、山本、花丸、真弓这些大人，却一个比一个说不出口。

看着孩子们为大人的恋情着急、出主意，有时候会觉得，这群小朋友才是真正"懂恋爱"的人。

## 6.2 每个家庭都有一个小故事

这部作品里几乎每个孩子背后都带着一个家庭：葵家开鱼店，她想帮忙却被父亲劝去多玩耍，直到杏她们路过帮忙后父亲才同意；苺花被母亲认定是"乖孩子"而有点过度保护；杏的妈妈樱高三时怀孕、因丈夫赴美留学而放弃了高中毕业……这些小小的家庭侧写，让幼稚园不只是一个"卖萌的场景"，而是一个有生活气息的小社会。

## 6.3 舒缓，但不空洞

日常系作品最怕的是"什么都没讲"。《花丸幼稚园》的每一话都有一个小小的核心——一次初恋、一次和解、一次拜师、一次家庭里的小矛盾——再配上一首专属片尾曲收尾。它很舒缓，却从不空洞。

# 七、入坑建议

## 7.1 适合谁看

- 想看一部**轻松、温暖、没有负担**的日常喜剧的人；
- 喜欢"小孩子一本正经谈恋爱"这种反差萌的人；
- 喜欢角色歌、愿意认真听片尾曲的人——这部作品的片尾曲企划值得每话都听完；
- 对水岛精二、GAINAX 在"另一种题材"上的表现感到好奇的人。

## 7.2 观看建议

全12话、一季完结，没有续作负担，非常适合周末一口气看完，或者每天睡前看一两话放松。如果看完意犹未尽，原作漫画全11卷已经完结，后面土田和山本老师的感情结局，就藏在漫画里。

---

# 总结

《花丸幼稚园》讲的是一群小孩子的日常，却总让我想起大人才会有的那些犹豫——想说的话说不出口，喜欢的人看不懂心意，明明很近却迟迟不敢往前一步。

杏说她想快点长大，可看完这部动画，我反倒有点羡慕她：**能毫不犹豫地说出"最喜欢"的人，才是最勇敢的人。**

花圈圈一等赏，送给这所幼稚园里所有认真喜欢着谁的人。
