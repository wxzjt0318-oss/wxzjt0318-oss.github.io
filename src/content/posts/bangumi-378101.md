> 带着智能手机的冬夜依旧悠闲，但他的国家，已经开始被更大的危机悄悄逼近。

说实话，《带着智能手机闯荡异世界。》会出第二季，我是真的没想到。第一季播完是2017年，口碑两极、话题不少，之后就是长达五年多的沉寂。直到2022年4月官方宣布续作的消息，我才意识到：冬夜那份长长的“未婚妻名单”，原来还没讲完。

![带着智能手机闯荡异世界。 第二季封面](https://lain.bgm.tv/pic/cover/l/98/25/378101_XGh49.jpg)
*带着智能手机闯荡异世界。 第二季*

第二季的整体气质和第一季一样，依旧轻松、依旧顺风顺水，依旧是“冬夜帮人、女孩子们喜欢上冬夜”的节奏。不同的是，这一季的舞台更大了，登场的女孩子也更多了——从片尾曲的演唱阵容里，你就能看得一清二楚。

# 一、第二季的基本信息

## 1.1 播出与制作

| 项目 | 内容 |
|------|------|
| **原名** | 異世界はスマートフォンとともに。2 |
| **播出时间** | 2023年4月3日起，全12话 |
| **原作** | 冬原帕朵拉（HJ NOVELS） |
| **监督** | 岩崎良明 |
| **人物设定** | 龟山千夏 |
| **音乐** | 吉川庆、山田航平 |
| **动画制作** | J.C.STAFF |

## 1.2 换了一家制作公司

第二季最大的变化，是**制作公司从 Production Reed 换成了 J.C.STAFF**：

- **2022年4月15日**：官方宣布 TV 动画第二季制作决定
- **2022年7月**：宣布动画制作公司更换为 J.C.STAFF
- **2023年4月3日**：第二季开播，全12话

监督也从第一季的柳濑雄之换成了**岩崎良明**，人物设定换成了**龟山千夏**，音乐则由**吉川庆**与**山田航平**负责。几乎是一套全新的主创班底，所以如果你觉得第二季的画面观感和第一季不太一样，这很正常。

## 1.3 声优阵容

主要角色的配音全部延续第一季：**福原克己**的望月冬夜、**内田真礼**的爱尔泽、**福绪唯**的琳泽、**赤崎千夏**的八重、**高野麻里佳**的尤米娜、**山下七海**的苏西、**上坂堇**的翎。

而第二季最重要的新面孔，是三位新的女主角：

| 角色 | 声优 | 身份 |
|------|------|------|
| 露西亚·蕾雅·雷古路斯 | 高木美佑 | 雷古路斯帝国第三公主 |
| 希尔德嘉·米纳斯·瑞斯特亚 | 芹泽优 | 瑞斯特亚骑士王国第一公主 |
| 樱 | 久保田未梦 | 失去记忆的少女 |

另外，第一季最后一话片尾曲之后登场的神秘银发青年**恩德**，由**内田雄马**配音。

# 二、主题曲：越唱人越多的片尾曲

## 2.1 片头曲

| 类型 | 曲名 | 演唱 |
|------|------|------|
| **OP** | 《リアルダイヤモンド》（Real Diamond） | Gemstone7 |
| **ED** | 《イセカイジュエリー》（异世界珠宝） | 多位女主角 |
| **第10话插曲** | 《桜の歌》（樱之歌） | — |

## 2.2 片尾曲的“扩编”

第一季的片尾曲是六位女主角轮流独唱，第二季的片尾曲《イセカイジュエリー》则换了一种玩法——**演唱人数随剧情推进不断增加**：

| 话数 | 演唱阵容 |
|------|------|
| 第1–4话 | 尤米娜、爱尔泽、琳泽（3人） |
| 第5–8话 | ＋八重、苏西、翎（6人） |
| 第9–12话 | ＋露西亚、希尔德嘉、樱（9人） |

**从3人到6人再到9人**，这个设计几乎就是冬夜“后宫”扩张的进度条。到最后四话，九个声音合在一起，正好对应原作里冬夜最终的九位未婚妻。这份“直白”，倒也算是这部作品的一贯风格。

第10话的插曲《桜の歌》由吉川庆作曲——从歌名就能看出，它和新女主“樱”有着直接的关系。

# 三、新角色解析

> ⚠️ **以下内容涉及原作小说中的角色设定与后续剧情**

## 3.1 露西亚：被救出的帝国公主

**露西亚·蕾雅·雷古路斯**，雷古路斯帝国的第三公主，比冬夜小四岁，昵称“露”，有着美丽的银色长发。

在原作中，她在帝国发生军事政变时被冬夜救出。她使用双剑，不具魔法适性，个性较为内向，但同时也有身为公主的坚强与行动力。被冬夜拯救之后，她便喜欢上了冬夜，在政变平定后成为他的未婚妻。故事后期，她的厨艺进步到连冬夜都赞不绝口。

## 3.2 希尔德嘉：骑士王国的剑士公主

**希尔德嘉·米纳斯·瑞斯特亚**，瑞斯特亚骑士王国的第一公主，与八重同岁，比冬夜小一岁，昵称“希尔妲”。

她初次登场时正在抵御水晶魔物“**弗雷兹**”的侵袭，苦战之中遇到了前来寻找“巴比伦”的冬夜，并得到了他的协助。击退弗雷兹后，她收下了冬夜做的水晶剑，从此对冬夜念念不忘。之后，她以答谢为名跟随祖父前往冬夜的国家，并成功战胜祖父，得到了嫁给冬夜的认可。她和同为剑士的八重感情很好。

## 3.3 樱：失去记忆的魔王之女

**樱**初登场时身负重伤、失去记忆，被冬夜发现后带回治疗。因为她的发色是樱花色，冬夜暂时为她取名“樱”，她本人似乎也很喜欢这个名字。

原作中，她在冬夜的协助下找回记忆，得知自己的真实身份是**魔王国的公主、魔王与人类庶民所生的女儿**，本名法露涅赛·佛钮司。她头部两侧长有象征魔王的白银色双角，平时用魔法隐藏。她是个看不出情绪的“三无少女”，对父亲魔王的女儿控态度相当不耐烦。

## 3.4 恩德：知晓秘密的流浪者

一头白发、白围巾黑外套，自称“流浪者”的少年**恩德**，持有古代货币，能一击解决古代魔物，并且知晓这个世界的秘密。在原作里，他曾在沙漠中轻松打倒了冬夜一行人无法对付的弗雷兹——那种曾在五千年前摧毁古文明、却又突然集体消失的古代魔兽。

萌娘百科半开玩笑地说他“可能会是男主的基友”；而在原作中，他后来确实和冬夜成了酒友。

# 四、布伦希尔德公国：冬夜的“家”

> ⚠️ **以下内容涉及原作设定**

如果说第一季的冬夜还只是一个住在宅邸里的冒险者，那么原作接下来的故事，就是他从“冒险者”变成“公王”的过程。

在雷古路斯帝国的军事政变中，冬夜救出了露西亚等人，平定了叛乱。政变平复后，贝尔法斯特与雷古路斯结成同盟，两国各自分割一小块国土让给冬夜建国，并承认这个国家的地位——这就是**布伦希尔德公国**，名字来自北欧神话中的女武神“布伦希尔德”。

国王们之所以这么做，原因也很直白：两国的国王和皇帝都希望冬夜能迎娶自己的女儿，而要娶公主，冬夜就得有相应的地位。于是，他被半逼迫地推上了王位。

公国建立之后，冬夜的“家”开始迅速扩张：

- 以兔之兽人少女**雷英**为团长、以水晶般透明的剑与盾为标志的“**水晶骑士团**”
- 来自逸仙、原武田四天王的**高坂政信**（宰相）、**马场信晴**、**山县政景**、**内藤正丰**
- 从里佛雷特镇搬来开二号店的旅馆“银月”和咖啡店“帕伦多”

**第一季里那座宅邸，在原作中慢慢长成了一个国家。** 这也许是这部作品最有意思的“成长”——主角本人几乎没变，变的是他身边越来越多的人。

## 4.1 九位王妃与她们的“代表色”

原作里，冬夜最终迎娶的九位王妃各有一种代表色，正好和片尾曲里九个人的阵容一一对应：

| 王妃 | 身份 | 代表色 |
|------|------|------|
| 尤米娜 | 贝尔法斯特王国第一公主 | 银色 |
| 露西亚 | 雷古路斯帝国第三公主 | 绿色 |
| 希尔德嘉 | 瑞斯特亚骑士王国第一公主 | 橙色 |
| 苏西 | 欧尔托林德公爵千金 | 金色 |
| 翎 | 妖精族领袖 | 黑色 |
| 樱 | 魔王国公主 | 白色 |
| 琳泽 | 平民冒险者（双胞胎妹妹） | 蓝色 |
| 爱尔泽 | 平民冒险者（双胞胎姐姐） | 红色 |
| 八重 | 逸仙的武士 | 紫色 |

这些颜色后来还会成为她们各自专用巨型机兵“福雷姆基亚”的机身颜色。**一部从“手机”开始的异世界作品，最后连机器人的配色都安排好了**，冬原帕朵拉的“设定癖”可见一斑。

## 4.2 巴比伦的九座浮空岛

第一季末尾，冬夜找到了古代天才博士**蕾吉娜·巴比伦**留下的九座浮空岛之一“庭园”。原作中，九座岛各有一位继承了博士怪异人格的人造人管理者——“庭园”的西丝卡、“工房”的洛赛塔、“炼金楼”的芙萝拉、“整备库”的莫妮卡……她们认证冬夜为主人的方式五花八门，大多还带着博士本人的恶趣味。

至于博士本人，则把自己的脑移植进了人造人的身体，在五千年后借由冬夜的魔力苏醒，自称冬夜的“情人”。**这一整座会飞的“遗产”，就是冬夜往后对抗弗雷兹的底气所在。**

# 总结

《带着智能手机闯荡异世界。 第二季》没有试图改变这部作品的本质：冬夜依旧强大、依旧温和、依旧被一群女孩子围着。它做的只是把舞台放得更大——更多的国家、更多的伙伴，以及一首从三个人唱到九个人的片尾曲。

你可以说它“没有新意”，但对喜欢这部作品的人来说，这份不变恰恰是最好的安心。

**冬夜的冒险从来不是为了变强，而是为了让那份“家人”的名单，再长一点。**
