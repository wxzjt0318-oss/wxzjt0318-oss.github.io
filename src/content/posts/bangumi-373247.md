> 失去的、错过的、来不及说出口的——鲁迪乌斯带着伤痛，重新出发。

说实话，第一季下半部的结尾，我是真的替鲁迪乌斯难受。那个以为自己终于和艾莉丝心意相通的少年，一觉醒来只剩下一封信，然后整个人就垮掉了。等了一年半，第二季开播的第一个画面，就是一个瘦了一圈、眼神空洞、连魔术都提不起劲的鲁迪。

![无职转生 第二季 ～到了异世界就拿出真本事～封面](https://lain.bgm.tv/pic/cover/l/cf/55/373247_aBFR1.jpg)
*无职转生 第二季 ～到了异世界就拿出真本事～*

这一季没有第一季那样壮阔的旅途，也没有接连不断的大战。它更像是一段漫长的疗伤：一个失去自信的年轻人，在陌生的城市、陌生的学校里，慢慢重新学会和人相处，然后在某个雨后的夜晚，发现那个一直关照着自己的人，正是童年时最好的朋友。

# 一、作者与原作

## 1.1 基本信息

| 项目 | 内容 |
|------|------|
| **原名** | 無職転生 〜異世界行ったら本気だす〜 |
| **作者** | 不讲理不求人（理不尽な孫の手） |
| **插画** | 白鹰（シロタカ） |
| **网络连载** | 成为小说家吧，2012年11月 – 2015年4月 |
| **实体书** | MF books（KADOKAWA），2014年1月起；最终卷于2022年11月25日发售 |
| **累计发行** | 2021年11月突破960万部 |

《无职转生》在“成为小说家吧”上从2013年10月到2019年2月一直保持着累计排行榜第一名，2015年7月获得《这本WEB小说真厉害！》第一名，可以说是“异世界转生”这一类作品的标杆之一。

作者说过，本作受到《惑星公主蜥蜴骑士》和《寄生兽》的影响，**以家庭和人际关系为主轴**，讲述主人公克服前世创伤、逐渐成长的故事。这一点在第二季体现得格外明显：这一季几乎没有“打怪升级”，几乎全是“和人相处”。

## 1.2 一部被争议包围的主角

关于鲁迪乌斯，作者从一开始就知道他会引发争议。前世的他是一个34岁的家里蹲，被兄弟姐妹赶出家门，在大雨里为救几个高中生被卡车撞死；转生之后，他幼年时的种种好色行为，至今都是这部作品被批评最多的地方。

可作者并不介意读者批评，反而希望由观众来评价这个角色。他想描写的，是一个“在学校失败、毁掉了整个人生”的人，如何在新的人生里重新找到机会。**而第二季，恰好就是鲁迪重新“回到学校”的那一季。**

# 三、剧情解析

> ⚠️ 以下内容包含第二季上半部与原作的剧情，未看者请注意。

## 3.1 被“拒绝”之后

第一季的最后，鲁迪与艾莉丝建立了亲密关系，可艾莉丝很快就无声无息地离开了。鲁迪误以为自己被拒绝了，陷入了深深的沮丧。

第二季开场时，他依旧在寻找失踪的母亲塞妮丝，身边也有了新的同伴——但他整个人都是“空”的。海外评论注意到，第二季第一话里，鲁迪几乎没有使用第一季培养出的实力，这正是因为他的孤独困境；也有评论称赞，正是新同伴的出现，让沮丧的鲁迪能继续旅程，并变得更擅长与人相处。第一话的结尾，也被认为比第一季更突显了鲁迪的成长。

更糟糕的是，艾莉丝离开后，鲁迪还患上了ED——这对一个“本性好色”的主角来说，几乎是最残酷、也最讽刺的打击。

## 3.2 拉诺亚魔法大学

在人神的建议下，鲁迪和艾莉娜丽洁一起进入了**拉诺亚魔法大学**，目的之一，就是治疗自己的ED。

这所大学有两百多年历史，用耐魔砖建成，课程从魔术到商业、军事无所不包；对魔术优秀的人，学校会发邀请函，让他们作为特别生入学。鲁迪就是这样入学的。

对一个前世是辍学生的人来说，重新回到校园本身就有特别的意义。鲁迪很珍惜这一世的学习机会，而在大学里，他也第一次真正有了“同学”：横行霸道的兽族公主莉妮亚娜和普露塞娜、身份神秘的七星静香，还有那位总跟在爱丽儿公主身边的“菲兹学长”。前世被霸凌、被孤立的他，这一次终于不再是教室里那个透明人。

## 3.3 “沉默的菲兹”

大学里最受敬仰的人之一，是阿斯拉王国第二公主爱丽儿身边的护卫“**菲兹**”。他戴着墨镜、一头白发，从不开口，释放魔术时也用“无咏唱”，所以被称为“沉默的菲兹”。他曾用计教训过那两位兽族公主，一个人击退了二十多名兽族学生。

而这位菲兹，其实就是**希露菲叶特**。

十岁那年的菲托亚领地转移事件，把希露菲一个人传送到了阿斯拉王宫的高空。她拼尽全力降落，魔力耗尽，头发也因此变成了白色；又误打误撞救下了遇袭的爱丽儿公主，从此女扮男装、化名“菲兹”，成为爱丽儿的守护术师，一路跟着她来到了拉诺亚。

是希露菲向爱丽儿建议，请鲁迪来魔法大学的。她本以为可以顺利相认，可重逢时的鲁迪正处在人生最低谷，对着这位“学长”低声下气、毕恭毕敬，**完全没认出她来**。希露菲满心失望，把到了嘴边的话又咽了回去。

## 3.4 雨后的重逢

爱丽儿明白希露菲的苦衷，安排了好几个计划帮她和鲁迪相认。最后，是一次“情景重现”——借鉴了小时候鲁迪意外脱下希露菲衣服、才发现她是女孩子的那段往事——让鲁迪终于惊觉：那个一直关照自己的“菲兹学长”，就是自己想了多年的青梅竹马。

希露菲也知道了鲁迪来大学的原因之一是治疗ED。她下定决心要帮他。那一夜之后，鲁迪的病好了；他感激希露菲为自己的付出，**决定娶她为妻**。

# 四、角色深度解析

## 4.1 鲁迪乌斯：在低谷里学会依靠别人

第一季的鲁迪，是一个天赋异禀、努力弥补前世的少年；第二季的鲁迪，是一个**第一次真正失去自信的人**。

我觉得这一季最可贵的地方，是它没有让鲁迪靠“变强”走出低谷，而是让他靠“别人”走出来——新的同伴、大学里的朋友、以及希露菲。前世的他就是因为被霸凌、被孤立，才把自己关在房间里；这一世，他终于学会了接受别人的好意。

当然，也有观众不满第二季的鲁迪太过忧郁，战斗表现也比第一季普通。但我反而觉得，这正是这部作品的诚实之处：**一个人从失恋和自我怀疑里走出来，本来就不是一件热血的事。**

## 4.2 希露菲叶特：一直在等他的人

希露菲有1/4的长耳族血统，生来一头与被人忌讳的“斯佩路德族”相同的绿发，从小被欺负。五岁那年，是鲁迪救了她，成为她多年来唯一的朋友，还教她魔术。在鲁迪的教导下，她也学会了“无咏唱”，甚至掌握了鲁迪自己都无法理解的无咏唱治愈魔术和解毒魔术。

七岁时，保罗为了让她真正成长，把两人分开。目睹鲁迪被“绑走”时，她情急之下用水弹攻击了保罗，然后对自己的父亲说，她要变强，**强到能够保护鲁迪**。

所以，当她以菲兹的身份站在鲁迪面前、却没有被认出来的时候，那种失落是可以想象的。她等了那么多年、变了那么多，最后等来的却是一句“学长好”。可她依然没有放弃——这就是希露菲。

茅野爱衣为了配好年幼的希露菲，还专门去公园观察小孩子的行动。从童年那个怯生生的“ルフィ”，到大学里那个沉默寡言的菲兹，再到最后鼓起勇气的希露菲，这一路的声音变化，是这一季最值得细细品味的东西之一。

## 4.3 七星静香：一位神秘的新面孔

七星（塞伦特·赛文斯塔）是这一季新登场的角色，由若山诗音配音。她在大学里的存在感并不张扬，却总给人一种“和周围格格不入”的感觉。她的故事在这一季里只是开了个头，留给后面慢慢揭开——这里就不剧透了。

# 五、入坑建议

- **观看顺序**：第一季上半部 → 第一季下半部 → **第二季上半部（本篇）** → 第二季下半部 → 第三季。
- **不建议跳过第一季**：第二季的一切情绪，都建立在第一季结尾艾莉丝的离开之上；希露菲的回归，也只有看过第一季童年篇的人才能感受到那份分量。
- **对主角有心理门槛的观众**：第二季的鲁迪，比第一季收敛了很多。如果你曾因为第一季鲁迪的种种行为而弃坑，第二季也许能让你重新认识他。

---

# 总结

第二季上半部没有惊天动地的战斗，只有一个跌入谷底的年轻人，和一个一直在原地等他的女孩。它讲的不是如何变强，而是如何在最狼狈的时候，依然有人愿意把手伸过来。

**这一世，鲁迪终于不是一个人了。**
