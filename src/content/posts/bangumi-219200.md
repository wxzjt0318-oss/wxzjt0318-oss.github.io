> “西片，你又上当了哦。”——每一次被捉弄，都是她藏不住的喜欢。

说实话，《擅长捉弄的高木同学》是一部"什么都没发生"的作品——没有异世界、没有超能力、没有三角恋，甚至连"告白"都要等到原作最后一话。每一集讲的，不过是两个初中生在教室后排、放学路上、海边空地里的小小较劲：谁先笑、谁先脸红、谁先认输。

![擅长捉弄的高木同学封面](https://lain.bgm.tv/pic/cover/l/09/16/219200_wFT9i.jpg)
*擅长捉弄的高木同学*

可就是这样一部作品，单行本卖出了一千万册以上，拿下了小学馆漫画赏，动画做了三季加一部剧场版，还拍了真人剧和真人电影。我想原因很简单：**它把"喜欢一个人"最初的那份心动，拍得太真实了**。

# 一、作者山本崇一朗：一张座位表引出的故事

## 1.1 从短篇《换座位》开始

《擅长捉弄的高木同学》的前身，是山本崇一朗在《**月刊少年Sunday**》2012年7月号上刊出的一篇 **8 页短篇《换座位》**（席替え）。故事讲的是视力不好的西片一直换不到前排座位，于是总被同样视力不好、坐在他旁边的高木找机会捉弄。

有意思的是，那时候的画风比现在写实得多，高木的表情也"坏心眼"得多。后来正式连载时，山本把高木的头型画得更圆、眼睛的位置往下调，变成了现在大家熟悉的那张"娃娃脸"——**少了几分恶作剧的狡黠，多了几分让人心动的温柔**。

## 1.2 连载历程

| 时间 | 事件 |
|------|------|
| 2012年7月 | 《月刊少年Sunday》刊载短篇《换座位》 |
| 2013年7月 | 在《月刊少年Sunday-mini》（附录别册）开始连载 |
| 2014年6月 | 小学馆推出单行本第1卷 |
| 2016年8月 | 移籍至《月刊少年Sunday》本志连载 |
| 2021年 | 系列销量突破1000万册，获第66回小学馆漫画赏 |
| 2023年 | 正篇完结（最终话为第176话） |

2017年，这部作品还在全国书店店员票选的推荐漫画里拿到了**第1名**。一部"日常小甜饼"能有这样的成绩，本身就说明了它有多受欢迎。

## 1.3 一个共享的世界

山本崇一朗在连载《高木同学》的同时，还创作了《**札月家的小杏子**》和以三位女孩美奈、早苗、友加里为主角的《**明天星期六**》，并把这几部作品放在**同一个世界观**里。美奈三人组之所以会出现在《高木同学》里，正是因为她们原本就是另一部作品的主角——这种"作品宇宙"的设定，让这个小小的海边小镇显得格外热闹。

## 2.1 基本信息

| 项目 | 内容 |
|------|------|
| **原名** | からかい上手の高木さん |
| **英文名** | Teasing Master Takagi-san |
| **作者** | 山本崇一朗 |

| **中文版** | 尖端出版（繁体）、哔哩哔哩漫画（简体电子版）、长春出版社（简体实体版） |
| **荣誉** | 第66回小学馆漫画赏少年部门 |

## 2.2 故事梗概：一场永远赢不了的较劲

普通的男中学生**西片**，坐在同班女生**高木**的邻座。高木成绩全校前十、体育也好、人缘不错，最大的爱好是——**捉弄西片**。

上课时的小把戏、放学路上的打赌、各种出其不意的"测试"……西片每天都被耍得面红耳赤，于是他发誓一定要捉弄回去。可无论他想出多少计划，最后总会被机灵的高木反将一军。为了激励自己，他甚至给自己定了惩罚：**被捉弄几次，当天就要做几倍的俯卧撑**。

西片不知道的是：高木之所以总捉弄他，是因为**她喜欢他**。她觉得西片慌张的样子特别可爱，也一直在等着——等这个迟钝的少年，有一天能看懂她的心意，然后主动回应。

## 2.3 核心魅力："捉弄"即"告白"

这部作品最巧妙的地方，是把"喜欢"藏在了"捉弄"里：

- 高木的很多捉弄，其实都是**变相的告白**——她会故意说一些暧昧的话，看西片脸红的样子
- 西片每次以为自己"输了"，其实都离高木的心意更近了一步
- 观众是全知视角，**我们比西片更早知道高木喜欢他**，所以每一次捉弄都看得又甜又着急

# 三、动画第一季：小豆岛的夏天

## 3.1 制作信息

| 项目 | 内容 |
|------|------|
| **动画制作** | 新锐动画（Shin-Ei Animation） |
| **监督** | 赤城博昭 |
| **系列构成** | 横手美智子 |
| **人物设定** | 高野绫 |
| **播出时间** | 2018年1月8日 – 3月26日 |
| **话数** | 全12话 |

## 3.2 取景地：作者的故乡小豆岛

原作其实并没有明确的舞台设定，但动画版选择了**原作者山本崇一朗的出身地——香川县小豆岛土庄町**一带作为舞台原型，土庄町立土庄中学校还为动画组提供了特别协力。

所以你在动画里看到的那些海边公路、渡轮码头、山坡上的小路，很多都能在小豆岛找到原型。这份"真实存在的风景"，让高木和西片的日常多了一份温度——**仿佛他们真的就在某个海边小镇上，每天一起走路回家**。

## 3.3 主题曲：翻唱 J-POP 的小巧思

第一季的片头曲是**大原由衣子**作词作曲演唱的《**言わないけどね。**》（虽然我不会说出口），歌名本身就是高木的心声。

而片尾曲是这部作品最有名的巧思：**每隔一两集就换一首，全部由高木的声优高桥李依翻唱经典 J-POP 情歌**：

| 话数 | 曲名 | 原唱 |
|------|------|------|
| 第1–2话 | 《気まぐれロマンティック》 | 生物股长 |
| 第3–4话 | 《AM11:00》 | HY |
| 第5–6话 | 《自転車》 | JUDY AND MARY |
| 第7–8话 | 《風吹けば恋》 | chatmonchy |
| 第9–10话 | 《小さな恋のうた》 | MONGOL800 |
| 第11话 | 《愛唄》 | GReeeeN |
| 第12话 | 《出逢った頃のように》 | Every Little Thing |

每一首都是日本家喻户晓的恋爱歌曲，配上片尾高木骑着自行车、在海边散步的画面，就好像在听高木用别人的歌，唱自己说不出口的心事。这个设计后来延续到了第二季和第三季，成了系列的招牌。

## 3.4 主要角色配音演员

### 高木 CV：高桥李依

高木的声音难点在于"**游刃有余**"——她捉弄西片的时候总是不急不躁、带着笑意，好像一切尽在掌握。高桥李依的演绎轻柔又带一点调皮，尤其是那种"嗯？西片，你在想什么呢？"的尾音上扬，几乎成了高木的标志。而在少数几次高木自己也害羞起来的时刻，她声音里那一点点乱了阵脚的慌张，更是让人心动。

### 西片 CV：梶裕贵

西片的戏份几乎全是"慌张"：被捉弄时的语无伦次、想反击时的自信满满、被识破后的崩溃大叫。梶裕贵把这种单纯直率的少年感演得特别有喜感，很多西片的内心独白，光听声音就能让人笑出声。

# 四、第一季看点梳理

> ⚠️ 本节包含第一季动画的情节描述。

第一季没有贯穿始终的主线，而是由一个个独立的小故事组成，大致可以分成几类：

## 4.1 教室里的较劲

橡皮擦上写名字的传说、课本里藏着的小纸条、"谁先笑谁就输"的鬼脸比赛……教室后排这两个座位，是高木和西片最主要的"战场"。这些小游戏看似幼稚，却最能体现两人的关系：**西片总是很认真地想赢，高木总是很认真地想看他输**。

## 4.2 放学路上

一起走路回家，是两人每天的固定节目。沿着海边的公路、穿过小镇的街道，他们打赌、聊天、偶尔沉默。很多最甜的瞬间，都发生在这条回家的路上——比如那把被高木"借走"的伞，比如一起看海的傍晚。

## 4.3 美奈、早苗、友加里

三个女孩的小剧场穿插在每一集之间：天然呆的美奈、扑克脸的早苗、向往恋爱的友加里，她们的日常和高木、西片的故事交替出现，节奏很轻快。

## 4.4 中井与真野

班上已经在交往的一对小情侣，是西片眼中"别人家的恋爱"。他们的存在，让西片偶尔会意识到："原来恋爱是这个样子的"——然后再被高木狠狠捉弄一次。

# 五、主要人物深度介绍

## 5.1 高木：等一个人看懂自己

### 基本档案

| 项目 | 内容 |
|------|------|
| **年龄 / 血型** | 13岁 / O型 |
| **特点** | 成绩全校前十，运动也好，擅长做鬼脸 |
| **爱好** | 看漫画、散步 |
| **CV** | 高桥李依 |

高木最打动人的地方，是她的**耐心**。她早就知道自己喜欢西片，也早就看出西片对她有好感，可她不着急，也不催他。她用一次次捉弄去试探、去暗示，然后安静地等着——等这个迟钝的少年有一天自己明白过来。

原作最终话（第176话）的夏日祭典上，她终于等到了西片的告白，也说出了自己的心意。而在衍生作品里，她和西片结了婚，有了一个和她长得很像、却和西片一样容易慌张的女儿小千。

## 5.2 西片：输给了喜欢

### 基本档案

| 项目 | 内容 |
|------|------|
| **年龄** | 13岁 |
| **特点** | 单纯、容易害羞、容易慌张 |
| **爱好** | 漫画、电玩，爱情漫画《单恋100%》的忠实读者 |
| **CV** | 梶裕贵 |

西片是那种"一眼就能看穿"的男孩：开心、生气、害羞都写在脸上。他每天想着怎么捉弄回去，却从没意识到，自己在意的从来不是输赢，而是高木。

有个很可爱的细节：入学典礼那天，西片因为把高木遗失的手帕送去办公室而迟到了——**他们的故事，其实从第一天就开始了**。

# 八、总结：每一次输，都是一次心动

《擅长捉弄的高木同学》没有宏大的世界观，也没有曲折的剧情，它只是在讲一件很小的事：**一个女孩喜欢一个男孩，用捉弄的方式说了一遍又一遍**。

如果你正在找一部可以在睡前放松看、看完会心一笑的作品，第一季一定适合你。它会让你想起初中时坐在后排的那个人，想起放学路上那些说不出口的话。

**西片输了很多次，但他赢得了最重要的那一个人。**
