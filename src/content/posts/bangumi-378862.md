> 沉迷游戏的家里蹲哥哥，一觉醒来变成了初中女生——始作俑者，是他那位天才科学家妹妹。

说实话，第一次听说《别当欧尼酱了！》的时候，我对它的印象基本停留在“那部汉化组玩梗玩疯了的性转漫画”。毕竟这部作品在中文圈的走红，很大程度上要归功于一群放飞自我的汉化组；它的标题本身，听上去也像个不太正经的段子。

![别当欧尼酱了！封面](https://lain.bgm.tv/pic/cover/l/7e/ca/378862_24TnR.jpg)
*别当欧尼酱了！*

可真正看完动画之后，我才发现自己完全想错了。它当然很“萌”，也当然有不少让人哭笑不得的擦边镜头，可它的内核其实非常朴素：**一个因为自卑而把自己锁进房间的哥哥，被一个笨拙地爱着他的妹妹，一点一点拉回了阳光底下。**

# 一、作者与原作：一部从pixiv走出来的同人漫画

## 1.1 基本信息

| 项目 | 内容 |
|------|------|
| **原名** | お兄ちゃんはおしまい！ |
| **简称** | 别酱了（おにまい） |
| **作者** | 猫豆腐（ねことうふ） |
| **首发** | 2017年2月25日起于pixiv连载，每月更新一话 |
| **商业连载** | 一迅社《月刊ComicREX》，2018年8月号起刊载，2019年6月号起正式连载 |
| **商业单行本** | 一迅社 ID COMIC |
| **累计发行** | 商业版截至2023年12月突破120万部 |

《别当欧尼酱了！》最初是一部同人漫画。猫豆腐从2017年2月开始在pixiv上每月更新一话，通常在每月最后一个周六更新；2018年1月起在niconico静画同步刊载；同年5月的COMITIA 120上，出版了第一本实体同人本。

到了2018年6月，一迅社开始在《月刊ComicREX》上刊载本作，并整理出版商业单行本；2019年6月号，正式宣布连载。从一部个人发表的同人作品，一路走到商业杂志连载、再到TV动画化，这样的经历本身就很少见。

## 1.2 一段与中文圈的奇妙缘分

这部作品在中文圈的人气，有一半要归功于汉化组。萌娘百科写得很直白：人气汉化组放飞自我的翻译和天马行空的玩梗，与本就离谱的原作产生了剧烈的化学反应，在一片欢声笑语中积累了庞大的人气。

而这股热度，也引起了猫豆腐对华语圈的注意。他甚至通过汉化组传话感谢粉丝，又在一系列投票调查之后，决定**自费推出繁体中文电子版**——2018年1月27日，第一卷繁中电子版在BOOTH上架。考虑到支付方式对中国大陆用户不友好，他又先后上架到支持支付宝的ONE DOUJIN等平台。之后，本作与布卡漫画签下了官方简体中文连载协议，布卡漫画破产后，改在哔哩哔哩漫画继续连载。

一位日本漫画家为了海外读者自掏腰包做翻译，这件事在当时被ACG媒体纷纷报道。我觉得这也解释了为什么这部作品在中文圈的口碑总是格外温暖：**作者是真的在乎看他漫画的人。**

| 时间 | 荣誉 |

# 二、剧情简介：哥哥，结束了

绪山真寻原本是个沉迷色情游戏的家里蹲。某天，他喝下了妹妹绪山美波里研制的怪药，醒来后发现自己变成了一个女孩子——而且还是个初中生模样的小女孩。

美波里是个天才，高中入学没多久就跳级进了大学，平时在家穿着白大褂搞各种古怪研究。她制定了一个“**欧尼酱改造计划**”：用这瓶小药水把哥哥变成女孩子，再按照女孩子的标准管理（调教）他，让他恢复正常、回归社会。为此，她还在真寻的房间里装了摄像头，监视着“哥哥（妹妹）”的一举一动。

从一开始的不安和抗拒，到变得越来越女性化，真寻的一切都在美波里的监视与控制之中。他在家里遇到了美波里的朋友穗月枫，又认识了枫的妹妹穗月椛和椛的青梅竹马樱花朝日，后来甚至以女初中生的身份去上学，成为了她们的同班同学。

标题“お兄ちゃんはおしまい！”，直译过来就是“哥哥结束了！”。**结束的是“哥哥”这个身份，开始的却是一个人重新与世界相处的新生活。**

## 3.1 制作信息

| **美术监督** | 小林雅代 |
| **色彩设计** | 土居真纪子 |
| **音响监督** | 吉田光平 |
| **音乐** | 阿知波大辅、桶狭间有沙 |
| **动画制作** | STUDIO BIND |
| **出品** | “别酱了”制作委员会 |

STUDIO BIND此前以《无职转生》闻名，这一次接手的却是一部完全不同风格的日常喜剧。结果证明，这个选择非常正确。

## 3.2 一部被称赞的“作画盛典”

这部动画最让人惊艳的，是它的画面。《澳门日报》的文章称赞了它角色动作的自然流畅和背景的细致描绘；KAI-YOU的撰稿人太田祥晖说，本作因其对日常生活的细致描绘而引人注目，“虽然由于其性别转换主题，它可能并不适合所有人，但它像是最近的作画盛典的浓缩版，是本季必看的作品”。

在 Niconico 和动画评分网站 Anikore 上，本作都被日本观众评为**2023年冬季最佳TV动画**。

我自己最喜欢的，是它把“日常”拍得很有质感：真寻穿上裙子时那种别扭的小动作、换季时添加的黑色裤袜、厨房里的锅碗瓢盆……很多细节其实和剧情关系不大，可正是这些东西，让这个荒唐的设定显得可信。

## 3.3 关于“修正版”

这部动画还有一个特别的地方：**仅在日本播出未修正版**。日本以外的授权版本，部分集数在画面和声音上都做了修正。第一集播出后，曾有海外平台被发现使用了日本的“正常版”音轨，代理商随后厘清是音轨设定错误，重新修正上架。

这件事本身也说明了这部作品的“两面性”：它的画面精致、故事温柔，可确实也有不少刻意的擦边镜头。英文媒体早期的评价就褒贬不一——有评论者批评第一集的前提和萝莉控主题，但几乎一致认为它的画面和音乐质量上乘。

# 四、故事的几个阶段

> ⚠️ 以下内容包含动画与原作漫画的部分剧情。

## 4.1 第一阶段：家里的“改造”

故事开头，真寻的世界只有一个房间、一台电脑和一堆游戏。美波里的小药水让他变成了女孩子，可他的第一反应还是想维护自己作为男性的尊严。

这一阶段的笑点，几乎都来自“男人的灵魂”和“女孩的身体”之间的冲突：洗澡、穿衣、上厕所、内衣……每一件日常小事都能让真寻手忙脚乱。而美波里就在旁边，一边认真记录“实验数据”，一边满足自己当了多年“想要一个妹妹”的心愿。

## 4.2 第二阶段：穗月枫的到来

转折点是**穗月枫**的登场。她是美波里的初中同学、现役女高中生，成熟温柔，却又热衷打扮，身上总带着各式各样的化妆品。原作里，她在真寻家上厕所时被真寻撞见，随即用一招“怀中抱妹杀”反制了真寻；然后向真寻展示了自己的厨艺，又强行给他化了妆。

枫其实来过真寻家好几次，可因为真寻性转之前一直宅在房间里，所以从没见过面，只知道美波里有个哥哥。真寻干脆告诉她，这个哥哥“已经去到遥远的地方，过上幸福的生活了”。——这句话现在想想，也挺心酸的。

## 4.3 第三阶段：交到朋友

接下来，真寻认识了枫的妹妹**穗月椛**。椛着装偏中性、梳着短短的小辫子，一开始还被真寻当成了男孩子，被朝日取了个昵称叫“椛次郎”。然后是椛的青梅竹马**樱花朝日**，一个天然呆、喜欢运动、说话很直的女孩。

和她们相处的过程，就是真寻重新学习社交的过程。他因为长时间不与社会接触，变得十分怕生；可他毕竟是个成年人，在这群初中生里反而显得更成熟一些——椛就说过，“真寻有时候也会说一些很成熟的话呢”。

## 4.4 第四阶段：重返校园

最后，真寻以初中生的身份走进了学校，成为椛、朝日和室崎美夜的同班同学。这一步对他来说意义重大：**一个因为升学失利而把自己锁在家里的人，又一次坐进了教室。**

原作里，他会因为枫帮自己化妆而被老师教育，会帮同学向喜欢的男生告白；他的社交能力在和朋友们的长期相处中逐渐恢复，虽然有时还是会怕生，但已经比以前好了不少。

# 五、角色深度解析

## 5.1 绪山真寻：被自卑困住的哥哥

萌娘百科对真寻的“过去”只有寥寥几句，却很重要：在还是男性的时候，真寻原本是个**善良温柔、疼爱妹妹的哥哥**。直到美波里逐渐向天才靠拢，周围的压力加上大学落榜，他才开始自暴自弃，把自己锁在家里，沉溺于游戏之中。

维基百科的说法也一样：由于妹妹天资过人、备受瞩目，作为长兄的他感到自卑，升学失利后就宅在了家里。原作第74话里，还有一段小时候的真寻在雷雨天安慰美波里的情节。

所以这部作品真正的主题，其实不是“性转”，而是**自卑**。真寻不是天生的废柴，他是被“优秀的妹妹”压垮的哥哥。而变成女孩子之后，那个“哥哥”的身份连同它背负的压力一起消失了，他反而能重新开始。

一开始，他对性转药是抵触的；可在与朋友们接触之后，因为珍视友谊，他变得不再那么热切地希望变回男性，只是有时候也会想找回自己身为哥哥的尊严。

还有一个小细节：真寻的姓氏“绪山”与日语的“女形”同音（oyama），而“女形”是歌舞伎里男扮女装的演员。作者从起名开始，就把这个角色的命运写好了。

## 5.2 绪山美波里：笨拙的妹妹

美波里是这部作品里最容易被误解的角色。表面上，她给哥哥下药、装摄像头监视、把哥哥当实验对象，怎么看都是个“病娇”；可萌娘百科的描述是：她的“改造计划”，是**为了让哥哥恢复正常、回归社会当个正经人**——当然，也是为了满足她自己的妹控需求。

她还是初中生的时候就非常喜欢哥哥，为了得到哥哥的鼓励而拼命学习，“可以说是努力过头了”。头上的发卡，是她初一考试取得好成绩时哥哥送的。小学时，她曾对枫说过自己也想要个妹妹——这个心愿，后来成了“欧尼酱改造计划”的种子。

这里有一个很残忍的因果：**美波里努力是为了让哥哥夸她，可正是她的优秀压垮了哥哥。**所以当她看到哥哥有所改变时，会欣慰地哭出来；从哥哥那里收到自制的饼干和情人节巧克力时，也会感动得哭出来。她想要的，从来不是一个实验品，而是那个曾经温柔地夸她的哥哥回来。

## 5.3 穗月枫与穗月椛：另一对姐妹

穗月姐妹是绪山兄妹的“镜子”。

枫是个妹控，喜欢和椛以及真寻亲密接触，在家务上是美波里的学习对象；她很羡慕美波里的“姐（兄）妹之情”。有意思的是，她初中时其实不怎么在意打扮，样子和现在的椛很像，是升上高中后才开始在意穿着打扮的。

椛则是真寻在学校里最亲近的朋友。她和真寻一样不习惯穿裙子的感觉，与真寻认识后经常和她在一起，对她有着微妙的关注。

一对是因为药水才变成的“姐妹”，一对是天生的姐妹，两组关系放在一起，让这部作品的“家庭感”更加立体。

## 5.4 樱花朝日与室崎美夜

朝日是椛的青梅竹马，天然呆、喜欢运动、说话直来直去，她叫美波里“博士”；美夜是轻度百合控，身材比真寻她们几个都要成熟。她们俩让真寻的校园生活热闹了起来，也让这部作品在“兄妹”之外，多了一层青春群像的味道。

# 六、原作与动画的小差异

- 美波里携带外出的药水，原作里装在50cc的棕色试剂瓶中，动画版换成了透明安瓿瓶。
- 枫的身材，在动画里比漫画“史诗级加强”了（萌娘百科原话）。
- 真寻的发型在动画里变化很多，经常能看到不同的造型。
- 关于小药水，原作还有不少设定：它会让服药者“返老还童”，药效有时效性，失效时真寻会短暂变回男性；而且**切勿与温泉搭配使用**。

# 七、入坑建议

- **适合的观众**：喜欢日常系、萌系画风、对精致作画有要求的观众。这部动画的“作画密度”在同类型里非常少见。
- **需要注意的地方**：性转主题和部分刻意的擦边镜头，确实会让一些观众感到不适，评价也因此两极分化。如果你对这类内容比较敏感，可以先看第一集再决定。
- **看完动画之后**：原作漫画仍在连载，故事已经走得很远——真寻升上了二年级，枫也考进了美波里的大学。此外还有广播剧CD和官方同人集可以补。

---

# 总结

《别当欧尼酱了！》表面上是一个荒唐的性转喜剧，底子里却是一个关于自卑与和解的家庭故事。哥哥被优秀的妹妹压垮，妹妹用最笨拙的方式把哥哥拉回来；当“哥哥”这个身份结束的时候，那个被压抑已久的、善良温柔的人，终于重新走到了阳光下。

**哥哥结束了——可这对兄妹之间的故事，才刚刚开始。**
