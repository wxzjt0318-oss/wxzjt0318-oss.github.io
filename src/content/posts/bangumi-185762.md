> 八年前被叫作“猪脚”的胖小子回来了——这一次，他要让那位大小姐爱上自己，再狠狠地甩掉她。

说实话，《政宗君的复仇》这个标题第一次映入眼帘的时候，我以为它是一部热血向的“打脸爽番”——胖子逆袭、帅哥归来、把当年欺负自己的人踩在脚下，听起来就很解气。结果看完才发现，这部作品真正的主题，根本不是“复仇”，而是**一个被一句话改变了人生的少年，怎么发现那句话从一开始就不是对方说的**。

![政宗君的复仇封面](https://lain.bgm.tv/pic/cover/l/05/bf/185762_xyM3h.jpg)
*政宗君的复仇*

它前半段是标准的恋爱喜剧：政宗满脑子“让她爱上我再甩掉她”，结果每次都把自己绕进去；爱姬吃得比谁都多、凶得比谁都狠，却在某些瞬间软得一塌糊涂。可故事越往后，你越会注意到那个一直站在旁边、帮政宗出谋划策的小女仆——这部作品最大的反转，就藏在她那张无辜的脸后面。

# 一、原作：竹冈叶月 × Tiv 的“复仇恋爱喜剧”

## 1.1 基本信息

| 项目 | 内容 |
|------|------|

| **英文名** | Masamune-kun's Revenge |
| **原作** | 竹冈叶月 |
| **作画** | Tiv |
| **连载杂志** | 一迅社《月刊 Comic REX》 |
| **连载时间** | 2012年12月号（10月27日发售）—2018年8月号（6月27日发售） |
| **中文版** | 东立出版社（繁体）、哔哩哔哩漫画（简体电子版） |
| **累计发行** | 2023年12月突破380万册 |

原作由**竹冈叶月**担任脚本、**Tiv**负责作画。Tiv 笔下的女孩子线条干净、表情丰富，爱姬“残虐公主”的冷笑和偷偷大吃时的满足感，都画得极有反差。

## 1.2 外传与续篇

本篇完结之后，故事并没有真正结束：

- **《政宗君的复仇 after school》**：《月刊 Comic REX》2018年11月号至2019年3月号短篇连载
- **《政宗君的复仇 -engagement-》**：大学生篇，2023年4月26日起在《comic HOWL》连载
- **《政宗君的复仇 0》**：收录政宗、爱姬、吉乃、宁子、小十郎、妙等人的独立短篇
- **《特别篇 租借男友 政宗君》**：先以电子版推出，后刊登于《月刊 Comic REX》2020年10月号

此外还有竹冈叶月亲自执笔、Tiv 插画的小说版（一迅社文库，2013年12月20日发售），以及结城心一作画的搞笑外传漫画《政宗君的○○○》和多位画师参与的漫画选集。

## 1.3 名字里的伊达家

这部作品有个很好玩的小设计：**大部分角色的名字原型，都来自战国大名伊达政宗及其妻妾、部下**。

- 真壁政宗 ← 仙台藩初代藩主**伊达政宗**
- 安达垣爱姬 ← 伊达政宗的正室**田村爱姬**
- 小岩井吉乃 ← 侧室**饭坂之局**
- 藤之宫宁子 ← 侧室**新造之方**
- 双叶妙 ← 侧室**妙伴**
- 朱里小十郎 ← 近习**片仓景纲**（片仓小十郎）

知道这一层之后再看角色关系，会有种“历史在开玩笑”的感觉——正室和侧室们围着政宗打转，倒也算“名副其实”。

# 二、故事梗概：一个胖子的八年

政宗小时候是个被大家欺负的懦弱小胖子。有一天，一个美少女千金给他起了个丢脸的绰号——“**猪脚**”（豚足）。为了让他改头换面，外公把他接回老家，进行了整整**八年**的魔鬼训练。

八年后，摇身一变成为大帅哥的政宗，改掉了原来的姓氏，以“**真壁政宗**”的身份回到这座小镇，转入私立八坂高中。他的目标只有一个：让那位千金——**安达垣爱姬**——在不知道他真实身份的情况下爱上他，然后再甩掉她，作为复仇。

问题是，爱姬现在是全校闻名的“**残虐公主**”：长得漂亮、被无数男生告白，却每次都狠狠拒绝，还要给对方起个难听的外号。而唯一知道政宗秘密的，是爱姬身边的小女仆**小岩井吉乃**。她主动提出要帮政宗复仇，被政宗尊称为“师父”。

“为了向那个混蛋女人复仇，我又回到这个镇上啦……！”——复仇恋爱喜剧，就此开幕。

# 四、剧情解析：复仇计划是怎么失控的

> ⚠️ **以下内容涉及原作剧情，未看过的朋友请注意**

## 4.1 第一阶段：完美的复仇计划

政宗的复仇思路很简单：**接近、示好、让对方心动、然后甩掉**。他靠着八年锻炼出来的外表，以及吉乃这个“内应”提供的情报，一步步靠近爱姬。

但现实总不按剧本走。他很快发现了爱姬最大的秘密：这位“残虐公主”**食量惊人**，为了不让别人知道，每天都让吉乃买来大量午餐，然后一个人躲进仓库里吃。秘密被撞破之后，两人的距离反而一下子拉近了。

更搞笑的是第一次约会：爱姬极度信任吉乃，结果被吉乃“骗”着打扮成了魔法少女动画里的 Cure White。复仇者和被复仇者，一个比一个狼狈。

## 4.2 第二阶段：越来越多的“变数”

随着故事推进，政宗身边的变数越来越多：

- **藤之宫宁子**突然转进他的班级，小时候在藤之宫家的婚宴上就认识政宗，掌握着“他就是猪脚”的秘密，说的话却很少是真的
- 班长**双叶妙**热心地帮他画学校导览图，还对他和小十郎的“配对”很感兴趣
- 爱姬的婚约者**雅宗兼次**登场，因为体型和过去的政宗相似、名字也容易混淆，竟被爱姬误认为是小时候的“猪脚”

政宗一边要维持复仇计划，一边又要应付这些人，渐渐地，连他自己都分不清：**自己到底是想让爱姬喜欢上“真壁政宗”，还是自己已经喜欢上了爱姬**。

## 4.3 学园祭：白雪公主的吻

学园祭是整部作品的高光之一。为了帮爱姬所在的 A 班脱离困境，政宗不顾自己重度发烧，临时扮演话剧《白雪公主》里的王子，并与爱姬接吻，还被全校票选为“最佳情侣”。

而也正是在校庆时，吉乃第一次意识到：**自己喜欢上了政宗**。

## 4.4 八年前的真相

故事真正的转折，在原作后半段揭开。

修学旅行去法国时，爱姬向政宗解释自己无法接受他的原因——小时候经历过一次失去心爱之人的悲伤，不想再体验一次。可她回忆里的往事，和政宗记忆中的细节对不上：**爱姬清清楚楚地记得小时候的点点滴滴，却唯独不记得给政宗起过“猪脚”这个外号**。

回到日本后，政宗终于想明白：当年他以为安达垣家只有爱姬一个同龄孩子，可实际上，吉乃也住在宅邸里，只是因为出水痘没法出门。而一直叫他“猪脚”的人，是吉乃。

**吉乃为了独占爱姬，假扮成爱姬，叫了他“猪脚”。**

这一句谎言，让政宗改姓、消失、发起复仇，也让被政宗“不辞而别”的爱姬觉得自己被背叛，大哭一场、暴饮暴食，从此变成了“残虐公主”。八年后，满怀内疚的吉乃主动帮政宗复仇，是想让两人和好如初——却在这个过程里，自己也喜欢上了政宗。

## 4.5 结局

得知真相后，政宗对爱姬的恨意消失了。他在爱姬差点被雅宗的谎言欺骗时赶到，揍了雅宗一拳——雅宗兼次其实是为了复兴没落家族、女扮男装接近爱姬的女孩子。政宗在戳破谎言时，不小心说出了正式交往的请求，而爱姬接受了。

最终，政宗在吉乃和爱姬之间选择了爱姬。吉乃在漫画第48话因爱姬的鼓励向政宗告白，被拒绝了。

# 五、角色深度解析

## 5.1 真壁政宗：复仇者也是恋爱新手

政宗特别害怕蜘蛛，熟读妹妹收藏的少女漫画《蔷薇之瞳的类固醇》，把里面的套路当成恋爱教科书。他的“复仇”从头到尾都带着一股少年气的笨拙——**他嘴上说要甩掉爱姬，却每一次都在关键时刻站到她身边**。

他最大的魅力不是帅，而是“真”：真的会生气、真的会心软、真的会在发着高烧的时候去演王子。

## 5.2 安达垣爱姬：被抛下的女孩

爱姬小时候因为父母不和而感到孤独。有一天，她偶然把政宗从欺负他的人手里救了出来，两人成了朋友；在父母要离婚、觉得自己已经没有机会追求幸福的时候，是政宗的陪伴和鼓励让她喜欢上了他。

可政宗后来不辞而别。**“残虐公主”的冷酷和那份惊人的食量，都是那次被抛下留下的伤**。看懂这一点之后，再回头看她拒绝男生、给人起外号的样子，只会觉得心疼。

## 5.3 小岩井吉乃：这部作品真正的“主角”

吉乃出身于世代侍奉安达垣家的管家一族，总戴着白色双发卡，表面沉默寡言、像只无害的小动物，实际上相当腹黑。

她是整个故事的起点，也是整个故事的“罪魁祸首”。但这部作品最妙的地方在于，它没有把吉乃写成单纯的反派：**她因为太想独占爱姬而撒了谎，又因为内疚而想弥补，最后却在弥补的过程中失去了自己的心**。她告白被拒的那一刻，可能是全篇最让人难受的场面。

## 5.4 藤之宫宁子与其他人

- **藤之宫宁子**：身体不好、饭前要吃大量营养补充品，小时候和政宗一样胖乎乎的。政宗曾想过，如果不是要向爱姬报仇，或许会喜欢宁子这类女孩
- **双叶妙**：游泳社的班长，喜欢照顾人，曾向政宗告白过一次
- **朱里小十郎**：外表像女孩的男生，成绩不好、爱吃甜食，喜欢宁子
- **雅宗兼次**：爱姬的“婚约者”，其实是为了家族和生病的妹妹而女扮男装的女孩

## 5.5 让喜剧更热闹的配角们

除了恋爱主线上的几位，这部作品的配角也撑起了大量笑点：

- **“爱姬亲卫队”三人众**：剑道部一年级的暴力担当**金子园香**（伊濑茉莉也）、被称为“八坂高校影之权力者”的原学生会副会长**木场菊音**（伊藤加奈惠）、出谋划策担当兼班级委员长**水野鞠**（佐藤聪美）。她们对政宗充满敌意，又一次次被他耍得团团转
- **早濑绢江**：政宗的母亲，42岁却外表年幼，和儿子出门购物会被当成妹妹。小时候给政宗做大量高糖高油的食物，正是他发胖的“元凶”
- **早濑千夏**：政宗的妹妹，中学二年级，活泼开朗、怎么吃都不胖，常常闯进哥哥的房间吐槽他的怪异举动
- **由井崎翠**：爱姬父亲的女秘书，喝醉后个性很糟，一度看不惯政宗和爱姬的感情，后来被政宗的温柔打动转为支持

# 六、这部作品好在哪里

## 6.1 “复仇”是一层糖衣

很多恋爱喜剧靠“误会”推动剧情，但《政宗君的复仇》的误会是**结构性**的：整个故事的出发点，就建立在一个错误的前提之上。观众一开始和政宗站在同一边，跟着他一起恨爱姬、一起设计陷阱；等到真相揭开，你会发现自己也被那句“猪脚”骗了很久。

这种“读者和主角一起被骗”的写法，让后半段的反转格外有冲击力。回头重看前几集，吉乃的每一次“帮忙”、每一个意味深长的眼神，都变成了伏笔。

## 6.2 没有真正的坏人

另一点让我很喜欢的是：这部作品里几乎没有纯粹的恶人。吉乃撒谎是因为太依恋爱姬；雅宗兼次女扮男装接近安达垣家，是为了复兴家族、为生病住院的妹妹筹医药费，最后靠在学校福利社打工、出售家族老宅来偿还欠款；就连对政宗冷嘲热讽的亲卫队，也只是太喜欢她们的公主。

**每个人都有自己的“复仇”或“执念”，而故事最后让他们一个个放下。** 这也是它能在热闹的喜剧外壳下，留下一点余温的原因。

## 6.3 动画的取舍

动画第一季的节奏明显偏向“喜剧＋心动”，把政宗的心声吐槽、爱姬的反差萌和各种翻车场面放在了最前面。对于第一次接触这部作品的观众来说，这是一个很友好的入口；至于故事后续的走向，则要交给续作与原作漫画继续回答。

# 总结

《政宗君的复仇》用了一个很“爽番”的开头，讲了一个很“苦”的故事。一句童年的谎言，让三个人各自背着伤走了八年：一个拼命变强想要报复，一个把自己变成了刺猬，一个在愧疚里越陷越深。

政宗以为自己是复仇者，最后才发现，他要找的从来不是报复的对象，而是当年那个把他从欺负里救出来的女孩。

**复仇的尽头不是胜利，而是终于看清了——自己恨错了人，也爱对了人。**
