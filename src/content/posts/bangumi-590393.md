> “喜欢女童向动画又怎样？”——偏偏就有辣妹，愿意坐下来和他一起聊。

说实话，"辣妹对阿宅很温柔"这个梗在网上流传了很多年，大多数人提起它的时候都带着点自嘲——现实里哪有这种好事。所以当一部作品直接把标题写成《没有辣妹会对阿宅温柔!?》的时候，那个问号就显得格外有意思：它好像在说，"真的没有吗？"

而这部作品的回答很温柔：辣妹也是人，阿宅也是人，喜欢的东西一旦对上了，所谓的"种姓"就没那么重要了。

# 一、作者与原作

## 1.1 原作基本信息

| 项目 | 内容 |
|------|------|
| **中文名** | 没有辣妹会对阿宅温柔!?（又译：哪里有温柔对待阿宅的辣妹!?） |
| **原名** | オタクに優しいギャルはいない!? |
| **英文名** | Gals Can't Be Kind to Otaku!? |
| **原作** | のりしろちゃん |
| **作画** | 鱼住さかな |
| **连载杂志** | 《月刊COMIC ZENON》 |
| **连载时间** | 2021年8月25日起 |
| **单行本** | 2022年3月19日起由 Coamix 发行 |

原作由のりしろちゃん负责故事、鱼住さかな负责作画，2021年8月在《月刊COMIC ZENON》开始连载。官方给它的定位是"阿宅遇上辣妹的'喜欢'相交织的校园种姓恋爱喜剧"。

## 1.2 剧情简介

高中生**濑尾卓也**个性内向，是个喜欢面向年轻女孩的冷门动画、却没法大声说出口的御宅族。坐在他前面的同班同学**伊地知琴子**和她的朋友**天音庆**，则是光鲜亮丽的辣妹，和卓也的性格截然相反。

一次偶然的机会，琴子向卓也借了橡皮擦。起初卓也和她们待在一起浑身不自在，但随着庆开始看卓也喜欢的动画、琴子也渐渐产生兴趣，三个人的关系慢慢变得亲密起来。两个女孩都渐渐喜欢上了卓也——而卓也本人，对此浑然不觉。

# 三、角色深度解析

## 3.1 濑尾卓也：不敢大声说"喜欢"的阿宅

卓也是本作的主角，最喜欢的是少女向动画《闪亮萌宠》（简称"闪萌"）。他不擅长人际交往，尤其不擅长和辣妹相处，却在机缘巧合下和天音庆、伊地知琴子有了交集——两人都直接叫他"阿宅"。

他的学业成绩很差，也知道自己需要学习，但一感到沮丧就会沉迷动画来逃避现实。他的爱好是画画，经常把作品发到社交平台上。

卓也身上最打动人的，其实是那种"喜欢一样东西却不好意思说"的心情。对很多观众来说，这种心情太熟悉了。而这部作品要做的，就是让一个这样的人发现：原来说出来，也会有人听。

## 3.2 天音庆：外冷内热的"隐藏阿宅"

庆拥有模特般冷艳的外表，篮球打得很好，国中时在全国大赛中表现出色，却因为再怎么打得好也始终冷静、不露笑容，被人戏称为"铁面人"。她看起来很聪明，成绩却不太好；讨厌花椰菜；个性比较内敛。

她其实是个宅女。为了掩饰，她总说自己是"为了妹妹才喜欢动漫"——但卓也早就看穿了。一聊到动漫，她就会兴奋起来，说话变得直率，有时甚至会不自觉地说出些奇怪的话。

庆非常珍惜和卓也的友谊，也很感激能找到一个可以坦诚分享爱好的人。随着时间推移，这份感激慢慢变成了恋情。**冷面辣妹+隐藏阿宅**，这种反差就是她最大的魅力。

## 3.3 伊地知琴子：会考虑结婚的认真辣妹

琴子个性随和，家里人口多，常常帮忙做家务——她是五个兄弟姐妹中的老三，上有两个哥哥，下有两个弟弟。她邀请庆去游戏厅后，两人成了朋友。

和庆正好相反，琴子沟通能力强、成绩很好，唯独运动不太行。她待人友善，非常不想被人讨厌；对爱情的看法很认真，认为如果恋爱，就应该考虑结婚。她思想很开放，很快理解了庆和卓也的爱好，甚至自己也产生了兴趣。

放学回家后，她要帮忙照顾弟弟、补贴家用，那时的她戴着眼镜、头发凌乱——卓也见过她这副素颜，让她很尴尬。其实她内心很欣赏卓也的诚实和善良，也为他没有知心朋友而难过。和庆一样，她也渐渐喜欢上了卓也。

如果说庆是"同好"，那琴子就是"理解者"。一个和卓也有共同语言，一个看得见卓也的好，三角关系的张力就在这里。

## 3.4 雨宫纱优：被当成"妹妹"的小学生

纱优住在天音家隔壁，正是庆早期用来否认自己是阿宅时提到的那个"妹妹"本人。她就读于东小学三年四班，实际上是庆母亲朋友的孩子。她厨艺精湛，常在庆的父母上班时过来帮忙做饭；喜欢下将棋，也很擅长电子游戏。作为小学生，她心思相当成熟，很喜欢庆和卓也之间的关系——某种意义上，她是这段感情最热心的"观众"。

## 3.5 伊地知一家

- **伊地知弦一郎**：五兄妹中的大哥，IT工程师。做事有点粗枝大叶，习惯用按太阳穴的"弦哥特别技"对付弟妹，但骨子里非常珍视家人，是伊地知家最暖心的存在。
- **伊地知翔**：琴子的弟弟，小学二年级，排行第四，外表和个性都像琴子一样开朗活泼。
- **伊地知响**：最小的弟弟，小学一年级。

翔和响都暗恋纱优，也都以为卓也是姐姐琴子的男朋友。伊地知家的热闹，是琴子"随和、顾家"性格的来源，也给校园主线之外加上了一层家庭喜剧的温度。

# 四、看点与入坑建议

## 4.1 打破"种姓"的温柔

所谓"校园种姓"，指的是学校里那种看不见却真实存在的阶层感：辣妹在顶层，阿宅在角落。本作的有趣之处在于，它并不否认这种阶层感的存在，而是让人物一点点跨过去——借一块橡皮擦、一起看一部动画，距离就这样慢慢缩短。

## 4.2 两位女主，两种喜欢

庆的喜欢来自"终于有人懂我"，琴子的喜欢来自"我看得见你的好"。两种感情都很真诚，也都很有说服力，这让三角关系不至于沦为单纯的"选谁"，而是变成两种不同的心意如何被回应。

## 4.3 适合谁看

- 喜欢**辣妹×阿宅**题材的观众；
- 曾经有过"喜欢的东西说不出口"体验的观众；
- 喜欢轻松、甜度适中的校园恋爱喜剧的观众。

全12话，一季看完没有负担。

---

# 总结

《没有辣妹会对阿宅温柔!?》的标题是个问句，而整部作品就是在慢慢给出答案：辣妹会不会对阿宅温柔，取决于她是不是真的看见了这个人。

**喜欢的东西被人认真听完的那一刻，大概就是温柔本身。**
