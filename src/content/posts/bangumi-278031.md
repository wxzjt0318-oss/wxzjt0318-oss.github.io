> 史莱姆建立的魔物之国日益壮大，而利姆路必须面对的，是人类与魔王都无法忽视的选择。

说实话，看完第一季的时候，我对《关于我转生变成史莱姆这档事》的印象一直是“异世界版模拟城市”：收哥布林、给大家起名字、盖房子、做温泉、搞外交，史莱姆利姆路像个好脾气的社长，一路顺风顺水。直到第二季开播，我才意识到——**之前那些岁月静好，都是在为这一刻铺垫**。

![关于我转生变成史莱姆这档事 第二季封面](https://lain.bgm.tv/pic/cover/l/e6/78/278031_skvSD.jpg)
*关于我转生变成史莱姆这档事 第二季*

第二季第1部分，是这部作品第一次认真地问观众：一个想和所有人好好相处的魔物，如果别人不愿意和你好好相处，你该怎么办？它给出的答案，至今仍是整个系列里最有分量的一段。

# 一、作品来历：从网络小说到大型系列

## 1.1 原作小说

《关于我转生变成史莱姆这档事》（日语：転生したらスライムだった件，简称“転スラ”）的作者是**伏濑**。它最初是2013年2月20日开始在小说投稿网站“成为小说家吧”上连载的网络小说，点阅次数超过1亿4000万，登上过该网站累积综合排名第一。

2014年5月，作品在修改部分情节后由微杂志社（GC NOVELS）发行书籍版，插画由**みっつばー**绘制。书籍版和网络版在剧情上有不小的改动，所以“web 版”和“文库版”在粉丝口中常常是两套话题。

## 1.2 漫画与动画

2015年3月，由**川上泰树**作画的同名漫画开始在《月刊少年天狼星》连载，2022年还获得了“讲谈社漫画奖”。值得一提的是，**TV 动画正是以川上泰树的漫画为原作改编的**——这也是动画分镜和节奏里常常能看到漫画影子的原因。

| 项目 | 内容 |
|------|------|
| **原作** | 伏濑（网络小说 / GC NOVELS 书籍版） |
| **插画** | みっつばー |
| **漫画** | 川上泰树（《月刊少年天狼星》） |
| **系列累计发行量** | 2021年9月突破2700万本，2022年1月突破3000万本，2023年2月突破4000万本 |

除了正篇，它还衍生出《转生史莱姆日记》《魔物之国的漫步指南》等一大串外传漫画，以及游戏、舞台剧、管弦音乐会——可以说是近十年最成功的异世界 IP 之一。

# 二、第二季第1部分的基本信息

## 2.1 播出与制作

| 项目 | 内容 |
|------|------|
| **原名** | 転生したらスライムだった件 第2期 |
| **播出时间** | 2021年1月12日起 |
| **话数** | 第1部分全12话（第二季共24话，分割为两个季度播出） |
| **监督** | 中山敦史 |
| **人物设定** | 江畑谅真 |
| **动画制作** | 8bit |

TV 动画第一季于2018年10月开播，第二季则在两年多后的2021年1月回归，并采用了**分割两季度**的播出方式：第1部分在1月开播，第2部分在同年7月接续。在第1部分开播前一周的2021年1月5日，官方还先播出了一集特别篇《闲话：日向·坂口》，提前把一位关键人物推到了观众面前。

在第一季和第二季之间，外传《转生史莱姆日记》的动画也在2021年4月播出，所以这一年对史莱姆粉丝来说几乎是“全年无休”。

## 2.2 声优阵容

| 角色 | 声优 |
|------|------|
| 利姆路·坦派斯特 | 冈咲美保 |
| 大贤者 | 丰口めぐみ |
| 维鲁多拉·坦派斯特 | 前野智昭 |
| 红丸 | 古川慎 |
| 朱菜 | 千本木彩花 |
| 紫苑 | M·A·O |

主角利姆路的声优**冈咲美保**，正是凭借第一季的利姆路而受到关注，并在2020年3月获得了第十四届声优奖新人女优赏。到第二季，她的利姆路已经完全“长”在了这个角色身上：平时软乎乎、爱吐槽，认真起来又冷得让人发毛——这一季恰恰最需要后者。

而**丰口めぐみ**配音的“大贤者”，依旧是那个只有利姆路听得见的冷静解说声。它的存在，在这一季会变得格外重要。

# 三、主题曲：讲故事的人与寻找故事的人

第二季的片头曲是 **TRUE** 演唱的《**Storyteller**》（作词：唐泽美帆，作曲、编曲：津波幸平），片尾曲是 **STEREO DIVE FOUNDATION** 的《**STORYSEEKER**》（作词、作曲、编曲：R·O·N）。一首“讲故事的人”，一首“寻找故事的人”，两首歌名彼此呼应，很有“史莱姆的故事翻开新篇章”的意思。

另外，TRUE 演唱的《**黎明**》（作词：唐泽美帆，作曲、编曲：兼松众）先是用在了第二季的第一支 PV 里，之后又作为第34话的插曲出现。这首歌出现的位置，懂的人都懂——它是这一部分情绪最高点的配乐。

# 四、剧情解析：繁荣之后的第一场风暴

> ⚠️ 以下内容包含第二季第1部分的剧情描述。

## 4.1 魔国联邦的“成功”

经过第一季的积累，利姆路在鸠拉大森林里建立起了一个**不分人类与魔物，大家都能和平快乐生活**的国家——鸠拉·坦派斯特联邦国，也就是魔国联邦。它四通八达的道路和不断展开的新兴事业，让这个魔物之国渐渐成为各国贸易的新枢纽。

问题恰恰出在“成功”上。位于森林西北方的**法尔姆斯王国**，原本靠着作为大陆东西贸易的中继站赚取大量收益，魔国联邦的兴起让它的利益大受损失。在一个封建贵族强权的大国眼里，一个由魔物建立、又抢了自己生意的国家，就是必须拔掉的钉子。

## 4.2 当温柔被当成软弱

这一季最让人难受的地方在于：**魔国联邦从来没有做错什么**。利姆路一直以来对人类的善意与克制，在别有用心的人看来，反而成了可以利用的破绽。

剧情在这里毫不留情。伙伴们倒下的那一刻，第一季累积起来的所有温馨日常，都变成了刺向观众的刀子。也正因为前面那么多集的“种田”，这一刻的失去才显得那么沉重——**我们是真的认识这些角色，真的在乎他们**。

## 4.3 成为魔王

面对失去，利姆路做出了选择。在这个世界里，魔王种需要获得大量人类的灵魂才能“觉醒”为真正的魔王；而利姆路，为了把失去的伙伴找回来，决定走上这条路。

这是整部作品的分水岭。之前的利姆路一直自认是“前世是普通上班族的史莱姆”，对人类始终抱有亲近感；可在这里，他第一次以**魔王**的身份，冷静而决绝地对敌人出手。动画用了大量压抑的色调和留白来处理这一段，配合《黎明》的旋律，几乎是整个系列最震撼的段落。

这一战之后，他身边的伙伴们也随之获得了新的力量——红丸就是在利姆路成为魔王时受到祝福，进化成了更高阶的“妖鬼”。而紫苑和与她一同复活的部下，后来也组成了直属于利姆路的亲卫部队“紫克众”。

## 4.4 暴风龙归来

第1部分里另一个让粉丝期待已久的时刻，是利姆路的“盟友”**维鲁多拉**的回归。这条体型巨大、黑色鳞片的暴风龙，曾被封印在洞窟中，第一季开头和利姆路结下了奇妙的友情。他其实有点傲娇、有点中二，在遇到利姆路之前非常寂寞——这样的龙重新站到利姆路身边，既是战力上的定心丸，也是这一季沉重氛围里难得的一点温暖。

# 五、角色深度解析

## 5.1 利姆路：温柔的人发起火来最可怕

利姆路的魅力，一直在于“平衡感”：他有前世社畜的常识和谦逊，也有史莱姆身体带来的强大能力。第二季第1部分第一次打破了这种平衡——他必须承认，**想要守护的东西，有时需要用力量去守护**。

但即使成为魔王，他也没有变成冷酷的统治者。他做出那个选择，是为了伙伴，而不是为了力量本身。这一点，是利姆路和那些“为了称霸而当魔王”的角色最本质的不同。

## 5.2 大贤者：最靠谱的“另一个声音”

大贤者是利姆路的独特技能之一，平时负责解说、分析，偶尔还会多嘴解说一些多余的事情。但在这一季，它不再只是一个“系统提示音”，而是陪利姆路走过最艰难时刻的存在。很多观众都是在第二季，才真正意识到大贤者对利姆路有多重要。

## 5.3 红丸：大鬼族的少主

红丸原本是被猪头族灭村的六名大鬼族幸存者之一，时任大鬼族少主，是朱菜的哥哥、白老的剑术学徒，也是苍影多年的挚友兼对手。被利姆路命名后，他从大鬼进化成鬼人，名字则源自他的一头红发——利姆路命名时还说过，这是个很有武士感的名字。

红丸为人勇敢慷慨，擅长指挥、判断局势，很有大将之风，即使是曾经的敌人投降归顺，他也愿意接纳。第二季里，他作为魔国联邦的军事核心，第一次真正扛起“总大将”的担子。顺带一提，这位帅气的大将拿妹妹朱菜完全没辙，还是个甜食控。

## 5.4 紫苑与朱菜：魔国联邦的“家人”

紫苑（M·A·O）和朱菜（千本木彩花）同样是那六名大鬼族幸存者里的成员：朱菜是红丸的妹妹，紫苑则一直守在利姆路身边。原作后来的设定里，由紫苑统率、和她一同复活的部下组成了“紫克众”——一支专门守护利姆路性命的亲卫队，甚至“因为是守护利姆路性命的部队，所以不会听从他的命令”。这一句设定，大概就是紫苑这个角色最好的注脚。

第二季里，这两位女孩的命运牵动着整部作品的情绪，也让“魔国联邦是一个家”这件事变得无比具体。

**第二季的两个部分一定要连着看**。第1部分结尾留下的悬念，会在第2部分的“魔王盛宴”里迎来清算。如果你看第一季时觉得节奏太慢、太“种田”，那请务必坚持到第二季——前面埋下的每一份温馨，都会在这里变成情绪的重量。

# 总结：史莱姆也会愤怒

第二季第1部分，是《关于我转生变成史莱姆这档事》从“轻松异世界建国物语”走向“史诗”的转折点。它告诉我们，利姆路的温柔并不廉价——那是一个拥有足以颠覆世界的力量的人，**自己选择了温柔**。

而当有人践踏了这份温柔，史莱姆也会愤怒。

**那一刻，他成了魔王；但他依旧是大家的利姆路。**
