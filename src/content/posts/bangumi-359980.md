> 转生进一款乙女游戏，才发现这是一个男人被当作附属品的世界——身为路人角色的他，只想好好活下去。

说实话，第一次看到《恋爱游戏世界对路人角色很不友好》这个标题的时候，我以为它又是一部“恶役千金”类的作品——毕竟这几年“转生进乙女游戏”的题材实在太多了。结果第一集看完我就乐了：主角是个男的，还是个连名字都不配出现在游戏里的路人；而他面对的世界，是一个女人可以把男人当玩物随意买卖的“地狱难度”。

更有意思的是，这个路人一点都不想当英雄。他只想活下去、想过平凡日子，可偏偏手里攥着前世的攻略知识，身边飘着一个满嘴“要不要把新人类灭绝掉”的 AI 球。于是，一个嘴上最毒、心里最软的“外道骑士”就这样诞生了。

# 一、作者与原作：一部“男性向的恶役千金”

## 1.1 基本信息

| 项目 | 内容 |
|------|------|
| **原名** | 乙女ゲー世界はモブに厳しい世界です |
| **简称** | 路人世界（モブせか） |
| **作者** | 三嶋与梦 |
| **插画** | 孟达（台湾插画师） |
| **网络连载** | 成为小说家吧，2017年10月 – 2019年10月 |
| **实体书** | 微杂志社（GC Novels），2018年5月 – 2024年3月，全12卷 |
| **漫画** | 潮里润作画，全13卷 |
| **累计发行** | 截至2024年7月，系列逾450万本 |

## 1.2 作者的创作初衷

很多人会被标题骗到，但作者三嶋与梦在访谈里说得很清楚：**这是一部男性向作品**，目标读者是男性，主角也是男生。他的创作灵感正来自在女性读者中大受欢迎的“恶役千金”类作品——他觉得其中一些作品其实也很对男性读者的口味，于是想试着写一部“男性向的恶役千金”。

作品的两大主题，作者概括为**“因果报应”与“劝善惩恶”**。而那个令人咋舌的“女尊男卑”世界观，按作者的说法，是“后宫作品的男女逆转版本”。有意思的是，他刻意在作品里解释了这个世界为什么会变成女尊男卑，而不是一句“因为这是游戏世界”就糊弄过去。更出人意料的是，作者在写这部作品之前**从来没玩过乙女游戏**，为此还专门做了一番资料搜集。

## 1.3 成绩与衍生

本作在《这本轻小说真厉害！》中多次上榜：2020年单行本部门第8位、2023年第14位、2024年第18位。系列发行量从2020年7月的30万本，一路涨到2024年7月的450万本——动画化前后的增长尤其明显。

衍生作品也相当丰富：

- 外传漫画《女性向游戏幼稚园对路人角色很不友好》（近江のこ作画，全2卷）
- if 线小说《那部女性向游戏世界对我们很不友好》——由原本作为问卷特典刊载的“玛丽耶路线”大幅加笔出版，插画为悠井もげ
- 续篇漫画【共和国篇】，于2025年起在《月刊龙时代》连载
- 2020年5月推出的广播剧，主角由小林裕介配音

值得一提的是，实体书第4卷和网络连载版有大幅改动，第5卷更是和网络版完全不同——所以只看过网络版的读者，到了中后期会发现剧情走向不太一样。

# 二、剧情简介：路人的生存战

一个日本社畜，在被任性的妹妹强迫帮她通关一款乙女游戏之后猝死，醒来时成了游戏世界里某个乡下男爵家的三子——**里昂·冯·巴鲁特法尔特**。

他很快发现，这个世界糟糕透顶：在荷尔法特王国，女性拥有特权，男性的地位甚至比奴隶还低，下级贵族的男人要想翻身，只能通过联姻往上爬。而里昂的继母，正打算把他卖给某个贵族老太婆当情夫。

唯一的例外，是以王太子为首的五位“可攻略角色”。而里昂唯一的武器，就是前世被妹妹逼着通关时记下的游戏知识。

为了逃离被卖掉的命运，他决定当冒险者，并凭借攻略知识找到了一处浮岛遗迹，获得了“失落物品”——一艘旧人类的宇宙移民船，以及船上的人工智能**卢克西恩**。从此，路人里昂有了一台性能远超王国所有现役机体的专用机“亚洛冈兹”（意为“傲慢”），也有了足够的财力在这个世界站稳脚跟。

可当他进入贵族学园后，却发现了一件更离谱的事：原本属于游戏女主角**奥莉薇亚**的剧情和机缘，全被一个叫**玛丽耶**的少女抢走了。五位攻略对象为了玛丽耶神魂颠倒，原本的女主在学园里受尽欺负，原本的恶役千金**安洁莉卡**则被王太子当众抛弃……

“只想当个路人”的里昂，终究没能忍住。

动画化消息于2021年11月25日公布，属于 Comic RIDE 五周年、GC Novels 七周年纪念活动“五大计划”中的第五项。作者三嶋与梦回忆，他在2020年夏天第一次从编辑那里听说动画化的事，但当时还没落实，直到几个月后的秋天才正式确定。

宣传片里最早披露的除了片头曲，还有**机甲战斗片段**——对一部标题叫“乙女游戏”的作品来说，这本身就是个很好的反差宣传。

# 四、剧情解析

> ⚠️ **以下内容包含剧情剧透。**

## 4.1 决斗：路人掀桌

故事真正的转折点，是里昂与“五傻”的决斗。

王太子尤里乌斯为了玛丽耶，当众解除了与安洁莉卡的婚约。看着这位明明最有贵族气度、却被当成恶役的公爵千金受辱，里昂终于站了出来。而他的手段也很“里昂”——既然要打，就用碾压级的机体和卢克西恩的支援，把对方的骄傲踩得粉碎。

决斗之后，尤里乌斯被废嫡，五位攻略对象跌落神坛。站在他们对面的里昂，则从一个无人在意的路人，变成了全学园都知道的“问题人物”。

这场戏的爽点不只是“打赢了”，而是**规则被打破了**。在一个男人只能靠联姻往上爬的世界里，一个路人用实力让整个体系颜面尽失——这就是作者说的“劝善惩恶”。

## 4.2 “外道骑士”的诞生

之后里昂又被卷入与凡欧斯公国的冲突。公国公主赫特鲁蒂率军袭击满载学生的豪华客轮，人称“黑骑士”的公国最强英雄班戴尔也登场了。

里昂两度击败公国，却总是放过手下败将。在对手看来，这比杀了他们还屈辱——于是他被世人称为“**外道骑士**”。

但这个外号背后，其实藏着里昂最沉重的一面：他前世生活在和平年代，从没经历过战争和杀戮，知道对面是活生生的人，所以下不了杀手。而当他终于不得不为了阻止战乱而杀人时，身心都被压垮了——原作里写到，他甚至要依赖药物才能入睡。

这部作品常被当成“爽文”，可里昂的这份痛苦，是它和普通爽文最大的不同。

## 4.3 玛丽耶的真相

全作最大的反转，是玛丽耶的真实身份——**她就是里昂前世那个任性的妹妹**。

前世的她十分依赖哥哥，间接成了哥哥过劳死的元凶。哥哥死后，她被父母赶出家门，后来有了一个女儿，最终被有暴力倾向的男友打死。正因为前世过得太不幸，她才会在这个世界里不择手段地攻略五位贵公子、抢走女主的位置——她只是想过上奢华幸福的生活。

可她自己也没完整通关过游戏，对剧情一知半解，结果扰乱了无数人的人生，最后还得靠里昂来收拾残局。

在原作里，兄妹俩是在第3卷相认的。从那以后，里昂对这个“最讨厌的女人”的态度彻底变了——他同情她今世的悲惨遭遇，在各方面援助她。而玛丽耶，则在养活“五傻”的苦日子里，慢慢长成了一个家务万能、意外节俭、对重要的人很好的姑娘。

# 五、角色深度解析

## 5.1 里昂：嘴上最毒，心里最软

里昂是个很难用“好人”或“坏人”定义的主角。他个性乖僻、狡猾卑鄙，做事冲动又脱序，周围人对他的评价普遍很低；可他内心善良，看到不公时永远忍不住出手。

他最大的心愿是“贯彻路人角色、过平凡的生活”，结果却因为不断立下功绩，地位一路飙升，最后成了远近驰名的救国英雄。**一个越想低调越被推上台前的主角**，这本身就是本作最大的喜剧来源。

## 5.2 奥莉薇亚：被夺走剧本的女主

奥莉薇亚是游戏原本的女主角，特招进贵族学园的平民少女，擅长治愈魔法。因为玛丽耶的介入，她没能和任何攻略对象产生交集，反而在学园里受尽贵族子女的欺凌。

有个细节很有意思：里昂前世玩游戏时，曾经把奥莉薇亚叫作“心机女”；可转生后亲自接触了她本人，立刻就改观了。被剥夺了剧本的她，反而以最真实的样子出现在里昂面前——好学、温柔，在假期里就把学园图书馆的藏书看完了。

## 5.3 安洁莉卡：被当成恶役的真千金

安洁莉卡是游戏里的反派千金、王太子的原未婚妻。可现实里，她却是**最有贵族气度的那一位**。被尤里乌斯甩掉之后，陪在她身边的是奥莉薇亚——原本游戏里的“女主与情敌”，就这样成了朋友。

两位女主和里昂之间的关系，也在一次次并肩中慢慢变化。原作后来写到，两人一起向里昂告白，并用计“迫使”他和两人订婚——这对“曾经的女主与恶役”，联手攻略了路人。

## 5.4 卢克西恩：本作最强吐槽役

卢克西恩是旧人类宇宙移民船上的 AI，平时以红色单眼的机器球体形态飘在里昂身边。因为里昂身上留有旧人类（日本人）的基因，它才认他为主。

它痛恨新人类，核心指令就是消灭所有带魔力的新人类，所以动不动就向里昂提出“要不要毁灭世界”的危险建议。它常常挖苦里昂，可实际上对这位找到自己的主人评价很高。石田彰那种温文尔雅的语气说出“灭绝”二字，反差感拉满。

## 5.5 “五傻”：五个帅气的笨蛋

尤里乌斯、吉克、布拉德、克里斯、格雷格——游戏里的五位攻略对象，长相帅气、地位崇高，可因为金钱观缺乏常识、战斗漏洞百出，被里昂统称为“五傻”。就连原本应该和他们相爱的奥莉薇亚，也分别给了他们“浮夸”“腹黑”“自恋狂”“轻浮”和“头脑简单的莽夫”的评价。

他们是本作最好的喜剧素材，但也不完全是纯粹的笑料：尤里乌斯在身为王太子的巨大压力下，爱上了“理解他”的玛丽耶——只不过那份理解，来自于她对游戏剧情的了解。

# 六、入坑建议

**适合谁看？**

- 喜欢“转生+攻略知识开挂”的爽快展开
- 喜欢毒舌主角和吐槽役搭档
- 想看机甲空战但又不想看太严肃的战争戏
- 对“恶役千金”题材审美疲劳，想换个视角的观众

**可能劝退的点**：前期的女尊男卑设定相当夸张，部分女性角色的恶劣程度可能会让人不适；主角的行事风格也确实“外道”，不是传统意义上的正派英雄。

看完第一季意犹未尽的话，可以接着看[《恋爱游戏世界对路人角色很不友好 第二季》](/posts/trapped-in-a-dating-sim-season-2/)。

# 总结

《恋爱游戏世界对路人角色很不友好》是一部把“乙女游戏”当外壳、骨子里却是男性向爽文的作品。它用一个夸张的女尊男卑世界，讲了一个很朴素的道理：**不公平的规则，总有人要站出来打破它**。

而站出来的那个人，偏偏是个只想当路人的家伙。他嘴上说着“跟我无关”，手却永远比嘴快；他被称为“外道骑士”，却连敌人都不忍心杀。

**路人不想当主角，可这个世界，偏偏需要一个路人来拯救。**
