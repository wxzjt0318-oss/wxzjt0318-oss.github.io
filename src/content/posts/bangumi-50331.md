> 正片还没开播，邪王真眼的使用者已经先在 YouTube 上发动了。

说实话，现在回头看，《中二病也要谈恋爱！Lite》是一个很聪明的点子：正片还没播，先在网上放几集短短的小剧场，让观众提前认识这群人——戴眼罩的邪王真眼少女、拼命想忘掉黑历史的"漆黑烈火使"，还有他那两个妹妹。

![中二病也要谈恋爱！Lite封面](https://lain.bgm.tv/pic/cover/l/8f/2c/50331_KWKjN.jpg)
*中二病也要谈恋爱！Lite*

它只有6话，每话大约6分钟，却开了系列"先行 Lite 短篇"的头：一年多以后，第二季开播前又照样来了一次。

# 一、基本信息

## 1.1 播出与制作

| 项目 | 内容 |
|------|------|
| **原名** | 中二病でも恋がしたい！Lite |
| **形式** | 网络动画（每话约6分钟） |
| **话数** | 全6话 |
| **配信时间** | 2012年9月27日～11月1日，每周四16:00（日本时间） |
| **配信平台** | 京都动画 YouTube 官方频道、动画官方网站 |
| **动画制作** | 京都动画 |
| **监督** | 石原立也 |
| **人物设定** | 池田和美 |
| **原作** | 虎虎（KA Esuma 文库） |

据萌娘百科，每一话都只在网上**限时公开一星期**，赶不上就看不到了。系列的 TV 动画第一季随后在2012年10月开播，Lite 的配信正好和正片的前几周重叠。

## 1.2 原作

原作是虎虎创作、逢坂望美插画的轻小说，属于京都动画自家的 KA Esuma 文库第一批作品之一；第1卷获得了第1届京都动画大赏的鼓励奖。动画版加入了五月七日茴香、凸守早苗等原创角色，其中一部分后来又被写进了小说第3卷以后的内容。

## 1.3 登场角色与声优

| 角色 | 声优 | 身份 |
|------|------|------|
| 小鸟游六花 | 内田真礼 | 自称"邪王真眼的使用者"的现役中二病少女 |
| 富㭴勇太 | 福山润 | 想告别中二黑历史的男主角 |
| 丹生谷森夏 | 赤崎千夏 | 班长，深藏不露的"前"中二病 |
| 凸守早苗 | 上坂堇 | 六花的"侍从"，初三学生 |
| 富㭴樟叶 | 福原香织 | 勇太的大妹妹 |
| 富㭴梦叶 | 设乐麻美 | 勇太的小妹妹 |
| 勇太的母亲 | 天野由梨 | 富㭴家的妈妈 |
| Kimera | 冲佳苗 | 六花捡来的猫 |

另外，萌娘百科的声优表里还列出了两位 **Lite 专属角色**：小友（藤村步）和美香（大坪由佳）。

---

# 二、两位主角

- **小鸟游六花**：勇太的同班同学，现役中二病患者，自称"邪王真眼的使用者"。她的设定是"右眼寄宿着魔力、闪着金光，平时要封印起来"，所以戴着眼罩——眼罩下面其实是一片金色的美瞳。她不喜欢被叫"小鸟游同学"，和勇太"签订契约"时，要他直接叫自己"六花"；
- **富㭴勇太**：初中时自称"漆黑烈火使"，把妄想写进"黑暗笔记"，还会念出"在黑暗的火焰中消失吧！"这样的咒语，结果被周围的人疏远。意识到给别人添了麻烦以后，他决定把这段黑历史彻底封印，上了高中只想当个普通人——可他偏偏坐在了六花旁边。他有两个妹妹，很会照顾人。

---

# 三、富㭴一家与那只猫

Lite 的声优表里有富㭴家的好几位成员。按维基百科的介绍：

- **樟叶**：勇太的大妹妹，初一学生。擅长做饭，和勇太一起包办家务；日文维基百科还提到，她不知为何只会做"很男子气"的料理；
- **梦叶**：勇太的小妹妹，5岁，元气满满、话很多，性格有点早熟，提要求时还会意外地现实。她非常喜欢勇太买给她的"相扑熊五郎"玩偶，也很黏六花——被认为将来很可能也会变成中二病；
- **勇太的母亲**：名字不详，因为兼职工作忙得分身乏术，常常被孩子们耍着玩；
- **Kimera**：动画原创的猫，是六花捡来的。背上的翅膀装饰让它看起来像神话里的奇美拉，名字就是这么来的。因为六花的姐姐十花对猫过敏，它最后被寄养在了富㭴家。

对于一部讲"中二病"的作品来说，这一家人是很好的"普通人"参照：哥哥拼命想当个普通高中生，妹妹却在一旁被六花的世界观吸引。

# 四、主题曲

| 类型 | 曲名 | 演唱 | 词曲编 |
|------|------|------|------|
| **片头曲** | 君へ（致你） | ZAQ | ZAQ |
| **片尾曲** | 漆黒に躍る弧濁覇王節 | ZAQ | ZAQ |

正片第一季的片头曲《Sparkling Daydream》和片尾曲《INSIDE IDENTITY》也都出自 ZAQ 之手。《君へ》后来还收进了角色歌专辑《暗黑虹彩乐典》。

到了第二季前的《恋 Lite》，片尾曲换成了同样由 ZAQ 包办的《深淵に舞う戦栗謝肉祭》——两首 Lite 片尾曲的歌名，一看就是同一个"中二"命名风格。

---

# 五、系列中的位置

1. **网络动画《中二病也要谈恋爱！Lite》**（2012年9月～11月，全6话）——本篇
2. TV 动画第一季《[中二病也要谈恋爱！](/posts/love-chunibyo-and-other-delusions/)》（2012年10月）
3. 剧场版《[小鸟游六花·改 ～剧场版 中二病也要谈恋爱！～](/posts/chunibyo-rikka-version-movie/)》（2013年9月，第一季总集篇加新剧情）
4. 网络动画《[中二病也要谈恋爱！恋 Lite](/posts/love-chunibyo-heart-throb-lite/)》（2013年12月）
5. TV 动画第二季《[中二病也要谈恋爱！恋](/posts/love-chunibyo-and-other-delusions-heart-throb/)》（2014年1月）
6. 剧场版《[电影 中二病也要谈恋爱！ -Take On Me-](/posts/take-on-me/)》

Lite 不承担主线剧情，单独看也没问题。不过最好的看法，还是和第一季正片一起看：认识了这群人，再看这些短短的小剧场，才会觉得好笑。

---

# 总结：先发动的邪王真眼

《中二病也要谈恋爱！Lite》只有6集、每集6分钟，还只限时公开一星期。可它让观众在正片开播前，就先见到了六花的眼罩、勇太的无奈，和富㭴家的两个妹妹。

**正片还没开始，中二病已经先发作了。**
