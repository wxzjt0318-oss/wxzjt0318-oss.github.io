> 这颗星球正在沉没——在海水淹没的小镇上，少年打捞起了一个会说“我是高性能的”机器人少女。

说实话，第一次看到《亚托莉 -我挚爱的时光-》的宣传图时，我以为这就是一部“可爱机器人少女陪你过夏天”的轻松番：蓝天、大海、白裙子、呆毛，还有一句中气十足的“我是高性能的嘛！”。可真正看下去才发现，这部作品的底色其实是**告别**——一颗正在沉没的星球，一个正在倒数的生命，一个不敢再相信“心”的少年。

![亚托莉 -我挚爱的时光-封面](https://lain.bgm.tv/pic/cover/l/66/6d/397604_TgJ63.jpg)
*亚托莉 -我挚爱的时光-*

它用最明亮的夏天，讲了一个关于“有限”的故事。亚托莉的每一次笑、每一次逞强、每一次大口吃东西，到了最后回想起来，都像是在和这个世界认真地说再见。

# 一、原作：ANIPLEX.EXE 的处女作

## 1.1 一款“想把视觉小说带给全世界”的游戏

| 项目 | 内容 |
|------|------|
| **原名** | ATRI -My Dear Moments- |
| **类型** | 视觉小说（全年龄） |
| **制作** | Frontwing、枕（The pillow） |
| **发行** | ANIPLEX.EXE |
| **发售日** | 2020年6月19日（Steam / DMM），同年12月28日登陆 DLsite |
| **故事原案** | 绀野アスタ |
| **角色原案** | ゆさの、基4 |
| **主题曲** | 片头曲《光放て！》（柳麻美）、片尾曲《Dear Moments》（亚托莉 CV：赤尾光） |

《ATRI》是 Aniplex 旗下新创立的视觉小说品牌 **ANIPLEX.EXE** 的两部处女作之一，另一部是同日发售的《徒花异谭》。品牌创始人兼制作人**岛田纮希**从学生时代起就是视觉小说玩家，他希望借这个品牌把这一类型的乐趣传达到全世界——所以《ATRI》从一开始就支持日、英、繁中、简中四种语言，并通过 Steam 面向全球发行。

## 1.2 几经波折的诞生

这部作品的诞生过程颇有戏剧性。岛田找到曾参与《向日葵的教会与长夏假期》剧本的绀野アスタ，绀野收到邮件时一度以为是恶作剧；后来绀野入职 Frontwing，本想推掉这份工作，结果枕社的制作人 SCA-自反过来大力向岛田推荐 Frontwing，最终促成了 Frontwing 与枕的联合制作。

岛田对作品只提了一个要求：**“要有真正感人的部分。”** 机器人元素是岛田提的，潜水艇则是绀野出于个人喜好加进去的。一贯擅长日常系的绀野，把本作定位为“泣系”游戏，这也是他第一次挑战这个方向；主人公腿部有残疾的设定，则延续了他“上帝关上一扇门，必然会打开一扇窗”的创作思路。

美术方面，岛田在看到当时还没什么名气的插画师 ゆさの（Yusano）的样稿后，当即拍板让其负责。夏生和亚托莉之间那组令人印象深刻的**身高差**，就是在这一过程中确定下来的。

## 1.3 从小众到五十万

这部定位为“2—3卷轻小说分量”的短篇作品，口碑一路发酵：发售一周年时与《徒花异谭》合计销量突破10万；2022年9月宣布动画化时单作已售出17万套；2024年4月突破30万套；同年10月，ANIPLEX.EXE 宣布销量突破**50万套**。游戏还先后移植到了 Switch、Android 和 iOS 平台，漫画版由じゃこ作画，在《Comptiq》2022年11月号至2025年3月号连载，共5册单行本。

# 二、故事简介

在不远的未来，海平面因不明原因急速上升，地表的大部分都沉入了海中。人类的栖息地被迫收缩，曾经处于巅峰的科学技术不断流失——这是一个**逐渐迈向灭亡的、平静的时代**。

少年**斑鸠夏生**8岁时在一场隧道事故中失去了母亲和右腿，依靠义肢行走。他原本就读于都市里被称为“科学院”的精英学府，却因与老师产生矛盾而休学，搬回了已故外祖母曾居住的海边小镇，与青梅竹马**神白水菜萌**重逢。

外祖母是一位海洋地质学家，留给他的只有一艘船、一艘潜水艇——和一大笔债务。自称讨债人的神秘女子**凯瑟琳**找上门来，要夏生找出外祖母的遗产还债。于是两人潜入海底的旧宅仓库，在一个棺材般的装置里，夏生发现了沉睡的少女——**亚托莉**。

她是一台构造精密到与人类无异、拥有丰富感情的机器人。被打捞上岸的亚托莉对夏生说：

> “我想完成主人留给我的最后的命令。在此之前，我会成为夏生先生的腿！”

就这样，在一个逐渐沉入海中的平和小镇里，少年和机器人少女的夏天开始了。

音乐沿用了游戏原作的作曲者**松本文纪**，系列构成则交给了经验丰富的**花田十辉**。把一款带有分支结局的视觉小说压缩成一条13话的线性叙事，本身就是一件需要取舍的事。

## 3.2 声优阵容

| 角色 | 声优 |

| 亚托莉 | 赤尾光 |

**赤尾光**从游戏时代起就为亚托莉配音，动画版继续由她出演，可以说是这部作品最稳的一根柱子。游戏版本中夏生作为主人公没有配音，TV 动画则请来了**小野贤章**——那种“认真、别扭、不太会表达”的少年感，和夏生非常贴合。

## 3.3 舞台：铫子

动画把故事舞台设定在了**千叶县铫子市**，铫子港塔、铫子电铁犬吠站前广场等当地景点都在片中登场，还加入了与当地小吃**今川烧**相关的原创剧情。一座真实存在的海边城市，被放进“海平面上升”的设定里，那种“熟悉的街道一半泡在水里”的画面，比完全架空的世界更让人心里一紧。

# 四、分阶段剧情解析

> ⚠️ 以下内容包含原作故事的核心剧透，未看完动画的朋友请谨慎阅读。

## 4.1 前段：45天的约定

亚托莉醒来后告诉夏生，**45天后**她就必须与夏生分别。她希望夏生在那之后把她卖掉，换一条新的义肢；而在这45天里，她会和夏生一起生活，做他的“腿”，同时请夏生帮她完成前主人留下的“最后的命令”。

于是故事的前半段，几乎是一部明亮的日常喜剧。自称“战斗家务机器人”的亚托莉家务一塌糊涂，做出来的饭被夏生称为“工业废料”，却又格外爱吃东西——“好吃就是高兴嘛！”她会跟拐杖较劲，会中二地自夸“高性能”，会在夏生怕黑的夜里要求一起睡。

夏生在亚托莉的陪伴下走进了当地那所**一半已经沉入海中的学校**，认识了大哥一样的龙司、好学的凛凛花，还和水菜萌一起照顾着几个小学生。他利用自己的知识造出了**微型漩涡发电机**，解决了学校的供电问题——这个曾经在都市里被孤立的天才少年，第一次在小镇里找到了“被需要”的感觉。

## 4.2 中段：日志簿与“心”的怀疑

随着相处，夏生对亚托莉产生了好感，也得知外祖母留下了一座名为**“伊甸”**的人工岛，作为人类生存问题的解决方案。

转折来自一本日志。夏生无意间读到了亚托莉的工作日志簿，认定她对自己的那些感情，**全都只是机器演算出来的结果**。对一个本就不太相信别人的少年来说，这是一记重击——他要求亚托莉别再“假装”拥有感情。

这一段是全作最揪心的地方。亚托莉为了取悦主人而“刻意再现”情感，夏生则因为害怕受伤而拒绝相信。**一个在学怎么拥有心，一个在学怎么相信心**，两个人隔着同一本日志，谁都没有错，却都在受伤。

## 4.3 后段：亚托莉的过去

亚托莉的真实身份逐渐揭开：她实际上拥有自我意识和情感，是所谓的**“技术奇点”**。她的前主人，正是夏生的母亲**八千草诗菜**。诗菜幼年遭到同学欺凌，无法接受主人被如此对待的亚托莉冲进学校殴打了欺凌者——这起事件导致同型号机器人被判定存在重大缺陷，全部遭到回收，只有亚托莉逃了出来。

她从此躲在暗处继续守护诗菜，直到那场隧道事故。诗菜在弥留之际下达了命令，让亚托莉把夏生当作新主人，救他出来。之后，亚托莉在夏生外祖母的安排下进入了休眠。她被设计了寿命，而当夏生打捞起她时，**距离寿命的终点只剩45天**。

原来那个“最后的命令”，从一开始就和夏生有关。

## 4.4 高潮与尾声：天台、伊甸与火箭

当年的事件也让亚托莉的开发者小西久作身败名裂、含恨而终。他的学生**安田**为了替恩师报仇找到亚托莉，两人在学校天台对峙。原作游戏中，这里的走向取决于玩家的选择：夏生没能赶上时，会走向令人心碎的坏结局；赶上并制止了亚托莉，对她说“不必再假装自己没有感情”，才会通往好结局。

在好结局中，夏生在亚托莉停止机能的前一天把她带到“伊甸”，让她休眠于主控室，成为岛上的系统管理员。而在原定的那一天，夏生和朋友们一起仰望了父亲斑鸠宗司主持研发的火箭发射——**人类重新开始了对太空的探索**。

原作还有一个在完成两个结局后才解锁的**真结局**：60年后，夏生与水菜萌结为夫妻，夏生让世界迎来了技术奇点，机器人被人类当作朋友接纳。在夏生弥留之际，完成使命的“伊甸”即将沉没，他通过部分电脑化的大脑连上网络，唤醒了沉睡60年的亚托莉。两人在电脑模拟出的海边悬崖上，度过了各自最后的一天。

动画作为一条线性叙事如何处理这些分支，就留给大家自己在第13话里确认吧。

# 五、角色深度解析

## 5.1 亚托莉：笨蛋又高性能的“心”

亚托莉是山崎制造厂的第四代型号，在设计理念上就与当时市面上的机器人不同——她的设计者致力于做出一台**和人类别无二致、拥有“心”的机器人**。她有仿生脑、会流泪的电子眼、痛觉感受器，甚至有完全用不上的仿生肺——而这个“无用设计”，意外地救过夏生一命。

她最可爱的地方在于“笨”：明明是高性能，却会忘事；明明是家务机器人，却做饭难吃（后来在水菜萌的教导下总算做出了可口的菜）。可这些“缺陷”到了后段全都翻转成了刀子——会忘事，其实是仿生脑接近寿命的征兆。

她的名字 Atri，游戏里写明是**燕雀**，一种季节性候鸟。候鸟只会停留一个季节，这个名字本身就是一句预告。

## 5.2 斑鸠夏生：不会表达的天才少年

夏生眼神凶恶，内心善良，是“矛盾性格的集合体”。他高一就学完了高中三年的课程，却被残疾和幻肢痛所困，怕水、怕黑。这样一个人，对“真心”有着近乎偏执的警惕，所以那本日志才会伤他那么深。

亚托莉说要做他的“腿”，可到最后，真正被扶起来的不只是他的身体。他从那个逃离都市、对未来不抱期待的少年，变成了会仰望火箭、会为人类找出路的人。

## 5.3 神白水菜萌：小镇里的大姐姐

水菜萌是夏生幼时寄住外祖母家时结识的好友，从没走出过这个小镇，纯朴善良、非常会照顾人。学校老师辞职后，她甚至自己充当老师带着低年级学生上了一个月的课。她是这部作品里最温柔的“锚”：亚托莉私下把夏生托付给她，而她也在之后的岁月里一直牵挂着亚托莉。

## 5.4 龙司、凯瑟琳与凛凛花

**野岛龙司**是本地孩子们的老大，比起动脑更擅长运动。制作团队精心刻画了他与夏生从关系不好到建立友谊的过程，这个角色的塑造据说受到了《樱花大战》系列加山的影响。**凯瑟琳**本名小佐田花子，表面上是讨债人，实际上是当地一位曾经失踪的少女，回乡后当了学校的小学老师，也放弃了讨债。**名波凛凛花**是好学的小学女生，制作团队起初不想加入这个角色，后来出于“需要孩童角色”的考虑才保留，还一度把她设定为伪娘。

# 六、主题曲

## 6.1 动画主题曲

| 类型 | 曲名 | 演唱 |
|------|------|------|
| 片头曲 | 《あの光》（那一束光） | 乃木坂46 |
| 片尾曲 | 《YESとNOの間に》（在YES与NO之间） | 22/7 |
| 第6话片尾曲 | 《Dear Moments》 | 亚托莉（赤尾光） |
| 第13话片尾曲 | 《光放て！》（绽放光芒！） | 柳麻美 |

动画的片头曲和片尾曲分别由同属索尼音乐旗下的**乃木坂46**和**22/7**演唱，作词均为秋元康。《あの光》在第1话被用作片尾曲；《YESとNOの間に》则在第1、6、13话未使用。

最让老玩家动容的安排，是**第6话和第13话**：第6话片尾换成了游戏原作的片尾曲《Dear Moments》，第13话则用上了游戏片头曲《光放て！》——两首歌都由绀野アスタ作词、松本文纪作曲，这也是绀野第一次挑战作词。当游戏时代熟悉的旋律在动画最后响起，那种“终于回到这里”的感觉，大概只有玩过原作的人最懂。

# 七、观看建议

## 7.1 先看动画还是先玩游戏？

- **只想看故事**：直接看13话动画即可，节奏紧凑，情绪完整。
- **想要完整体验**：推荐补原作游戏。游戏有三个选择支、坏结局、好结局和真结局，那个跨越60年的真结局，是原作最重要的情绪落点之一。游戏篇幅不长，本身就是按“2—3卷轻小说”的分量设计的。
- **喜欢漫画**：じゃこ的漫画版全5卷已完结，也是不错的补充。

## 7.2 适合谁看？

如果你喜欢“夏天、海边、倒计时”的组合，喜欢那种明亮画面下藏着离别的作品，那《亚托莉》一定会戳中你。但也要做好心理准备：前半段笑得越开心，后半段就会哭得越安静。

# 总结：候鸟停留的那个夏天

《亚托莉 -我挚爱的时光-》讲的是一颗正在沉没的星球、一座逐渐被海水吞没的小镇、一个只剩45天寿命的机器人少女。可它从头到尾都没有绝望——小镇的学校重新通了电，火箭重新飞向了天空，人类在“迈向灭亡的平静时代”里，依然选择了抬头。

亚托莉总说自己是“高性能”的。到了最后你会明白，她最高性能的地方，不是能承受30米的水压，也不是能掰弯铁制匕首，而是**她真的学会了一颗心**——然后把这颗心，留给了一个曾经不敢相信心的少年。

**候鸟只停留一个季节，可那个夏天，会被记住一辈子。**
