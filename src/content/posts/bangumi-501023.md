> 被祖父们安排和班上最讨厌的女生结婚——每天都在吵架的两个人，同居生活就此开始。

说实话，“和最讨厌的人结婚”这个设定，我在点开之前就已经猜到了大半走向：一开始吵吵闹闹，然后慢慢发现对方的好，最后——你懂的。

但真正看下去，我发现《我和班上最讨厌的女生结婚了。》最好看的地方，不在“结局是什么”，而在“**两个嘴硬的人到底要多久才肯承认**”。才人和朱音在学校里是被同学调侃成“夫妻漫才”的冤家，回到家里却要分配家务、讨论晚饭吃什么、为了谁先洗澡吵上一架。这种“明明都很在意，偏偏谁都不肯先开口”的别扭感，才是这部作品真正的甜点。

而且越往后看越会发现，他们之间的缘分，其实比两人自己以为的要早得多。

# 一、原作与基本信息

## 1.1 从YouTube动态漫画起步

这部作品的出身有点特别。它最早是YouTube频道“漫画エンジェルネコオカ”于**2020年3月8日**起连载的同名动态漫画，由**天乃圣树**撰写剧本、**もすこんぶ**作画。第1至3话最初由殊座配音，从第4话起改由铃木爱唯配音，前三话也随之发布了重制版总集篇。

之后，天乃圣树将其改写为轻小说，由**成海七海**担任插画，2020年12月至2025年1月由KADOKAWA旗下的MF文库J发行。繁体中文版由东立出版社出版，此外还有韩文版和英文版。

## 1.2 漫画版

漫画版依旧由もすこんぶ作画，2021年5月14日起在KADOKAWA旗下的“少年Ace plus”连载，单行本发行于角川Comics A，繁体中文版由青文出版社出版。

# 二、剧情简介

高中生**北条才人**和同班同学结婚了。对象是学校里他最应付不来、天敌般的女生——**樱森朱音**。

“和我结婚的事，要是跟班上的人说了，我就杀了你。”
“我也不想让别人知道我结婚的事，又没什么好处。”

平时就互相讨厌的两个人，新婚生活不可能一帆风顺，总是冲突不断。但在每天的相处中，两人的距离一点点拉近，在一起的快乐时光慢慢增加，也开始渐渐理解彼此。

才人看到了朱音从未展现过的、可爱的素颜；朱音也渐渐意识到了自己心中藏着的那份心意……两个无法坦诚面对彼此的人，令人心动的新婚生活就此开幕。

# 四、剧情解析

> ⚠️ **剧透警告**：以下内容涉及主要角色的背景设定与感情线，请谨慎阅读。

## 4.1 被逼出来的婚姻

这场婚姻的始作俑者，是两位老人。

才人的祖父**北条天龙**是北条集团的最高领导者，六十岁了还在商场上打滚。他以“集团接班人”的身份、准备妥当的房子和生活费为筹码，半引诱半强迫地让孙子和同班同学结婚。朱音的祖母**樱森千代**则以“负担大学学费”为条件，逼着一心想当医生的朱音向现实低头。

为什么非要让这两个孩子结婚？答案藏在两位老人自己身上。

## 4.2 两代人的“未完之恋”

天龙和千代在学生时代曾有过一段热闹的恋爱，后来却各奔东西，直到年老才终于生活在一起。在天龙看来，孙子和千代的孙女相处的样子，**和当年的自己与千代几乎如出一辙**——他强迫孙子结婚，也是想圆自己心中的遗憾。

千代虽然圆了年轻时一半的遗憾，却也希望看到孙女走上自己当年没能走完的路。

我很喜欢这个设定。它让一个看起来很“狗血”的强制婚姻，多了一层温柔的底色：**老人们不是在安排孩子的人生，而是不想让他们重蹈自己错过的覆辙。**

## 4.3 从“规则”到“习惯”

才人和朱音的同居生活，一开始几乎处处不搭：性格、打扫卫生、生活习惯、饮食习惯，没有一样合得来。朱音家务全能，才人却懒散怕麻烦、对家务有拖延症，三餐常常是泡面、蛋白粉和各种食材混在一起的奇怪蔬菜汁。

两人最后的解决办法是**协调意见、制定规则**，各自负责一部分家务——而在这个过程中，他们也开始喜欢上了这种生活。

这大概是整部作品最真实的一笔：感情不是突然爆发的，而是从“谁洗碗”“谁倒垃圾”这样的小事里，一点一点长出来的。

## 4.4 那块手帕

> ⚠️ 以下涉及两人的过往。

小时候，朱音曾和祖母一起参加天龙的生日派对，在派对上遇见了才人。两人愉快地交谈，**成为了彼此的初恋**。

才人从那以后一直无法忘记那次相遇，至今还保留着当时朱音送给他的手帕。只是他当时没有问朱音的名字，再加上重逢时朱音已经剪成了短发，他没能认出她来。

也就是说，两个在学校里吵得不可开交的“天敌”，其实**早就是对方的初恋**——只是谁都不知道。这个设定给整部作品埋下了一颗糖：观众知道，角色不知道，于是每一次吵架都变得格外好笑，又格外让人着急。

# 五、角色深度解析

## 5.1 北条才人：不懂生活的天才

才人几乎是被父母抛弃的孩子，由祖父天龙抚养长大，被评价为北条家族有史以来的天才，入学以来成绩一直是年级第一。他拥有过目不忘的记忆力，连朱音喜欢的事物、自己走过的地方这些细节都记得清清楚楚，在北条集团也拥有最低限度的管理权，甚至会去姑姑的公司帮忙打工。

但这位天才的生活技能极差——说准确点是**懒散怕麻烦**，其实他会做家务。他是个理性派，却不代表情商低；喜欢读书、打游戏和摄入蛋白质。在班上很受女生欢迎，也因此招来不少男生的仇视。

## 5.2 樱森朱音：永远的第二名

朱音不说话的时候，拥有能和模特媲美的美貌和身材。她争强好胜、不服输，是个努力家，梦想是成为一名**能在别人受苦时伸出援手的医生**——即使结了婚，她也没打算放弃这个梦想。

她无论如何努力，都无法在考试总成绩上击败才人，一直是年级第二；但在家政课上，她多次赢过才人。小时候她经常照顾身体不好的妹妹，所以家务全能。

她的可爱之处藏在许多小细节里：极度喜欢猫，喜欢到被某家猫咪咖啡厅拒绝入店（因为玩过头把猫累坏了）；爱吃草莓；很怕鬼，也怕恐怖游戏和恐怖电影；看到才人和其他女生互动时会吃醋。矢野妃菜喜把她那种“嘴上凶、心里软”的劲儿演得恰到好处。

## 5.3 石仓阳鞠：辣妹外表下的温柔

阳鞠是朱音为数不多的朋友，外表华丽的辣妹，性格却温和宽容。她的发色和长相遗传自美国籍的生母——母亲在她很小的时候就病故了。小时候她因此不断被欺负，父亲怕麻烦想让她把头发染黑，阳鞠出于对母亲的思念断然拒绝，也因此与父亲和继母不和。**她打扮成轻浮的辣妹，是为了不再被欺负。**

她在学校里扫除和活动都很积极，沟通能力超强，能和任何人成为朋友。她经常调侃朱音，却总能在最后给出现实又有用的建议。

而她心里也有一个秘密：高一时她就喜欢上了才人，约会邀请被断然拒绝后，她依旧没有放弃。

## 5.4 北条糸青：观察者与“妹妹”

糸青是才人的堂妹，也是同班同学，拥有洋娃娃般的外表和冷淡的表情。她父亲是入赘北条集团的俄罗斯人，所以她有一半俄罗斯血统，食量大得与体型完全不符。

她观察力和推理能力极强，是**第一个发现才人结婚的同龄人**，还帮才人练习怎么和女生相处。她和才人从小一起长大，关系亲密到经常钻进同一条毯子里睡觉，会自然地要求公主抱，嗅觉灵敏到能闻出才人身上别人的味道。她常常潜入两人的住处一起生活，甚至装成幽灵把朱音吓得不轻。

但这一切背后，其实是她在**观察朱音能不能给才人带来幸福**。

## 5.5 樱森真帆：麻烦的小姨子

真帆是朱音的妹妹，比她小三岁，后来转入两人所在的高中成了学妹。她从小体弱多病，父母为了赚医疗费拼命工作、很少在家，所以一直由姐姐照顾。她自由奔放又爱撒娇，经常诱惑才人，扬言要把才人从姐姐手里抢走。

# 六、主题曲

## 6.1 片头曲《恋人以上、好き未満》

| 项目 | 内容 |
|------|------|
| **演唱** | =LOVE |
| **作词** | 指原莉乃 |
| **作曲** | 中村瑛彦 |
| **编曲** | 古川贵浩 |
| **备注** | 第7话用作片尾曲 |

歌名直译是“恋人以上，喜欢未满”——这几乎就是才人和朱音关系的精确定义：**名义上已经是夫妻了，嘴上却还不肯说一句“喜欢”。**

## 6.2 片尾曲《スキキライも追い越して》

片尾曲《スキキライも追い越して》（连喜欢与讨厌都超越）由原田茂幸（Shiggy Jr.）作词作曲编曲，演唱阵容会随剧情变化：

| 话数 | 演唱 |
|------|------|
| 第1、2、6话 | 朱音、阳鞠、糸青 |
| 第3话 | 朱音 |
| 第4话 | 糸青 |
| 第5话 | 阳鞠 |
| 第8话 | 真帆 |
| 第9—12话 | 朱音、阳鞠、糸青、真帆 |

这种“谁是本集主角，就由谁来唱”的安排很贴心，而真帆在第8话独唱之后，从第9话起正式加入合唱阵容——四位女主角的声音最终汇在一起，本身就是一种叙事。

# 总结

《我和班上最讨厌的女生结婚了。》讲的是一个关于“错过”与“重逢”的故事：**两位老人错过了一辈子，于是用一纸婚约，不让孩子们再错过。**

而那两个孩子，一个记着一块手帕，一个记着一场派对，在吵吵闹闹的日常里，慢慢走回了彼此的初恋。

> 恋人以上，喜欢未满——可总有一天，他们会把“喜欢”说出口。
