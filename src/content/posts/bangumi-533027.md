> 无数次的“租借”之后，和也终于要面对那个问题：她，到底是不是他的女朋友？

说实话，写这篇的时候，第五季我还没有开始看——它还躺在我的“想看”列表里。但《租借女友》对我来说已经是一部“不管怎么吐槽都会追下去”的作品了：从2020年夏天第一季开播算起，我陪和也和千鹤纠结了整整六年。

![租借女友 第五季封面](https://lain.bgm.tv/pic/cover/l/97/ba/533027_I1FHy.jpg)
*租借女友 第五季*

所以这篇文章不会剧透第五季的剧情，而是想在开看之前，先把这一季的基本信息、系列走到今天的脉络整理一遍——给同样在等这一季的你，也给即将开看的我自己。

# 一、第五季的基本信息

## 1.1 播出与制作

| 项目 | 内容 |
|------|------|
| **原名** | 彼女、お借りします 第5期 |
| **制作决定** | 2025年9月19日 |
| **播出时间** | 2026年4月10日起（DMM TV 于4月8日起先行配信） |
| **话数** | 全12话 |
| **原作** | 宫岛礼吏 |
| **监督** | 古贺一臣 |
| **音乐** | 板垣祐介、大竹智之 |
| **人物设定** | 平山宽菜 |

第四季于2025年7月播出，第五季的制作决定则在2025年9月19日公布，并在2026年4月10日开播——这是系列第一次在春季档播出，和上一季之间只隔了不到一年。

而在第五季播出期间的2026年6月27日，官方又宣布了**第六季**的制作决定。“播完一季、宣布下一季”，已经成了这部作品的固定节奏。

## 1.2 熟悉的面孔，新的配乐

监督**古贺一臣**和人物设定**平山宽菜**从第一季一路做到了第五季，这样稳定的主创阵容，在长寿番里相当难得。

这一季的音乐由**板垣祐介**和**大竹智之**担任。这两个名字对老观众来说其实并不陌生：板垣祐介曾为第一季片尾曲《告白バンジージャンプ》编曲，也编写了第二季的角色插曲《DATE》和四人合唱《Favorite Lover》；大竹智之则编曲了第二季的《まみラップ》和《桜selfish》。**由一直在为这些角色“写声音”的人来负责整季配乐**，我觉得是一件很让人安心的事。

## 1.3 声优阵容

| 角色 | 声优 |
|------|------|
| 木之下和也 | 堀江瞬 |
| 水原千鹤 | 雨宫天 |

| 更科瑠夏 | 东山奈央 |

五位主要角色的声优依旧全员续投。从2017年的漫画宣传 PV 开始，雨宫天就是千鹤的声音；到第五季，她已经陪这个角色走过了将近十年。

# 二、主题曲

## 2.1 片头曲《ノンシナリオ・エチュード》

第五季的片头曲《**ノンシナリオ・エチュード**》（没有剧本的练习曲），由**雨宫天**亲自作词、作曲并演唱，编曲是户岛友祐和川岛章裕。

这首歌有两点特别打动我。一是“千鹤的声优为千鹤所在的作品写歌”——从第一季最终话的插曲《君を通して》，到第二季的角色歌《DATE》，雨宫天一直在用歌声诠释千鹤，而这一次，她是以创作者的身份站了出来。二是歌名本身：千鹤是一个想成为女演员的女孩，“租借女友”对她来说本就是一场有剧本的表演；而“**没有剧本**”的练习曲，听起来就像是在说——这一次，不再照着剧本演了。

当然，这只是我开看之前的一点联想，到底贴不贴切，要等看完再说。

## 2.2 片尾曲《204号室》

片尾曲《**204号室**》由 **なきごと** 演唱，作词作曲水上えみり，编曲高田真路。一个以“房间号码”为名的片尾曲，放在一部男女主角是隔壁邻居、隔着一堵墙纠结了好几季的作品里，光是歌名就很有画面感。

从第一季的“厘米”，到第五季的“没有剧本”，把这些歌名排在一起看，本身就像是一段关系慢慢变化的轨迹。

# 三、系列回顾：走到第五季之前

## 3.1 一切的起点

故事始于2017年：被交往一个月的女友七海麻美甩掉的大学生木之下和也，用“租借女友”服务租了水原千鹤。一次1星差评、一场医院里的谎言，再加上“同校同学”和“隔壁邻居”这两重巧合，让这段租来的关系越缠越紧。（第一季详见[《租借女友》](/posts/rent-a-girlfriend/)）

## 3.2 越积越多的谎言与心意

第二季里，两人的租借关系迈入第二年，和也已经清楚自己喜欢千鹤，却始终说不出口；更科瑠夏、樱泽墨和七海麻美，也各自怀着心思围绕在他身边。（第二季详见[《租借女友 第二季》](/posts/rent-a-girlfriend-season-2/)）

## 3.3 为了一个梦想

原作中，在千鹤的奶奶一之濑小百合再次病倒之后，和也向千鹤提出了一个大胆的计划：**用众筹的方式拍一部电影**，让曾是著名女演员的奶奶看到孙女在银幕上演出。在瑠夏、墨、邻居八重森美仁等人的支援下，他们完成了拍摄和后期制作——这是和也第一次真正为千鹤的梦想做了一件“大事”。

> ⚠️ 以下涉及原作后期剧情。

原作中，小百合奶奶最终在第151话离世，临终前睁开眼，看到了孙女的作品。而到了第181话，麻美在大学校园里正式戳穿了千鹤的身份。这些原作的重大转折，动画会在哪一季、以什么样的方式呈现，我也和大家一样在等待。

# 四、主要角色速览

- **水原千鹤 / 一之濑千鹤**：事务所“Diamond”的人气租借女友，练马大学文学部学生，梦想是成为女演员。她在“理想女友”和“真实的自己”之间切换，是整部作品的中心。
- **木之下和也**：优柔寡断、爱胡思乱想的大学生，却总在关键时刻不顾一切地往前冲。作者宫岛礼吏曾表示，自己就是他的原型。
- **七海麻美**：和也的前女友，表面爽朗、内心极度腹黑，始终在暗处观察着和也与千鹤。
- **更科瑠夏**：患有心律不整的活泼少女，因为和也让她第一次心跳加速，便以“女友”自居。
- **樱泽墨**：怕生的租借女友后辈，在和也的鼓励下慢慢克服恐惧，有以她为主角的外传《怕生女友》。
- **八重森美仁**：住在同一栋公寓202室的大学后辈，以 Coser、YouTuber 等身份活动，知道和也与千鹤的关系后拜和也为师，尽力撮合两人。

# 五、观看顺序与建议

1. TV 动画第一季（2020年7月，详见[《租借女友》](/posts/rent-a-girlfriend/)）
2. TV 动画第二季（2022年7月，详见[《租借女友 第二季》](/posts/rent-a-girlfriend-season-2/)）
3. TV 动画第三季（2023年7月）
4. TV 动画第四季（2025年7月）
5. **TV 动画第五季**（2026年4月）——本篇
6. TV 动画第六季（已宣布制作）

《租借女友》是一部**必须按顺序看**的作品：每一季都紧接着上一季的剧情，人物关系环环相扣，跳着看很容易一头雾水。如果你是看到第五季开播才想入坑，建议先从第一季补起——十二话一季，节奏其实不算慢。

---

# 总结：没有剧本的那一幕

五季动画、六年时间，和也和千鹤之间的那堵墙，好像薄了一点，又好像一直都在。

第五季的片头曲叫“没有剧本的练习曲”。对于一个靠演技谋生、靠剧本保护自己的女孩来说，“没有剧本”大概是最可怕、也最真实的事。

**无数次“租借”之后，也许终于到了不照着剧本、说出真心话的时候。**
