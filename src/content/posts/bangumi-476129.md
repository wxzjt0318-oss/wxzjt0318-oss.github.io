> 全班一起被召唤到异世界，只有“孤单”的他什么能力都没拿到——不过一个人，也有一个人的攻略法。

说实话，《独自一人的异世界攻略》最吸引我的，是它把“班级转移”这个题材里最常被忽略的一个问题摆到了台面上：**四十多个高中生一起掉进异世界，真的能团结一心吗？** 答案当然是不能。有人抱团，有人被排挤，有人起了歪心思——而主角遥，从一开始就站在所有小团体之外。

![独自一人的异世界攻略封面](https://lain.bgm.tv/pic/cover/l/d2/66/476129_q83DE.jpg)
*独自一人的异世界攻略*

他不是被班级抛弃的人，他只是习惯了一个人。在原来的世界里，他独来独往，不参加任何社团，连同学的名字都记不住，只会给人取外号；到了异世界，他连技能都只能捡别人挑剩的，还因为“边缘人”技能没法和任何人组队。可偏偏就是这样一个人，在得知同学们陷入危机之后，决定一个人去救他们。

## 1.1 基本信息

| 项目 | 内容 |
|------|------|
| **原名** | ひとりぼっちの異世界攻略 |
| **中文译名** | 孤单一人的异世界攻略 / 独自一人的异世界攻略 |
| **作者** | 五示正司 |
| **插画** | ぶーた（第1–2卷）→ 榎丸さく（第3卷起） |
| **网络连载** | 成为小说家吧，2016年10月起；2017年10月起转至“夜曲小说”（Nocturne Novels） |
| **文库版** | OVERLAP，2018年1月起 |
| **漫画** | びび作画，连载于 COMIC GARDO |
| **累计发行** | 截至2021年5月，系列累计超过100万册 |
| **中文版** | 繁体中文版由东立出版社出版；漫画在哔哩哔哩漫画上线 |

## 1.2 一部“出了名”的网络小说

这部作品的网络连载经历本身就很有话题性：

- 它最早的标题叫《外挂技能已完售（暂定）》（チートスキルは売り切れだった（仮題）），后来因为**内容尺度问题**，从第 296 话起转到了“成为小说家吧”旗下的男性向 18 禁部门“夜曲小说”继续连载。出版实体书后，网络版才改名为《孤单一人的异世界攻略 ～外挂技能已完售～》。
- 网络版的**错字多到出名**，被公认为“错字最多的作品”，甚至有读者专门为它搭建了一个错字反馈网站。
- 实体书的插画从第三卷起由ぶーた换成了榎丸さく，第三卷后记里提到可能是档期原因。

还有一个让我印象很深的幕后故事：作者原本打算让遥**在和田中的战斗中死掉**，但因为遥的人气压倒性地高，最后改写了剧本，让他继续当主角。

# 二、故事简介：技能是先到先得的

过着“孤单”高中生活的遥，某天突然和同班同学们一起被召唤到了异世界。回过神来时，他已经站在神明面前——在这里，每个人都可以从一份列满外挂能力的技能清单里，挑选自己喜欢的技能，好在异世界活下去。

问题是：**挑技能是先到先得的**。遥比其他 42 名同学晚到了一步，外挂技能早就被挑光了。神明为了补偿他，干脆把剩下的技能全都送给了他——结果却适得其反：

- 因为“**边缘人**”技能，他没法和任何人组队；
- 因为“**一事无成**”技能，他的等级成长幅度极低；
- 掷附加属性骰子时，他掷出了两个 MAX，却把全部属性都堆到了**运气**上，结果运气超标，三天两头触发普通人碰都碰不到的迷宫陷阱……

于是，遥只能一个人在异世界冒险。就在这时，他得知了同班同学们的危机，暗自下定决心要拯救他们——踏上了一条**不靠外挂、超越外挂**的异端最强之路。

# 四、一个班级的分崩离析

## 4.1 外号即身份

这部作品有一个很独特的设定：**遥几乎记不住任何人的名字**，所以同学们大多只以外号登场——“班长”“副班长A”“辣妹队长”“阿宅A”“肌肉笨蛋A”“图书委员”……原作里大多数同学都没有公开全名，直到动画官方才给每个人都起了正式的名字。

这种写法乍看是偷懒，其实很巧妙：它让读者完全站在遥的视角——在遥眼里，班级就是一群“标签”。而随着故事推进，这些标签背后的人，一个个变得具体起来。

## 4.2 班上的小团体

最初，包括遥在内全班共有 43 人（男生 23 人、女生 20 人），分成了好几个小团体：

| 小组 | 特点 |
|------|------|
| **班长组** | 班长和三位“副班长”，把一群有怪癖的同学统领成一个班级 |
| **辣妹组** | 五名时髦的辣妹，第一批被遥“使役”的人，升级比其他人快 |
| **体育生女子组** | 排球社、新体操社、游泳社……其中四人被称为班上的“无脑女四天王” |
| **文化生女子组** | 图书委员、手艺社女、料理社女 |
| **阿宅组** | 四名宅男，校内除了班长以外唯一和遥有交集的人，到异世界后成了班上最强的队伍 |
| **体育生男子组** | 五名全国顶级水平的男性体育生 |
| **不良少年组** | 六名品性败坏的男生 |

## 4.3 营地被烧毁之后

> ⚠️ 以下内容涉及原作剧情。

不良少年组在田中的怂恿下，学会了“魅惑”和“傀儡”技能，企图对班上的女生动歪脑筋。阿宅组向班长报告了他们的动向，还封印了他们的技能；计划败露的不良少年组被逐出营地，临走前**放火烧了营地**。

讽刺的是，营地被烧之后，辣妹组一度把责任推到阿宅组身上，阿宅组被迫离开同学身边，还要躲避不良少年组的追杀。体育生男子组也因为对班长的不信任而离开了营地。一个班级，就这样一点点散掉了。

## 4.4 田中：真正的元凶

这一切背后的人，是班上的数学天才**田中**——他是遥唯一会用名字称呼的同学（虽然也经常叫错）。

田中在原来的世界里过得很不愉快：没法专心学习，还被不良少年逼着帮他们写作业，一心想要逃离那样的校园生活。穿越之后，他得到了许多外挂技能，性格变得更加扭曲。他用“精神操作”技能制造班级内部的对立，假装当不良少年组的军师，私下用“模仿”复制他人的技能，最终杀死了包括不良少年组在内的十二名男同学，甚至打算对拥有“掠夺”技能的班长下手。

最后，遥发现了“模仿”技能有使用次数的限制，击败了田中，并当场处决了他。**田中是遥唯一亲手杀死的同班同学。**从此，班上的人数变成了 30 人（男生 10 人、女生 20 人）。

我觉得田中这个角色写得很有分量。他不是天生的恶人，他是被原来那个世界逼到角落里的人。可同样是“边缘人”，遥选择了去救别人，田中选择了报复所有人——这两个人，几乎是一体两面。

# 五、角色解析

## 5.1 遥：嘴上轻浮，手上靠谱

遥 171 公分，AB 型血，归宅部，兴趣是读书。他性格孤僻、我行我素，轻浮到几乎不听别人把话说完，总是不按常理出牌，让周围的人都很不放心。可他**厨艺高超**，而且过去经历过丧亲之痛。

刚到边境城镇奥姆伊时，他连冒险者都登记不了——公会规定要 10 级才能登记，他当时只有 7 级（而且未满 20 级必须强制组队，可他偏偏组不了队）。后来，他从盗贼手里救出了边境伯爵千金梅莉艾尔，才拿到了奥姆伊的身份证；再后来，他拯救了奥姆伊，又接连拯救了迪欧瑞尔王国，被人称为“**边境勇者**”和“**黑发军师**”。

## 5.2 班长：潜在的跟踪者

班长 168 公分，网球社，兴趣一栏写着“**寻找遥**”（有人说她是潜在的跟踪者）。她有领导才能，正义感强，是班上的校花，身上总带着一个哨子，被遥称为“超级班长”。

她和遥在小学就认识，对遥有好感，却也常常被遥的脱序行为搞得头疼，经常对他说教。她拥有“掠夺”技能——这也是田中想对她下手的原因。

## 5.3 安洁莉卡：迷宫深处的骨骸

安洁莉卡是迷宫皇，外号“甲胄班长”，实力强劲。她原本是迷宫深处的一具骨骸，因为诅咒而无法死去；被遥“使役”之后成了同伴，又因为装备的缘故恢复了人类的面容。由于被困在地下迷宫太久，她的语言能力几乎完全退化，只能用简单的肢体语言交流，正在努力学习手语和简单的单词。早见沙织的声音给了这个“几乎不说话”的角色很多温度。

## 5.4 辣妹组与阿宅组：被误会的人

遥对辣妹有偏见，原作里甚至用很难听的外号称呼辣妹队长（动画里改成了“辣妹队长”），把她们和不良少年组相提并论——但事实上，她们并不是他以为的那样。

阿宅组则是另一种“被误会”：他们因为揭发不良少年组而被迫离开营地，却在异世界成了**班上最强的队伍**，也是第一个和遥会合的小组。阿宅A小田达也后来还在王国内战期间，因为目睹商国的人袭击兽人村庄而愤怒，率领班上的男同学袭击了商国的港口。

# 六、入坑建议

**适合谁看？**

- 喜欢班级转移、多人群像式异世界作品的观众；
- 喜欢嘴碎吐槽型主角、节奏跳脱的喜剧风格；
- 想看“没有外挂的人如何赢过有外挂的人”的观众。

**需要知道什么？**

- 原作网络版尺度较大，文库、漫画和动画都做了含糊处理，但整体仍带有不少擦边元素；
- 遥的说话方式非常密集跳跃，第一集可能需要适应一下；
- 第二季已于 2026 年 7 月宣布制作。

---

# 总结

《独自一人的异世界攻略》讲的，是一个“多出来的人”的故事。

全班 43 个人分组，他总是落单；挑选技能，他只能捡剩下的；就连技能本身，都在告诉他“你没法和任何人一起”。可当班级四分五裂、有人背叛、有人死去的时候，正是这个从来不合群的人，一个个地把同学们找了回来。

**孤单不是他的弱点——是他一个人，也能走到所有人身边的理由。**
