> 假扮的恋人、真心的暗恋、十年前的约定——那把锁对应的钥匙，究竟在谁的手里？

说实话，OAD 这种东西，通常是"粉丝专属福利"——没看过正篇的人看了一头雾水，看过正篇的人看了心满意足。《伪恋 OAD》就是这样一部作品：它不推进主线，不揭开钥匙之谜，只是把那群熟悉的角色放进一些"如果正篇有时间就好了"的小故事里，让大家多甜一会儿。

![伪恋 OAD封面](https://lain.bgm.tv/pic/cover/l/2d/bb/104196_mIzDE.jpg)
*伪恋 OAD*

如果你是看完《伪恋》第一季意犹未尽的人，那这四话 OAD 就是给你的。

# 一、什么是《伪恋 OAD》？

## 1.1 基本信息

| 项目 | 内容 |
|------|------|
| **原名** | ニセコイ OAD |
| **形式** | OAD（随原作单行本特装版附赠） |
| **话数** | 全4话 |
| **发售时间** | 2014年10月起 |
| **动画制作** | SHAFT |
| **监督** | 龙轮直征（第1–2话） |
| **系列构成** | 东冨耶子、新房昭之 |
| **人物设定** | 杉山延宽 |
| **音乐** | 菊谷知树 |

## 1.2 OAD 和 OVA 有什么不同？

很多人分不清 OAD 和 OVA。简单来说：

- **OVA**（Original Video Animation）：直接以录像带、DVD、蓝光形式发售的动画
- **OAD**（Original Animation DVD）：通常**随原作漫画单行本的特装版一起附赠**，买漫画送动画

《伪恋 OAD》就是典型的后者：它是写给"已经在买漫画"的粉丝的礼物。

## 1.3 和正篇的关系

OAD 在时间线上处于第一季播出之后、第二季《伪恋：》之前，内容多改编自原作中**动画正篇没有收录的日常篇章**。也就是说，它不是"新剧情"，而是"补完"——把原作里那些好玩、好甜，但在 TV 动画里没地方塞进去的小故事，单独做成了动画。

制作班底和第一季基本一致，依旧由 **SHAFT** 负责，画风、配音、配乐的感觉都和 TV 版无缝衔接。

# 二、主要角色回顾

| 角色 | 声优 | 在 OAD 里的看点 |
|------|------|------|
| **一条乐** | 内山昂辉 | 依旧是被女孩子们折腾得团团转的吐槽役 |
| **桐崎千棘** | 东山奈央 | 嘴硬心软的程度又升级了 |
| **小野寺小咲** | 花泽香菜 | 一如既往的温柔与欲言又止 |
| **鸫诚士郎** | 小松未可子 | "杀手少女"的女孩子一面越来越藏不住 |
| **橘万里花** | 阿澄佳奈 | 直球攻势依旧火力全开 |

## 2.1 一条乐与桐崎千棘

到了 OAD 的时间点，乐和千棘的"假情侣"关系已经维持了一段时间，两个人吵架的频率没降，可吵完之后互相在意的样子越来越明显了。OAD 里没有帮派监视的压力，两人的互动反而更自然——**少了"演给别人看"，多了"演着演着就当真了"**。

## 2.2 小野寺小咲

小咲在 OAD 里依旧是那个"差一点就说出口"的女孩。番外故事给了她不少和乐单独相处的机会，每一次都让小咲党心跳加速，又每一次都在最关键的时候被打断——这个"梗"在 OAD 里同样没有缺席。

## 2.3 鸫诚士郎与橘万里花

鸫在 OAD 里有不少"被迫穿女装/被发现女孩子一面"的桥段，她手足无措的样子是 OAD 最好的笑点之一；万里花则继续以"未婚妻"自居，对乐展开毫不掩饰的攻势，和千棘之间的火药味一如既往。

# 三、看点：为什么值得一看？

## 3.1 没有主线压力的"纯甜"

TV 正篇里，乐和女孩子们的相处总是被"帮派危机""钥匙之谜"推着走；而 OAD 卸掉了这些包袱，只剩下最纯粹的校园日常和恋爱喜剧。**如果说正篇是正餐，OAD 就是甜点**。

## 3.2 SHAFT 风格的放大

SHAFT 那种夸张的分镜、色块和歪头杀，在短篇 OAD 里反而更加放得开。很多搞笑桥段的节奏比 TV 版更快、更密，看起来非常过瘾。

## 3.3 原作粉丝的"补完"

对于先看动画再读漫画的观众来说，OAD 能让你看到原作里那些没被 TV 动画收录的有趣篇章；对于先读漫画的原作党来说，OAD 则是"终于看到这一话动起来了"的惊喜。

# 四、借 OAD 聊聊：你站哪一队？

OAD 最大的价值，其实是让每位女主角都有了"多一点戏份"的机会。借这个机会，聊聊每位女主角最打动人的地方：

## 4.1 千棘党：从"最讨厌"到"最在意"

千棘的魅力在于**变化**。她和乐的关系是从"互相看不顺眼"开始的，每一点靠近都要跨过自己的骄傲。OAD 里的千棘依旧嘴硬，可那些不经意间的脸红、闹别扭、偷偷关心，比任何直白的告白都更有说服力。千棘党最爱的，就是这种"看着她一点点变得坦率"的过程。

## 4.2 小咲党：双向暗恋的遗憾美

小咲的魅力在于**纯粹**。她和乐其实是互相喜欢的，只是两个人都太害羞、太温柔，总是在最关键的时候退一步。OAD 里那些"差一点就说出口"的瞬间，对小咲党来说既甜又痛——这种"明明彼此喜欢却总是错过"的遗憾，正是初恋最真实的样子。

## 4.3 鸫党：杀手的第一次心动

鸫的魅力在于**反差**。一个冷静专业的杀手，在面对乐的时候却完全不知所措，连自己的心情都搞不懂。OAD 给了鸫更多"被迫展示女孩子一面"的机会，每一次都让人忍不住想多看几眼。

## 4.4 万里花党：最勇敢的直球

万里花的魅力在于**勇气**。在所有人都在犹豫、试探的时候，只有她从一开始就毫不掩饰地说"我喜欢你"。这份直球背后，是她从小体弱多病、把与乐重逢当作信念的过去。OAD 里的万里花火力全开，让人很难不被她的执着打动。

无论你站哪一队，OAD 都会给你的本命一点额外的高光时刻——这大概就是它存在的意义。

# 五、观看建议

## 4.1 观看顺序

1. 《伪恋》第一季（详见[《伪恋》](/posts/nisekoi/)）
2. 《伪恋 OAD》
3. 《伪恋：》第二季

**强烈建议先看完第一季再看 OAD**——OAD 默认你已经熟悉所有角色和他们之间的关系，没看过正篇会少很多乐趣。

## 4.2 适合谁？

- 看完第一季、还想再多看看女主角们的伪恋粉
- 有自己的"本命"、想看本命多一点戏份的站队党
- 想放空大脑、单纯看点轻松恋爱喜剧的观众

---

# 六、总结：甜点时间

《伪恋 OAD》不是一部需要深度解读的作品，它的意义很简单：**让喜欢这些角色的人，再多和她们待一会儿**。

四话的篇幅不长，没有沉重的剧情，也没有揭开任何谜底。但正是这些"不重要"的日常，让乐和女孩子们的关系显得更加真实——毕竟，恋爱本来就是由无数个吵吵闹闹的平凡日子组成的。

如果你也是那个在第一季结尾心想"再多看一点就好了"的人，那就来吃这份甜点吧。
