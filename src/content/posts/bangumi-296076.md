> 只是一次的“租借”，却让他再也分不清，哪一部分是演出来的恋人，哪一部分是真心。

说实话，《租借女友》大概是我看过的恋爱番里，**弹幕吵架最凶的一部**。有人被千鹤美到当场入坑，有人被和也的优柔寡断气到弃番，还有人一边骂“这男主怎么这样”一边准时追更——我就是最后那一种。

![租借女友封面](https://lain.bgm.tv/pic/cover/l/7a/37/296076_6cP6Q.jpg)
*租借女友*

它的设定很简单：一个失恋的废柴大学生，花钱租了个女朋友。可就是这个“租来的关系”，被一个又一个谎言越缠越紧，最后变成了一张谁也挣不脱的网。而在网的中央，是一个想当女演员的女孩，和一个总是在关键时刻退缩、却又总在最关键的时刻往前冲的男孩。

# 一、作者与原作

## 1.1 宫岛礼吏

《租借女友》（日语：彼女、お借りします，简称“かのかり”）的作者是漫画家**宫岛礼吏**。作品从《周刊少年Magazine》2017年第32号开始连载，单行本已出版38册；截至2024年4月，纸本书累计发行超过1300万册，电子版在中国大陆也售出了约70万部。

一个很有意思的细节：作者在单行本第五卷后记中提到，**他自己就是男主角木之下和也的原型**。难怪和也那些让人抓狂的小心思，写得那么真实。

| 项目 | 内容 |
|------|------|
| **原名** | 彼女、お借りします |
| **作者** | 宫岛礼吏 |

## 1.2 故事简介

2017年，大学生**木之下和也**被交往仅一个月的女友七海麻美提出分手，自暴自弃之下，他用“租借女友”服务租了一位名叫**水原千鹤**的女孩当一日女友。

因为千鹤在约会时的表现实在太过完美，和也觉得自己被“演技”欺骗了，事后给了她最低的1星评价。千鹤因此讨厌和也，在第二次约会时大发雷霆。可就在约会进行到一半时，和也的祖母病倒了。两人赶到医院后，为了让祖母安心，和也谎称千鹤是自己的女朋友——而祖母，非常中意千鹤。

就在和也决定挥别情伤、好好面对大学生活时，他却发现：千鹤和他是同一所大学的学生，更是住在同一栋公寓的**隔壁邻居**。从这一刻起，一个谎言，开始需要无数个谎言来圆。

TV 动画化的消息在2019年12月公布，第一季于2020年7月至9月播出。最终话播出后，官方随即宣布了第二季的制作——此后这部作品几乎保持着“播完一季、宣布下一季”的节奏，一路做到了第五季，第六季也已经确定。

## 2.2 声优阵容

| 角色 | 声优 |
|------|------|
| 木之下和也 | 堀江瞬 |
| 水原千鹤 | 雨宫天 |
| 七海麻美 | 悠木碧 |
| 更科瑠夏 | 东山奈央 |
| 樱泽墨 | 高桥李依 |
| 木部芳秋 | 赤坂柾之 |
| 栗林骏 | 梶原岳人 |
| 木之下和（和也的奶奶） | 野泽由香里 |
| 一之濑小百合（千鹤的奶奶） | 定冈小百合 |

这份名单里藏着一个有趣的小故事：在2017年的漫画宣传 PV 里，千鹤的声优就已经是**雨宫天**；而在2018年的宣传 PV 里，**悠木碧**一人分饰千鹤和麻美两个角色——到了动画版，她最终接下了麻美。一个声音温柔清亮、能演“理想女友”也能演“真实的千鹤”，一个声音甜美、却能在一瞬间变得阴冷——这两位的选角，可以说是这部动画最成功的地方之一。

## 2.3 主题曲

- **片头曲《センチメートル》**（厘米）：the peggies 演唱，作词作曲北泽ゆうほ。第1话被用作片尾曲。
- **片尾曲《告白バンジージャンプ》**（告白蹦极）：halca 演唱，作词作曲前山田健一，用于第2–6话、第8–12话。
- **第7话片尾曲《FIRST DROP》**：halca 演唱。
- **第12话插曲《君を通して》**（透过你）：由千鹤的声优雨宫天演唱。

片头曲的歌名“厘米”很妙：和也和千鹤之间，明明只隔着一堵公寓的墙，却怎么也跨不过那最后几厘米。而最终话里雨宫天演唱的《君を通して》，则把整季的情绪轻轻收住。

# 三、剧情解析：一个谎言接一个谎言

> ⚠️ 以下内容包含第一季及原作前期的剧情描述。

## 3.1 第一阶段：1星差评与医院里的谎言

故事的起点，是和也那个有点小气、又有点可怜的1星差评。他觉得千鹤的完美只是演技，于是决定再租一次，想借机羞辱她。结果在水族馆，他当众说出了千鹤的租借女友身份，千鹤卸下“理想女友”的面具，把他狠狠教训了一顿。

而就在这时，祖母病倒住院。和也阴差阳错地把千鹤带到了家人面前，祖母对千鹤一见倾心。更巧的是，千鹤的奶奶一之濑小百合和和也的奶奶，竟然是医院里结识的好友。从这一刻起，“假装交往”就不再是两个人之间的事，而是牵动着两位老人的心愿。

## 3.2 第二阶段：下田之行

第一季里最让人心动的段落，大概是众人去下田游玩的那一段。在木部的助攻下，和也和千鹤一起乘渡轮出海；和也在船上打电话，还想挽回麻美。就在这时，因为生病和晕船，千鹤跌入了海中——和也选择丢下手机，跳下去救人。

入水的那一瞬间，他意识到自己爱的似乎是千鹤，却不想承认。而他自己也在过程中溺水，被千鹤做了人工呼吸；可回去之后，他只觉得对方是“为了保护顾客”。直到某天，他眼前突然浮现出千鹤的音容笑貌——他终于承认，**自己现在喜欢的，是千鹤**。

## 3.3 第三阶段：越来越多的“女朋友”

随着剧情推进，和也的大学生活里又出现了两个同样是租借女友的女孩。

一个是**更科瑠夏**。她起初以和也好友栗林骏的租借女友身份登场，却在四人约会中私下点破了千鹤的身份。和也为了保护千鹤，死缠烂打地拜托瑠夏保密——结果瑠夏被他珍惜租借女友的诚意打动，心跳加速，认定和也就是她的真爱，并以“交往”作为保密的条件。

另一个是**樱泽墨**。她是千鹤所在事务所的后辈，内向到有着超乎想像的交流障碍。为了让她适应工作，千鹤拜托和也免费租借她一天，陪她练习约会。

而前女友**七海麻美**，则始终在暗处观察着和也的一举一动。

## 3.4 谎言的代价

《租借女友》最让人揪心的，是它把“谎言”写得非常真实：每一个谎言在说出口时都有不得已的理由——为了奶奶、为了千鹤的工作、为了不让谁伤心——可它们叠在一起，就成了一座随时可能崩塌的高楼。

和也想说真话，却总在开口的前一秒退缩；千鹤想划清界限，却总被奶奶们的笑容拉回来。**这两个人，谁都没有坏心，却谁都没办法停下来。**

# 四、角色深度解析

## 4.1 水原千鹤：理想女友与真实的女孩

千鹤的本名是**一之濑千鹤**，在租借女友事务所“Diamond”里以“水原千鹤”为艺名，是事务所排名第一的新人，平均评分一直是满分5星——直到和也给了她1星，她的平均分掉到了4.7。她非常在乎这个评分，为了第二次约会，甚至特地买了自己没兴趣的鱼类图鉴，把鱼的名字都背了下来。

在学校里，她穿着土气、绑着双麻花辫、戴着眼镜，除了和也没人认得出她就是那个“S级美少女”。她做租借女友的目的，是为了支付演员训练班的学费、磨练演技——**她想成为女演员**，而这个梦想，来自她曾经是著名女演员的奶奶一之濑小百合。

千鹤最迷人的地方，在于她的“两面”：作为租借女友时，她是温柔完美的理想女友；卸下面具后，她会毒舌、会生气、眼睛会变成“猫眼”。而观众真正爱上的，往往是后者。

## 4.2 木之下和也：废柴，但不只是废柴

和也是练马大学的学生，复读过一年，性格优柔寡断，靠父母给的100万日元入学助金过日子。他虚荣、爱妄想、没什么特长，生活一团糟——说实话，他是近年恋爱番里最“招骂”的男主角之一。

但他的儿时好友木部这样评价他：“他像个笨蛋，从始至终坚持做着自己的梦。”这也是一种才能。和也的笨拙和懦弱是真的，他在关键时刻的勇敢和温柔也是真的——下田的那一跳，就是最好的证明。

## 4.3 七海麻美：甜美外表下的暗面

麻美是和也的前女友，表面上性格爽朗，实际上极度腹黑且善妒。她对所有事情都有异常敏锐的观察和分析，有一个用来发布黑暗心情的私人账号“沼”。她当初只是随便答应和和也交往，分手后看到和也和千鹤在一起，却不明白自己为何会对和也如此执着。

麻美是这部作品里最复杂的角色之一。她讨人厌，却又让人忍不住想知道：**她到底在害怕什么？**

## 4.4 更科瑠夏：心跳的意义

瑠夏是活泼主动的短发少女，患有心律不整，从小心跳就比一般人慢。朋友们感受到的开心，她完全感觉不到，甚至觉得自己是“没有感情的机器人”。她做租借女友，就是为了找到能让自己心跳加速的人——而和也，让她的心跳第一次飙到了每分钟90下。

她的喜欢直接、热烈，甚至有点霸道，但出发点简单到让人心疼：**她只是想确认，自己也能像别人一样心动。**

## 4.5 樱泽墨：最努力的怕生女孩

墨是千鹤的事务所后辈，内向到几乎说不出话，却为了改变自己而选择了租借女友这份最需要“与人交流”的工作。她在和也的鼓励下一点点克服恐惧，是整部作品里最治愈的角色。宫岛礼吏甚至专门为她画了一部外传漫画《怕生女友》。

## 4.6 配角们：好友与两位奶奶

和也身边的两位好友也很有存在感。**木部芳秋**是和也的小学同学，个性耿直，还有一手骇客技术，他一直真心觉得和也能给千鹤带来幸福；**栗林骏**老家种苹果，因为羡慕和也“有女朋友”也跑去租借女友，租到的正是瑠夏。

而真正推动这段关系的，其实是两位奶奶。和也的奶奶**木之下和**今年76岁，个性强势，在木之下家人眼里“像大神一样”，却又不喜欢老人家的东西，平时会玩推特和电子游戏；千鹤的奶奶**一之濑小百合**曾经是著名的女演员，正是她的演技，让千鹤立下了成为演员的梦想。两位奶奶在医院里成了好友，还私下计划着要把孙子和孙女凑成一对——**整部作品最大的“压力来源”，也是最温柔的“助攻”，就是她们**。

# 五、作品的争议与影响

《租借女友》的人气和争议几乎是同时出现的。

在国内，bilibili 在动画化之前就获得了漫画的代理权，漫画在 bilibili 漫画平台的阅读和支持排名一直位于前列；而中国大陆的电视动画代理权则由 AcFun 获得。期间 bilibili 一度把漫画的译名改为《理想女友》，几天后又改了回来。

在海外，动画第一季在台湾由 Animax 以国日双语播出，并对部分画面做了删减或模糊处理；香港 J2 台则将全部集数分级为“M 成年观众”。2021年8月，拉脱维亚议会甚至以“违反公共道德”为由，提议禁止电视台播放本作，但这一提案最终被国会否决。

2022年，作品还被改编为真人电视剧，由大西流星主演、樱田日和饰演千鹤，在朝日电视台播出。

**适合谁看？** 如果你喜欢“慢热、纠结、心意藏不住”的恋爱故事，并且能接受一个不那么完美的男主角，《租借女友》会给你很多心动和抓狂的时刻。但如果你最受不了“主角明明有机会却不说”，那请做好心理准备——这部作品，最擅长的就是让你着急。

# 总结：租来的关系，真心的人

《租借女友》的故事，从一个“租来的关系”开始。可越往后看，你越会发现：在这段关系里，所有人都是真心的——千鹤对梦想的真心，和也对千鹤的真心，奶奶们对孙辈的真心，甚至麻美那份扭曲的执着，也是一种真心。

谎言可以租借，心动却不能。

**只是一次的“租借”，便拥有了闪耀的“真实”。**
