> 在一家店员都不太正常的家庭餐厅里，打工的日常本身就是一出停不下来的喜剧。

说实话，《迷糊餐厅》是我心目中"职场喜剧"这个分类里最不像职场的一部。说是家庭餐厅打工的故事，可你几乎看不到谁在认真端盘子：店长在吃店里的东西，主任在念叨店长，厨师在捉弄同事，新来的男生在躲一个随时会挥拳的女孩子——偏偏这家店就是莫名其妙地开得好好的。

![迷糊餐厅封面](https://lain.bgm.tv/pic/cover/l/87/db/4255_jm37v.jpg)
*迷糊餐厅*

它好笑，是因为每个人都怪得理直气壮；它耐看，是因为这群怪人之间藏着各种各样说不出口的心意。佐藤喜欢八千代，八千代满心都是店长；伊波喜欢小鸟游，却控制不住自己的拳头；小鸟游嘴上说着"十二岁以上都是老女人"，却一天不落地照顾着整个家。笑着笑着，就会被戳到。

# 一、原作：四格漫画与"犬组""猫组"

## 1.1 基本信息

| 项目 | 内容 |
|------|------|
| **原名** | WORKING!! |
| **英文名** | WAGNARIA!! |
| **作者** | 高津雁野（高津カリノ） |
| **连载杂志** | 史克威尔艾尼克斯《YOUNG GANGAN》 |
| **连载时间** | 2005年1号 – 2014年22号 |
| **番外篇** | 《迷糊餐厅 Re:Order》，2015年2号 – 12号 |
| **繁体中文版** | 东立出版社 |
| **形式** | 四格漫画（一般以六页为一个单位连载） |

## 1.2 一家餐厅，两个分店

《迷糊餐厅》有一个很特别的出身。作者高津雁野从2002年起就在个人网站上连载同名的网络漫画，那正是她作为职业漫画家出道的契机；后来在《YOUNG GANGAN》连载的版本，和网络版共用同一个世界观，但舞台是"瓦古娜利亚"连锁餐厅的不同分店。

作者自己把网络版称为"**猫组**"，把杂志连载版称为"**犬组**"。两边的剧情基本没有联系，但有部分人物关系是相连的——比如犬组店长白藤杏子就认识猫组的店长榊研一郎，还三不五时强迫对方请客。犬组连载结束后，高津又在持续连载的猫组漫画后期让犬组角色大量登场，直到完结。

我们通常说的《迷糊餐厅》三季 TV 动画，讲的都是**犬组**的故事；猫组则在2016年另外改编成了《WWW.WORKING!!》。

## 1.3 舞台：一家"危险得让人上瘾"的餐厅

故事发生在北海道某城市的"瓦古娜利亚"分店。这家店被常客评价为"**危险的感觉令人上瘾**"——光看这句评语，就知道这不是一家普通的餐厅。

四格漫画的形式决定了它的节奏：每一格都要有笑点，但四格和四格之间又巧妙地连接成更长的故事。维基百科的评价是"节奏掌握良好"，我觉得这正是它能连载近十年的原因。原作在2007年10月下旬曾排进日本漫画销售榜第七名，2009年3月底的一周里销量达到73054套。

# 二、剧情简介：被"小东西"骗进餐厅的男主角

## 2.1 故事梗概

高一生**小鸟游宗太**有一个不太好说出口的爱好：他极度喜欢"小小的东西"。萌娘百科的介绍非常直白——"这货真不是萝莉控，只是一个极度喜欢小小的东西的普通的变态"。

某天，他被一个看起来像小学生、实际上是高二学姐的女孩子**种岛白杨**招募去打工——用萌娘百科的说法，是被她"诱骗"进去的。就这样，小鸟游走进了瓦古娜利亚，开始了一段被怪人包围的打工生活：

- 不干活只吃东西的前不良少女店长；
- 随身带着日本刀、满脑子都是店长的外场主任；
- 面无表情、烟瘾很重的厨师；
- 笑眯眯却掌握所有人把柄的另一位厨师；
- 以及一个患有男性恐惧症、会痛殴所有男性的女孩子。

## 2.2 无聊、喜感又有爱

萌娘百科对剧情的概括是"讲述小鸟游和瓦古娜利亚的店员之间发生的无聊喜感又有爱的小故事"。这三个词我觉得用得特别准："无聊"是因为它确实没有什么大事件，"喜感"是因为每个人都怪得好笑，"有爱"则是因为在这些吵吵闹闹里，藏着好几条认真的感情线。

# 五、角色深度解析

> ⚠️ 以下内容涉及原作漫画后期剧情。

## 5.1 小鸟游宗太：店里唯一的常识人

小鸟游是登场人物里最有常识的一个——至少他自己这么认为。他从小被高大的姐姐们围绕着长大，因此对"大的东西"感到反感，又因为父亲和三姐梢的影响而喜欢布偶等可爱物品。在瓦古娜利亚待得越久，这个偏好就越严重，甚至认为"十二岁以上的女生就是老女人"（但种岛例外）。他最喜欢的东西是**水蚤**，房间里还摆着用相框装起来的水蚤图片。

但这个"变态"其实是全能型的好孩子：学习好、运动好、家务一流。因为不能把三个姐姐都不做的家务推给妹妹，他每天在学校、打工和家务之间连轴转。大家以为他是为了种岛才继续打工，其实他是在拼命存钱，想早点离开家。

小鸟游最出名的"黑历史"是**女装**。小时候被已故的父亲穿上女装拍照，让他对女装极为抗拒；可他女装起来偏偏是个大美人，佐藤还给这个形象起名叫"**小鸟儿**"（ことりちゃん）。动画第一季第9话和第13话，他都有女装登场。

## 5.2 种岛白杨：一点都不小！

种岛是把小鸟游拉进店里的人。她17岁，长相、身高和个性却完全不像，常被客人当成中小学生，连学校老师都把她当小孩。她一直为身高烦恼，口头禅是"**一点都不小！**"，为了长高每天喝牛奶却没什么效果，据说还在鞋底垫了增高垫。

种岛叫小鸟游（たかなし）总是叫成"小游鸟"（かたなし），小鸟游劝了几次无效后干脆放弃了，但被种岛以外的人这么叫他就会生气。她经常被佐藤和相马捉弄，却被全店的人疼爱着——有她在的地方，气氛就会变得欢乐起来。

## 5.3 伊波真昼：喜欢，但是忍不住打你

伊波是整部作品里最让我心疼的角色。因为父亲偏激的教育——不断向她灌输"男人非常可怕"——她患上了男性恐惧症（连雄性动物都怕），接待女客人完美无缺，见了男客人却会一拳打过去。她的腕力强大到经常打坏墙壁和电线杆。

小鸟游是负责照料她的人，也是她最常殴打的对象。为了能靠近伊波，小鸟游甚至随身带着一只"魔术手"（连出门买东西都带着）。渐渐地，伊波对他放下了戒心，尤其迷上了小鸟游对她父亲说教时的样子，并在**动画第一季第10话**中承认了自己喜欢小鸟游。

可问题是，她喜欢他，却还是忍不住打他；而她又害怕治好了暴力倾向以后，小鸟游就不会再关注她了。于是她陷入了一种"喜欢但是讨厌"的状态——这种矛盾，正是伊波这条感情线最动人的地方。

还有一个小细节：被小鸟游夸过发夹之后，伊波每天戴的发夹都不一样。白色情人节时小鸟游送了她一大堆发夹当回礼，她就每天从中挑一个来戴。

## 5.4 轰八千代与白藤杏子：刀与店长

**轰八千代**是外场主任，总是眯着眼睛面带微笑，工作认真，却随身带着一把日本刀（理由是老家开刀具店）。小学时被白藤从欺凌中救出后，她就一心一意地照顾着白藤，能一口气花好几个小时讲店长的事——这让其他店员，尤其是佐藤，负担很重。

**白藤杏子**是店长，原本是不良少女，什么都不做，一有空就找东西吃，认为店里的食物全是自己的。但她并非没有责任感：坚决反对店内恋爱、会赶走欺负种岛的客人，也非常疼爱小孩子，再饿也不会抢小孩的蛋糕。店里的打工生基本上都是她招进来的。

## 5.5 佐藤润：带着胃药的单恋者

佐藤是厨房里最认真工作的人，长得高大，外表冷酷内心温柔。他喜欢八千代，可八千代满心都是店长，还偏偏最信任他，常常找他倾诉——对佐藤来说，这就是每天都要经历的折磨。所以他随身带着头痛药和胃药，心情无处发泄时就去捉弄种岛。

在漫画第217到219道菜中，佐藤终于向八千代告白，两人正式成为恋人。对于看了那么久"单恋地狱"的观众来说，这是全作最让人想鼓掌的时刻之一。

## 5.6 相马博臣：笑眯眯的情报贩子

相马总是面带笑容，实际上却掌握了大半店员的弱点，以"说服"之名让别人帮他干活，所以就算店里很忙，他看起来也总是很闲。小鸟游认为他是店里最腹黑的人。不过他也有搞不定的人：音尾经理没有弱点，山田的思路异于常人，而伊波——他还没开口就会被打。

## 5.7 山田葵与小鸟游家

**山田葵**是被音尾经理捡回来的少女，姓名、年龄、经历全都不明，曾住在店里的阁楼，打破的餐具多到有专用的破损报告书。她想把山田家"凑齐"：音尾当爸爸、八千代当妈妈、相马当哥哥……

**小鸟游家的四姐妹**则是另一个笑点来源：用六法全书讲歪理的律师长女一枝、生活不能自理的恋爱小说家次女泉、常常喝醉倒在玄关的合气道讲师三女梢，以及为了帮哥哥而拼命长高、已经追上哥哥身高的小学生四女荠。小鸟游对"大"的抗拒，有一半要归功于她们。

# 六、这部作品好在哪里

## 6.1 怪癖是笑点，也是伤口

《迷糊餐厅》的每一个怪癖背后几乎都有来历：伊波的拳头来自父亲偏激的教育，小鸟游对"大"的抗拒来自被姐姐们包围的童年，八千代的执着来自小学时被店长救下的那一刻，松本对"平凡"的执念则来自一次远足时被朋友说"你的便当很奇怪"。

作品从不把这些来历拿出来煽情，它们只是轻描淡写地存在着。但正因为有这些来历，你笑完之后会觉得：这些人怪归怪，却都是认真活着的人。

## 6.2 三条单恋，一个屋檐

佐藤喜欢八千代，八千代喜欢店长；伊波喜欢小鸟游，小鸟游喜欢"小东西"。这家店里的感情几乎全是错位的单向箭头，而作品最擅长的，就是让这些箭头在同一个后厨、同一个外场里来回碰撞——碰出笑点，也碰出一点点酸。

第一季只是把这些箭头一一画出来，真正的变化要留到后面两季。所以看完第一季之后那种"好想知道后来怎么样了"的感觉，就是这部作品最成功的钩子。

# 七、番外话题："催婚餐厅"

《迷糊餐厅》在粉丝圈里有一个著名的外号——"**催婚餐厅**"。因为动画播出之后，出演的声优接二连三地传出结婚消息：白藤杏子的渡边久美子、小鸟游一枝的白石凉子、小鸟游梢的伊藤静、种岛白杨的阿澄佳奈、山田桐生的日野聪、小鸟游泉的日笠阳子、小鸟游荠的斋藤桃子、松本麻耶的川濑晶子、真柴美月的户松遥……作者高津雁野还为其中好几位画了结婚贺图。

这当然只是个玩笑，但也说明了这部作品在声优圈和粉丝圈里的存在感。

# 八、观看顺序与入坑建议

## 8.1 观看顺序

1. **第一季《WORKING!!》**（2010年4月，全13话）——本篇；
2. **第二季《WORKING'!!》**（2011年10月，全13话）；
3. **第三季《WORKING!!!》**（2015年7月，全13话）＋第14话一小时特别篇《LORD OF THE 小鸟游》（2015年12月）；
4. 猫组的《WWW.WORKING!!》（2016年10月，全13话）是另一家分店的故事，可以独立观看。

## 8.2 适合谁看

- 想看一部**纯粹轻松、笑点密集**的日常喜剧的人；
- 喜欢角色之间"吵吵闹闹但其实很有爱"的群像关系的人；
- 喜欢慢热感情线、愿意陪角色一起磨蹭的人——佐藤和伊波的感情线需要三季才能看到结果；
- 福山润、小野大辅、神谷浩史的粉丝。

第一季的节奏非常适合入坑：角色一个个登场，怪癖一个个揭晓，等你认识完全店的人，就已经离不开这家餐厅了。

---

# 总结

《迷糊餐厅》里没有谁是"正常"的：喜欢水蚤的高中生、不干活的店长、带刀的主任、带胃药的厨师、一见男人就出拳的女孩子。可正是这些"不正常"的人凑在一起，才让这家餐厅变成了一个让人想天天回去的地方。

**打工的地方未必有多好，但一起打工的人，会让日子变得有意思。**

欢迎光临瓦古娜利亚——危险的感觉，真的会上瘾。
